# Support

This repository is the companion material (labs, slides, videos, quizzes,
and illustrative code) for the book *Mastering Agentic AI Systems: Guide for
the NVIDIA NCP-AAI Exam*. It is a content repository, not a software
package, so "support" here mostly means getting questions about the material
answered and getting content gaps or errors fixed.

## Where to ask

* **Found an error, a broken lab, an outdated reference, or a content gap?**
  Open a [GitHub Issue](../../issues). This is the primary channel and the
  fastest way to get a response.
* **General questions about using the material?** Also use
  [GitHub Issues](../../issues) for now. GitHub Discussions is not currently
  enabled on this repository; it may be enabled in the future if there is
  demand, but do not assume it is available today.
* **Anything else** (including questions you don't want to raise publicly,
  or matters unrelated to a specific issue/PR) can be sent to the GSA
  project contact at [cto@gsa.gov](mailto:cto@gsa.gov).
* **Security concerns** should go through the process in
  [SECURITY.md](SECURITY.md) instead of a regular issue.

## Response times

We aim to give a first response to new issues and pull requests within
**3 business days**. This is a first response, not necessarily a
resolution — some content fixes take longer, especially for larger labs or
slide decks.

## Before you ask

* Search existing [issues](../../issues) to see if your question has already
  been raised.
* If you're reporting a problem with a specific lab, slide, video, or code
  example, include the file path so it's easy to locate.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to propose changes yourself.
