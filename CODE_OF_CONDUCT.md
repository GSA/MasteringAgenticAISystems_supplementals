# Code of Conduct

## Our commitment

We are committed to making participation in this project a respectful, harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity or expression, level of experience, education, socioeconomic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

Examples of constructive behavior include using welcoming language, respecting differing viewpoints, accepting feedback, focusing on what is best for the community, and showing empathy. Unacceptable behavior includes harassment, discriminatory language or imagery, personal attacks, trolling, threats, doxxing, or publishing another person's private information without permission.

## Scope

This code applies in project spaces and when an individual is representing the project in public spaces, including issues, pull requests, reviews, discussions, events, and project-related communications.

## Reporting and enforcement

Report conduct concerns privately rather than in a public issue. Contact the repository maintainers or GSA GitHub support at `gsa-github.support@gsa.gov` so the concern can be routed appropriately. Include enough detail for a fair review, but do not disclose sensitive personal information unnecessarily.

Project maintainers may remove, edit, or reject contributions and communications that are inconsistent with this code and may temporarily or permanently restrict participation. Reports will be handled as confidentially as reasonably possible, with attention to the safety and privacy of affected people.
