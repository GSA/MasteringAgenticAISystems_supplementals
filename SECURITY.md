# Security Policy

GSA-developed software and systems are subject to the [GSA Vulnerability Disclosure Policy](https://www.gsa.gov/website-information/vulnerability-disclosure-policy).

## Reporting a vulnerability

Do **not** report suspected security vulnerabilities in a public issue, discussion, or pull request. Submit a report through the channels described in the GSA Vulnerability Disclosure Policy: email `gsa-vulnerability-reports@gsa.gov` or use the CISA Vulnerability Disclosure Program Platform.

A useful report includes the affected file, branch or commit, reproduction steps, potential impact, and a minimal proof of concept when appropriate. Do not include sensitive data in email; request a secure exchange method when needed.

## Scope of this repository

This repository is primarily educational material and illustrative code. A sample may be intentionally incomplete or unsafe for direct production use. Security reports should distinguish a defect in the repository itself from a known limitation explicitly described in an example.

Supported security fixes apply to the default branch. Archived reference snapshots under `References/` should generally be reported to their upstream project unless the issue concerns how this repository packages or describes them.
