## Coverage

The library is uneven. Parts 1–5 carry most of the direct links; Parts 7–10 together list only 14. Many
entries in the later Parts are search suggestions ("Search *MIT 6.824 Spring 2020*") rather than links, and the
project has not verified that links still resolve or match their descriptions. Verifying and extending the library is an
open [contribution track]({% link contributing.md %}).

## Entry format

Each entry gives a title, the URL and approximate duration, and what the video covers:

```
### Progressive Disclosure
- https://www.nngroup.com/videos/progressive-disclosure/ ~8 minutes
- Covers: Progressive disclosure pattern, information layering, cognitive load management
```

Each Part page has a Videos column that links straight to that chapter's section in the source file.
