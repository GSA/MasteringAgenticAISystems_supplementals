## The tiers

### Essential

You must understand these to benefit from the book.

| Topic | Time needed if you must catch up |
|---|---|
| Large Language Model (LLM) Fundamentals | 4-6 hours |
| Python Programming | 15-25 hours if starting from basics |
| RESTful APIs and HTTP Fundamentals | 3-5 hours |
| Command Line and Shell Scripting | 4-6 hours |
| Docker and Containerization Basics | 5-8 hours |
| Machine Learning Fundamentals | 10-15 hours |

### Recommended

You can succeed without them, but expect to look things up often.

| Topic | Time needed if you must catch up |
|---|---|
| Software Architecture Patterns | 5-8 hours |
| Database Fundamentals | 6-10 hours |
| Kubernetes Fundamentals | 8-12 hours |
| Natural Language Processing (NLP) Basics | 6-10 hours |

### Beneficial

These accelerate learning but are not required.

| Topic | Time needed if you must catch up |
|---|---|
| Distributed Systems Concepts | 8-12 hours |
| GPU Architecture and CUDA Basics | 4-6 hours |
| Prompt Engineering Techniques | 3-5 hours |
| API Design and REST Principles | 4-6 hours |
| Async Programming in Python | 5-8 hours |
| CI/CD and DevOps Fundamentals | 6-10 hours |

A note on one topic: the detailed section lists **machine learning fundamentals** as essential, while the
document's own self-assessment checklist places it under recommended. Treat it as essential if you have not worked
with embeddings or model training before.

## Quick self-assessment

You should be able to answer yes to all five essentials:

- I understand how LLMs work (tokens, context windows, prompting).
- I can write and debug intermediate Python.
- I understand REST APIs and HTTP basics.
- I can use command-line interfaces and write shell scripts.
- I understand Docker containers and can build images.

If you cannot check at least four of the five, plan two to three weeks of remediation before starting.

## Preparation paths

| Path | Duration | Effort | Covers |
|---|---|---|---|
| Minimal | 2–3 weeks | 25–35 hours | Essentials only, enough to start Parts 1–2 |
| Recommended | 4–5 weeks | 40–60 hours | Essentials plus recommended topics |
| Comprehensive | 6–8 weeks | 60–90 hours | Essentials, recommended, and beneficial topics |

Week-by-week breakdowns and remediation resources are in the
