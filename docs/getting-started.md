## The study path

1. **Check your background.** Read [Prerequisites]({{ site.baseurl }}/prerequisites/) and work through its
   self-assessment. Budget 2–8 weeks of preparation if you are missing essentials.
2. **Choose your target certification.** Open [Certifications]({{ site.baseurl }}/certifications/) to see which chapters
   carry the most weight for your exam. For NCP-AAI, every chapter contributes.
3. **Read chapter by chapter.** Use the [Curriculum]({{ site.baseurl }}/curriculum/) pages for the overview and the
   [`Study_Plan.md`]({{ site.repo_blob }}/Study_Plan.md) for each chapter's key concepts, self-check questions, and time
   allocation. The Study Plan describes a 4-month (120-day) intensive schedule and allocates about
   340 hours across its chapters.
4. **Check retention.** Take each chapter's quiz from [Quizzes & practice exams]({{ site.baseurl }}/practice/) when you
   finish it.
5. **Practice.** Work through the [code examples]({{ site.baseurl }}/code-examples/) for the chapter, and the
   [lab]({{ site.baseurl }}/labs/) where one exists (coverage is still being built out).
6. **Take a second pass.** Use the [slides]({{ site.baseurl }}/slides/) for a condensed review and the
   [videos]({{ site.baseurl }}/videos/), embedded under each chapter summary on the Part pages, for another explanation of the
   same concept.
7. **Rehearse the exam.** Take the full-length practice exams, and use the [AI tutor]({{ site.baseurl }}/ai-tutor/) to
   work through what you miss.

## By goal

| If you are… | Start with |
|---|---|
| Preparing for **NCP-AAI** | Part 1, then follow the Parts in order; use every chapter |
| Preparing for **another certification** | [Certifications]({{ site.baseurl }}/certifications/): pick the chapters rated **H**, then fill gaps from **M** |
| **Teaching** a course | The [Curriculum]({{ site.baseurl }}/curriculum/) pages, [slides]({{ site.baseurl }}/slides/), and the [labs]({{ site.baseurl }}/labs/) template |
| Looking for **depth on a single topic** | The Part page for that topic; each chapter row links its slides, quiz, videos, figures, and code |
| Wanting to **help** | [Contributing]({{ site.baseurl }}/contributing/) |

## Using the repository directly

Everything on this site is a view onto files in the
[repository](https://github.com/GSA/MasteringAgenticAISystems_supplementals). The book's chapter text is not published here; the
[`Study_Plan.md`]({{ site.repo_blob }}/Study_Plan.md) is the reading guide, and the Part pages link into it chapter by chapter.
Clone the repository if you want the slides, figures, and code offline:

```bash
git clone https://github.com/GSA/MasteringAgenticAISystems_supplementals.git
```
