## The study path

1. **Check your background.** Read [Prerequisites]({% link prerequisites.md %}) and work through its
   self-assessment. Budget 2–8 weeks of preparation if you are missing essentials.
2. **Choose your target certification.** Open [Certifications]({% link certifications.md %}) to see which chapters
   carry the most weight for your exam. For NCP-AAI, every chapter contributes.
3. **Read chapter by chapter.** Use the [Curriculum]({% link curriculum/index.md %}) pages for the overview and the
   [`Study_Plan.md`]({{ site.repo_blob }}/Study_Plan.md) for each chapter's key concepts, self-check questions, and time
   allocation. The Study Plan describes a 4-month (120-day) intensive schedule and allocates about
   340 hours across its chapters.
4. **Check retention.** Take each chapter's quiz from [Quizzes & practice exams]({% link practice.md %}) when you
   finish it.
5. **Practice.** Work through the [code examples]({% link code-examples.md %}) for the chapter, and the
   [lab]({% link labs.md %}) where one exists (coverage is still being built out).
6. **Take a second pass.** Use the [slides]({% link slides.md %}) for a condensed review and the
   [videos]({% link videos.md %}) for another explanation of the same concept.
7. **Rehearse the exam.** Take the full-length practice exams, and use the [AI tutor]({% link ai-tutor.md %}) to
   work through what you miss.

## By goal

| If you are… | Start with |
|---|---|
| Preparing for **NCP-AAI** | Part 1, then follow the Parts in order; use every chapter |
| Preparing for **another certification** | [Certifications]({% link certifications.md %}): pick the chapters rated **H**, then fill gaps from **M** |
| **Teaching** a course | The [Curriculum]({% link curriculum/index.md %}) pages, [slides]({% link slides.md %}), and the [labs]({% link labs.md %}) template |
| Looking for **depth on a single topic** | The Part page for that topic; each chapter row links its slides, quiz, videos, figures, and code |
| Wanting to **help** | [Contributing]({% link contributing.md %}) |

## Using the repository directly

Everything on this site is a view onto files in the
[repository](https://github.com/GSA/MasteringAgenticAISystems_supplementals). The book's chapter text is not published here; the
[`Study_Plan.md`]({{ site.repo_blob }}/Study_Plan.md) is the reading guide, and the Part pages link into it chapter by chapter.
Clone the repository if you want the slides, figures, and code offline:

```bash
git clone https://github.com/GSA/MasteringAgenticAISystems_supplementals.git
```
