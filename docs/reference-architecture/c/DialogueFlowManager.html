Dialogue Flow Manager

Software componentOrchestrationOrchestration & Toolsarc:DialogueFlowManager

An orchestration component that manages multi-turn dialogue, tracking turn context and allowing users to digress from an in-progress task flow and later resume it where it paused.

Responsibility. Coordinates each conversational turn across intent handling, memory and response generation while tolerating non-linear dialogue.

Also known as: Multi-turn dialogue management, Conversation manager

Design guidance

  • SHOULD allow users to interrupt a task flow (e.g., a refund request) with tangential questions and resume it seamlessly.
  • SHOULD NOT model conversations as sequential form filling of predetermined fields.
  • MUST NOT fabricate information to maintain conversational flow when genuine knowledge is absent.
