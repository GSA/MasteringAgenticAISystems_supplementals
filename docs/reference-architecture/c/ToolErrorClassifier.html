Tool Error Classifier

Software componentTools & IntegrationOrchestration & Toolsarc:ToolErrorClassifier

A post-execution component that classifies tool failures as transient (timeouts, temporary unavailability, rate limits) or permanent (invalid tool name, authentication failure, parameter validation error) to select the recovery path.

Responsibility. Selects retry, fallback or escalation for each tool failure according to its error class.

Also known as: Error classification, Intelligent error handling

Design guidance

  • MUST route only transient failures to retry with exponential backoff.
  • SHOULD log permanent errors for investigation and escalate them to human operators for immediate attention.
  • SHOULD detect execution failures from exceptions, HTTP error codes, timeouts and explicit tool error returns.
