Sensor Stream Synchronizer

Software componentCognitionCognition & Memoryarc:SensorStreamSynchronizer

A buffering component that aligns multimodal sensor streams to common timestamps, holding early data until all modalities for that time are available.

Responsibility. Aligns sensor streams to common timestamps before fusion.

Also known as: Synchronized buffering
