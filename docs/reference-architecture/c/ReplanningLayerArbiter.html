Replanning Layer Arbiter

Software componentOrchestrationOrchestration & Toolsarc:ReplanningLayerArbiter

An orchestration component that resolves conflicting outputs of concurrently running replanning layers by precedence, recency and specificity, installing one active plan and retaining others as fallbacks.

Responsibility. Chooses which layer's plan becomes the active plan when layers conflict.

Also known as: Layer coordination protocol, Conflict resolver

Design guidance

  • MUST let safety-critical reactive responses override all other layers, and contingencies pre-empt incremental adjustments.
  • SHOULD let strategic replanning influence future decisions without disrupting in-progress execution.
  • SHOULD retain superseded plans (e.g., an incremental update) as fallbacks if the selected plan fails.
