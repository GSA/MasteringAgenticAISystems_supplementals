Dynamic Tool Loader

Software componentTools & IntegrationOrchestration & Toolsarc:DynamicToolLoader

A prompt-preparation component that selects, per request, only the tool descriptions relevant to the current task and injects them into the model prompt.

Responsibility. Limits the tool definitions sent to the model to those relevant for the current request.

Also known as: Tool description minimization, Dynamic tool description loading

Design guidance

  • SHOULD load tool descriptions only when relevant to the current task rather than on every request.

Quantitative guidance

As stated by the sources; verify before use.

  • An agent always loading database tools but using them 30% of the time wastes ~2,100 tokens on 70% of interactions (Ch3.10).
  • E-commerce: ~15% of tokens came from tool descriptions repeated across agent handoffs (Ch3.10).
