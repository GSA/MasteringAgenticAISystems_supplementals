Failure-Triggered Feedback Prompt

Software componentHuman OversightExperience & Human Oversightarc:FailureTriggeredFeedbackPrompt

A feedback collector that proactively solicits a reason when behavioural signals such as abandonment or rapid escalation indicate an unhelpful response.

Responsibility. Converts detected failed interactions into targeted feedback opportunities.

Also known as: Contextual failure prompt

Variant of Feedback Collector abstract

When to choose. Choose when training data should focus precisely on current weaknesses rather than random optional feedback.
