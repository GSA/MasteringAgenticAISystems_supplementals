Information Gain Scorer

Software componentCognitionCognition & Memoryarc:InformationGainScorer

A reasoning-step scorer that estimates, via conditional predictive value, how much each step reduces uncertainty about the final answer beyond prior steps.

Responsibility. Measures each reasoning step's informativeness.

Also known as: Informativeness scorer, Conditional PVI scorer
