Incremental Refresh Policy

Data artifactOrchestrationOrchestration & Toolsarc:IncrementalRefreshPolicy

A refresh configuration that processes only records new or changed since the last successful run's watermark.

Responsibility. Restricts each run to the delta since the last success.

Also known as: Incremental mode, Delta processing

Variant of Knowledge Refresh Policy abstract

When to choose. Choose as the default for scheduled (hourly or daily) runs that keep the knowledge base fresh.
