Memory Retrieval Policy

Data artifactMemoryCognition & Memoryarc:MemoryRetrievalPolicy

A configuration specifying memory retrieval parameters: ranking weights, decay rate, similarity threshold, top-k limit, token budget share and context metadata filters.

Responsibility. Declares how many and which memories retrieval may return and how they are ranked.

Also known as: Retrieval strategy weights, Retrieval limits, Graduated retrieval order
