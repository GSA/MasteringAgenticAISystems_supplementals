Environmental Context Adapter

Software componentTools & IntegrationOrchestration & Toolsarc:EnvironmentalContextAdapter

A connector that retrieves real-time external system states, such as inventory levels, traffic conditions, weather and market data, that bound which proactive actions and recommendations are feasible.

Responsibility. Supplies current external-world state to the agent's context.
