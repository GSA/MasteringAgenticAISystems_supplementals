Referential Integrity Validator

Software componentKnowledge & DataKnowledge & Dataarc:ReferentialIntegrityValidator

A validator that checks that document cross-references, internal links, citations and referenced IDs resolve to existing documents and that relationships agree across sources.

Responsibility. Detects broken or conflicting cross-document references.

Also known as: Cross-reference validation, Reference validation
