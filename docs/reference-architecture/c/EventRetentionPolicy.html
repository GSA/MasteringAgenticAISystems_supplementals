Event Retention Policy

Data artifactOrchestrationOrchestration & Toolsarc:EventRetentionPolicy

A configuration artifact specifying how long events remain available in an event log (hours, days, or indefinitely) for replay and reprocessing.

Responsibility. Bounds the replay window of an event stream.

Also known as: Topic retention configuration
