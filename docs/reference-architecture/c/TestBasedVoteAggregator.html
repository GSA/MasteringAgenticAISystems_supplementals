Test-Based Vote Aggregator

Software componentCognitionCognition & Memoryarc:TestBasedVoteAggregator

A self-consistency aggregator for generated code that executes each sampled implementation against provided test cases and selects among the samples that pass, instead of comparing output text.

Responsibility. Selects consensus code solutions by test-execution outcomes.

Also known as: Test-driven aggregation, Execution-based voting

Variant of Self-Consistency Aggregator abstract

When to choose. Choose for code generation where implementations vary textually but test cases define correctness.
