Escalation Handler

Software componentHuman OversightExperience & Human Oversightarc:EscalationHandler

A workflow node that hands an inquiry to human staff, creating a case number, setting an expected response time, notifying on-call staff, and marking the case escalated in state.

Responsibility. Hands inquiries that need a human over to on-call staff.

Also known as: Escalation node, Human handoff node, Escalation coordinator service, Human appeal pathway, Escalation handoff, Clinical symptom escalation, Coordination agent (human handoff)

Design guidance

  • MUST escalate immediately to human agents when customers express frustration or raise legal concerns.
  • SHOULD fail in isolation: a crash in escalation should affect only cases needing human handoff while automated handling continues.
  • MUST NOT add artificial friction (stated delays, lengthy forms) that discourages legitimate escalation.
  • SHOULD record escalation outcomes even for conversations closed as resolved, so deflection is not inflated by premature closure.
  • MUST give users readily accessible pathways to request human review of automated decisions.
