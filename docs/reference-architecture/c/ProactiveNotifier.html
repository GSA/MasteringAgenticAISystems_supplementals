Proactive Notifier

Software componentExperienceExperience & Human Oversightarc:ProactiveNotifier

A component that informs users after an agent autonomously completes low-risk actions, stating what was done and why, with options to view details or undo.

Responsibility. Initiates agent-to-user communication about completed autonomous actions.

Also known as: Notification pattern, Post-execution notification, Notification service, Delay notifier, Revised-ETA notifier, Push notification service, Unsolicited report notifier, Proactive alert delivery, Provisional approval with reviewer notification

Design guidance

  • SHOULD be used only for low-risk, high-confidence, reversible actions where undo exists.
  • SHOULD explain why the user is being contacted now (signals, data, assumptions) and how to correct wrong predictions.
