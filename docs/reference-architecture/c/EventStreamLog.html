Event Stream Log

Software componentOrchestrationOrchestration & Toolsarc:EventStreamLog

An event broker built on an immutable, partition-ordered event log supporting replay, temporal queries and auditing.

Responsibility. Retains an immutable, replayable log of events.

Also known as: Event stream processing, Distributed event log, Dumb-broker/smart-consumer event stream, Event persistence for replay

Variant of Event Broker abstract

When to choose. Choose when events must be replayed to rebuild state or train models, analysed temporally, or retained as a permanent audit record.

Design guidance

  • SHOULD let consumers track their own offsets so pipeline stages can restart and replay from any offset without complex state reconstruction.
  • SHOULD log all events to durable storage before delivery so failed workflows can be replayed through fixed agent logic.

As stated by the sources; verify before use.
