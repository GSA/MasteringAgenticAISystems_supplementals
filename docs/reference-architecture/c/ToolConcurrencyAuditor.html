Tool Concurrency Auditor

Software componentObservability & EvaluationObservability & Evaluationarc:ToolConcurrencyAuditor

An auditing component that correlates tool invocations across agents through shared trace IDs to detect simultaneous invocations of tools modifying the same shared resource.

Responsibility. Detects multi-agent race conditions on shared tools from correlated traces.

Also known as: Concurrency-aware auditing
