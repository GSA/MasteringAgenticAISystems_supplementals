State Cycle Detector

Software componentOrchestrationOrchestration & Toolsarc:StateCycleDetector

A loop-protection component that hashes key state fields each iteration and flags a cycle when a previously seen state hash recurs.

Responsibility. Detects when an agent has returned to a previously visited state.

Also known as: State hashing, Duplicate state detection, Reasoning loop detector

Design guidance

  • SHOULD hash key state fields rather than full state to avoid false negatives.
  • SHOULD on detection escalate to a human, switch to a fundamentally different approach, or fail gracefully with diagnostics.
  • SHOULD measure progress across iterations to distinguish productive refinement from unproductive loops.
