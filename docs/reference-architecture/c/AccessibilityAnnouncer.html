Accessibility Announcer

Software componentExperienceExperience & Human Oversightarc:AccessibilityAnnouncer

A presentation component that relays dynamic agent output and alerts to assistive technologies through live regions, buffering streamed text to announce only complete sentences.

Responsibility. Announces agent updates to screen readers at appropriate granularity.

Also known as: Screen-reader live region, Streaming response accessibility

Design guidance

  • SHOULD announce streamed responses only at sentence boundaries, separately from the visual display.
  • SHOULD use polite announcements by default and assertive ones only for critical alerts.
