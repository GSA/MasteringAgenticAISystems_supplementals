Human Proxy Agent

Software componentOrchestrationOrchestration & Toolsarc:HumanProxyAgent

A conversational agent acting on the user's behalf that validates other agents' proposed solutions by executing their code and reporting results back as conversational messages.

Responsibility. Executes and validates peer-agent outputs on the user's behalf within a conversation.

Also known as: UserProxyAgent, User proxy

Design guidance

  • SHOULD seek human approval before actions when configured for always-ask input mode, and run autonomously only when configured for never-ask mode.
  • SHOULD request human validation of the final output when the conversation ends or the round limit is reached.
