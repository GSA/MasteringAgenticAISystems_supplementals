Design guidance

  • SHOULD place critical information at context boundaries, but only when relevance-ranking confidence is high.
  • SHOULD fit retrieved chunks within token limits, prioritizing high-relevance chunks when truncation is required.

Quantitative guidance

As stated by the sources; verify before use.

  • Information in the middle 40-60% of context is retrieved less accurately; attention-aware positioning gives ~5-12% accuracy gains when ranking confidence is high (Ch5.9).
