Conversational (Chat) Interface

Software componentExperienceExperience & Human Oversightarc:ConversationalInterface

A chat-style interaction surface presenting user and agent messages as a timestamped vertical timeline, with streaming output, quick-action buttons, typing indicators, and visible conversation history.

Responsibility. Accepts user turns and renders agent responses as a conversation thread.

Also known as: Chat interface, Basic chat interface, Chatbot UI, Streaming chat client, Conversational user interface, Virtual assistant front end

Variant of Agent User Interface abstract

When to choose. Choose for general Q&A, customer support, simple task automation, and exploratory conversations; avoid for workflows needing visual process representation, dense structured data, or parallel information streams.

Design guidance

  • SHOULD show the last three to five exchanges by default with scrollable full history.
  • SHOULD highlight when responses draw on earlier context and allow users to clear context when switching topics.
  • SHOULD persist sessions across reloads when appropriate so users can resume complex tasks.
  • SHOULD warn users when the agent's context window approaches its limit.
  • SHOULD let users state goals in natural language instead of navigating predefined menu paths.
  • SHOULD accommodate voice, text and visual modality switches without treating them as conversation breaks.

Quantitative guidance

As stated by the sources; verify before use.

  • Menu-driven interfaces required 15-20 clicks for simple queries; Klarna resolution time fell from 11 to under 2 minutes (82%) after moving to conversation (Ch10.1).
  • Erica: 1.5 million daily interactions, 98% autonomous resolution, 4.7/5 satisfaction, 2 billion interactions since 2018 (Ch10.1).
