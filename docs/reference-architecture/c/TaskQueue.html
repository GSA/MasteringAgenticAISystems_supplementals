Task Queue

Data storeOrchestrationOrchestration & Toolsarc:TaskQueue

A shared queue that holds pending jobs and tasks so stateless replicas and specialised agent pools can coordinate work without affinity.

Responsibility. Buffers pending jobs for pickup by any available replica.

Also known as: Job queue, Queue system, Shared task queue, Request queue
