Static Security Scanner

Software componentSafety & SecuritySafety, Security & Governancearc:StaticSecurityScanner

A source-code security scanner that detects insecure patterns such as hardcoded secrets, injection-prone queries, unsafe deserialisation and unsanitised user input interpolated into prompt templates.

Responsibility. Flags insecure code patterns in agent application code before build.

Also known as: SAST scan, Prompt-template injection scan, Code filtering layer, Generated-code sanitizer, SAST

Design guidance

  • MUST add agent-specific rules that detect user input interpolated into prompts without sanitisation and flag them for review or explicit security annotation.
  • SHOULD be used as a fast but brittle first filter; it complements rather than replaces structural isolation.
  • SHOULD run both as a pre-commit hook and in CI, failing on high and critical findings.
