Unpartitioned GPU Layout

Data artifactInfrastructureInfrastructurearc:UnpartitionedGPULayout

A GPU partition layout that disables hardware partitioning so each GPU is allocated whole to one workload.

Responsibility. Declares that cluster GPUs are exposed as full, dedicated devices.

Also known as: Strategy none

Variant of GPU Partition Layout abstract

When to choose. Choose for 70B+ models, high-concurrency single-tenant or latency-critical deployments needing a full GPU.
