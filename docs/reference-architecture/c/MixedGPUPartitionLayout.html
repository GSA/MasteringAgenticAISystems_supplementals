Mixed GPU Partition Layout

Data artifactInfrastructureInfrastructurearc:MixedGPUPartitionLayout

A GPU partition layout that assigns different partition profiles to different GPUs in one cluster to match heterogeneous model sizes or service tiers.

Responsibility. Declares a heterogeneous partition geometry sized to the observed demand per tier.

Also known as: Strategy mixed, Heterogeneous partitioning

Variant of GPU Partition Layout abstract

When to choose. Choose for multi-tier offerings and diverse model sizes (7B-70B) when the team accepts extra scheduling and configuration complexity for better utilisation.

Design guidance

  • SHOULD derive the profile mix from the observed demand distribution and keep about 10% headroom for spikes or new tiers.
  • SHOULD monitor utilisation per profile to detect partitions idling while requests queue for another profile.

As stated by the sources; verify before use.
