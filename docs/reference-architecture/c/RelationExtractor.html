Relation Extractor

Software componentKnowledge & DataKnowledge & DataVariation point (abstract)arc:RelationExtractor

An abstract software component that identifies typed semantic relationships (triples with properties) between entity pairs mentioned in text.

Responsibility. Extracts typed relationship triples between entities in text.

Also known as: Relationship Extractor, Triple Extractor

Variants

VariantWhen to choose
Dependency-Parse Relation ExtractorChoose as a reliable baseline for explicit subject-verb-object relationships; it misses implicit relationships stated without verbs.
Neural Relation ExtractorChoose when implicit relationships (e.g., appositives like 'Google, a major Anthropic investor') must be captured for higher recall.

Design guidance

  • SHOULD normalize extracted verbs to a standardized set of relationship types.
  • SHOULD combine dependency parsing with neural models when high recall is required.
  • SHOULD be expected to err on coreference and context-dependent references even with LLM-based extractors; plan for validation.
