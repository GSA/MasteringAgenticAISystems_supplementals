In-Memory State Store

Data storeOrchestrationOrchestration & Toolsarc:InMemoryStateStore

A state checkpoint store that keeps workflow state in the agent process's memory for the duration of a task.

Responsibility. Keeps workflow state in process memory for short-lived tasks.

Also known as: Agent-local state

Variant of State Checkpoint Store abstract

When to choose. Choose for short-lived, agent-local workflows that complete in seconds to minutes on a single instance; state is lost if the instance fails.
