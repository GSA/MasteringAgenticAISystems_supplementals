Idempotency Store

Data storeOrchestrationOrchestration & Toolsarc:IdempotencyStore

A record of processed message identifiers that lets consumers detect and discard duplicate deliveries.

Responsibility. Records processed message IDs for deduplication.

Also known as: Deduplication store, Processed message ledger, Successful tool invocation record, Processed event ID store, Idempotency tokens

Design guidance

  • MUST be consulted by consumers of at-least-once channels before performing side effects.
  • MUST check an event's ID before processing and record it after processing to prevent duplicate emails, charges or records.
  • SHOULD use idempotency tokens so retried indexing requests are detected and not indexed twice.
