Stream Interrupt Handler

Software componentExperienceExperience & Human Oversightarc:StreamInterruptHandler

A control component that receives user stop or clarification messages during streaming and cancels or redirects the in-flight generation with updated context.

Responsibility. Applies mid-stream user interruptions to the running agent generation.

Also known as: Stop generation control, Mid-stream interruption handler
