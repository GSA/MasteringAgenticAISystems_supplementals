State Value Estimator

Software componentCognitionCognition & MemoryVariation point (abstract)arc:StateValueEstimator

An abstract cognition component that estimates the value of a newly expanded search-tree leaf state, producing the reward signal backpropagated through the tree.

Responsibility. Estimates the expected outcome value of a search leaf state.

Also known as: Leaf evaluator, Simulation phase

Variants

Rollout SimulatorChoose when no trained value network is available and simulations are cheap, favouring heuristic rollout policies where domain knowledge exists.
