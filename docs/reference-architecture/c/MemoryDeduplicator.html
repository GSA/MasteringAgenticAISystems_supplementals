Memory Deduplicator

Software componentMemoryCognition & Memoryarc:MemoryDeduplicator

A memory component that detects near-duplicate stored items by semantic similarity and merges them into a representative item with occurrence and outcome statistics.

Responsibility. Merges near-duplicate memory entries into consolidated representatives.

Also known as: Episode deduplication, Near-duplicate chunk consolidation
