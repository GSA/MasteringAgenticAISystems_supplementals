Smoke Tester

Software componentObservability & EvaluationObservability & Evaluationarc:SmokeTester

A post-deployment check that sends real requests to a newly deployed service (health endpoint, simple query, authenticated call) to verify basic functionality in its target environment.

Responsibility. Verifies a fresh deployment is minimally functional.

Also known as: Smoke tests, Retrieval smoke test
