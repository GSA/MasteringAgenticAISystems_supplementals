High-Performance Reverse Proxy

Software componentInfrastructureInfrastructurearc:HighPerformanceReverseProxy

An API gateway proxy with minimal per-request processing that forwards and load-balances traffic to backend agents, optionally serving as the cluster ingress controller.

Responsibility. Forwards and balances entry traffic with minimal latency overhead.

Also known as: Performance-optimized reverse proxy, Ingress controller

Variant of API Gateway Proxy abstract

When to choose. Choose when maximum performance and operational simplicity outweigh API-management features, authentication/rate limiting live elsewhere, and routing plus load balancing suffice.
