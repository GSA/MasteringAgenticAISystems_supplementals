Rule-Based Compliance Scorer

Software componentObservability & EvaluationObservability & Evaluationarc:RuleBasedComplianceScorer

A response scorer that extracts values (amounts, percentages, dates) from a response and verifies them against configured policy limits, failing on any violation.

Responsibility. Verifies that commitments stated in a response satisfy structured policy constraints.
