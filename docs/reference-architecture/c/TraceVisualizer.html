Trace Visualizer

Software componentObservability & EvaluationObservability & Evaluationarc:TraceVisualizer

An analysis interface that renders stored traces as interactive timelines with hierarchical drill-down, error highlighting, side-by-side trace comparison, and span filtering and search.

Responsibility. Renders stored traces for interactive, drill-down debugging.

Also known as: Trace timeline view, Trace explorer, Profiler timeline GUI, Waterfall trace view, Trace reconstruction, Agent collaboration timeline view, Visual reasoning flowchart

Design guidance

  • SHOULD display multi-agent workflows as one integrated timeline correlated by shared trace IDs, including message passing, handoffs and parallel executions.
  • SHOULD support filtering spans by tool, latency threshold and error status.

Quantitative guidance

As stated by the sources; verify before use.
