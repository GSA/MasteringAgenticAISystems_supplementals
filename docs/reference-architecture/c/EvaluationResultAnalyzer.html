Evaluation Result Analyzer

Software componentObservability & EvaluationObservability & Evaluationarc:EvaluationResultAnalyzer

An analytics component that statistically compares reasoning scores against reference chains, task outcomes and user feedback to locate systematic failure patterns and predictive quality dimensions.

Responsibility. Identifies systematic reasoning failure patterns from evaluation results.
