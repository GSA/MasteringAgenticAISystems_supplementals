User Trajectory Model

Model assetCognitionCognition & Memoryarc:UserTrajectoryModel

Machine-learning model weights trained on user trajectories, i.e., typical transitions from current to future states, predicting what users will need next and when they typically recognise that need.

Responsibility. Encodes learned user state-transition patterns for need prediction.
