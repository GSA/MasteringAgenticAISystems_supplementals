Multi-Model Inference Image

Data artifactModel ServingModelsarc:MultiModelInferenceImage

An inference service image supporting a broad range of model architectures loaded on demand from catalogs, hubs or local storage and switched through API parameters.

Responsibility. Serves many interchangeable models from one container.

Also known as: Multi-LLM Compatible NIM

Variant of Inference Service Image abstract

When to choose. Choose for research, experimentation, custom fine-tuned model pipelines, multi-model task switching and prototyping where experimentation velocity outweighs production stability.
