State Merge Policy

Data artifactOrchestrationOrchestration & Toolsarc:StateMergePolicy

A configuration of how a writer reconciles its intended state changes with changes committed since its read—merging disjoint partitions automatically and applying application-specific rules or manual review for same-field conflicts.

Responsibility. Specifies how version-conflicting shared-state updates are combined.

Also known as: Merge strategy, Conflict resolution policy

Relationships

configures structural

  • Optimistic Lock Controller Ch8.2A

Design guidance

  • SHOULD merge concurrent updates that touch disjoint partitions rather than let the last write win.
  • SHOULD route conflicts on the same fields to explicit resolution rules (latest, earliest) or human review.
  • SHOULD partition work across agents so they write disjoint state regions.

Quantitative guidance

As stated by the sources; verify before use.

  • Residual 0.3% failure rate reflects genuine same-field conflicts requiring manual resolution (Ch8.2A).
