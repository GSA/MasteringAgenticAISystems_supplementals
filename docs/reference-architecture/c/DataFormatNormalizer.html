Data Format Normalizer

Software componentKnowledge & DataKnowledge & Dataarc:DataFormatNormalizer

A transformation component that rewrites heterogeneous representations of dates, phone numbers and monetary values into canonical forms during ETL transformation.

Responsibility. Converts inconsistent value formats into canonical representations.

Also known as: Format standardization, Automatic remediation
