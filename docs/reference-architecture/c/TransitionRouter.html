Transition Router

Software componentOrchestrationOrchestration & ToolsVariation point (abstract)arc:TransitionRouter

A decision component that evaluates current workflow state against the logic tree to select the next node, tool, or sub-agent to execute.

Responsibility. Selects the next workflow operation from current state.

Also known as: Logic Tree Evaluation, Logic tree evaluator, Conditional edge

Variants

VariantWhen to choose
Hybrid Transition RouterChoose when LLM reasoning about the next step must be constrained by explicit rules.
LLM Transition RouterChoose when deciding what to do next requires reasoning, e.g., tasks without predetermined solution paths.
Rule-Based Transition RouterChoose when decision logic can be expressed as explicit rules over state fields.

  • SHOULD be unit-testable independently of node implementations using controlled state inputs.
