Memory Importance Scorer

Software componentMemoryCognition & Memoryarc:MemoryImportanceScorer

A memory component that assigns each episode an importance score from outcome significance, rarity/novelty, feedback quality, recency and how often its lessons proved useful in later retrievals.

Responsibility. Estimates how informative a memory is so encoding, retention and retrieval can prioritize it.

Also known as: Significance estimator, Episode prioritizer, Novelty scorer
