Agent Test Runner

Software componentObservability & EvaluationObservability & Evaluationarc:AgentTestRunner

A CI component that executes layered automated test suites (isolated unit tests, workflow integration tests, performance benchmarks) against agent code with coverage reporting and per-test timeouts.

Responsibility. Runs automated functional and performance tests of agent code.

Design guidance

  • SHOULD use fuzzy key-phrase checks or LLM-as-judge rather than exact string matching for non-deterministic agent outputs.
  • SHOULD focus integration tests on the ~20% of workflows handling ~80% of traffic plus known failure modes.
  • SHOULD enforce a per-test timeout to fail hung tests.
  • SHOULD run unit, integration, performance-benchmark and quality-evaluation test levels before every update (Ref8.08).

Quantitative guidance

As stated by the sources; verify before use.

  • Unit suite 30-90 s; version matrix cuts 4 minutes to 90 s (2.7x); suite matrix cuts 12 to 5 minutes (Ch4.2).
  • LLM-as-judge can stretch integration suites from 3 to 15+ minutes; focused suites stay under 5 minutes; per-test timeout 300 s (Ch4.2).
