Deferred Batch Scheduler

Software componentOrchestrationOrchestration & Toolsarc:DeferredBatchScheduler

A scheduling component that accumulates non-urgent agent queries and executes them in large batches during off-peak windows when discounted rates or spare capacity are available.

Responsibility. Defers non-urgent agent workloads to off-peak batch execution to cut cost.

Also known as: Off-Peak Batch Processor
