Pre-compiled Engine Backend

Software componentModel ServingModelsarc:PrecompiledEngineBackend

An inference backend executing engines pre-compiled for a specific GPU architecture and memory size, with architecture-specific kernels, validated FP8/INT8 quantization and memory optimizations.

Responsibility. Delivers peak inference performance on supported GPU configurations.

Variant of Inference Backend abstract

When to choose. Choose when pre-compiled engines exist for the deployed GPU (e.g., A100 40/80GB, H100 80GB, L40S 48GB).
