Action Rollback Service

Software componentHuman OversightExperience & Human Oversightarc:ActionRollbackService

A recovery component that reverses completed agent actions on human request, enabling after-the-fact correction of reversible operations.

Responsibility. Undoes completed agent actions.

Also known as: Undo, Rollback mechanism, Revert, Decision override / restore

Design guidance

  • SHOULD offer undo for completed actions when technically feasible.
  • SHOULD treat reversibility as a determinant of the required control pattern.
  • HOTL post-intervention is only viable for reversible actions; irreversible actions require HITL pre-approval.
