State Concurrency Controller

Software componentOrchestrationOrchestration & ToolsVariation point (abstract)arc:StateConcurrencyController

A coordination mechanism that keeps shared workflow state consistent when multiple agent instances update it concurrently.

Responsibility. Serialises or reconciles concurrent updates to shared workflow state.

Also known as: Distributed state coordination

Variants

VariantWhen to choose
CRDT State MergerChoose when state must converge regardless of the order of concurrent updates.
Optimistic Lock ControllerChoose when instances can detect conflicting updates and retry them.
Pessimistic Lock ControllerChoose when instances must hold exclusive access before modifying state.
