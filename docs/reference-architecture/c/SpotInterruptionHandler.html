Spot Interruption Handler

Software componentInfrastructureInfrastructurearc:SpotInterruptionHandler

A control component that detects provider termination warnings for interruptible instances, drains their in-flight requests and shifts load to on-demand capacity.

Responsibility. Gracefully evacuates work from spot instances facing termination.

Also known as: Spot termination handler, Node drainer
