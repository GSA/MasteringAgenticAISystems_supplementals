Memory Conflict Resolver

Software componentMemoryCognition & Memoryarc:MemoryConflictResolver

A memory component that reconciles contradictory retrieved or stored memories before they reach reasoning, using timestamp, frequency, outcome-quality or context-clustering strategies.

Responsibility. Resolves contradictions among memories so reasoning receives a consistent view.

Also known as: Conflicting episode resolution

Design guidance

  • SHOULD resolve conflicting episodes before injecting them into the prompt rather than relying on the model to reconcile them.
  • MAY cluster contradictory episodes by context to convert conflicts into conditional knowledge.
