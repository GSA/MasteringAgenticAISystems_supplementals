Full Conversation Buffer

Software componentMemoryCognition & Memoryarc:FullConversationBuffer

A context window manager that appends every human message and agent response to history and injects the complete, untruncated history into each prompt.

Responsibility. Supplies the complete conversation history to every prompt.

Also known as: ConversationBufferMemory, Chat history memory, Uncompressed history

Variant of Context Window Manager abstract

When to choose. Choose for moderate conversation lengths (roughly 10-20 exchanges) where perfect recall of prior turns matters; switch to sliding-window or summarizing variants when history approaches token limits.
