Chunk Schema Validator

Software componentKnowledge & DataKnowledge & Dataarc:ChunkSchemaValidator

A pre-load validation component that checks each processed chunk, including embedding dimensionality, against the target collection schema and fails fast on violations.

Responsibility. Blocks malformed records from reaching batch insertion.

Also known as: Pre-load schema validation
