Trace Annotation Console

Software componentHuman OversightExperience & Human Oversightarc:HumanEvaluationConsole

A review interface that displays reasoning traces and lets reviewers mark steps correct, incorrect or uncertain, comment on why, and suggest alternative reasoning.

Responsibility. Captures step-level human annotations on reasoning traces.
