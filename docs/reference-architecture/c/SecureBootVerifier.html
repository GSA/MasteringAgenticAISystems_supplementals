Secure Boot Verifier

Software componentSafety & SecuritySafety, Security & Governancearc:SecureBootVerifier

A boot-time integrity component that measures firmware, operating system and container components and refuses to execute any whose signature or hash does not match known-good values.

Responsibility. Prevents tampered software from running on serving hardware.

Also known as: Secure boot, Measured boot
