Output Structure Validator

Software componentSafety & SecuritySafety, Security & Governancearc:OutputStructureValidator

An output guardrail that checks responses against predefined form criteria: JSON or XML well-formedness, schema compliance, length bounds and presence of required elements.

Responsibility. Rejects outputs that violate required format, length or structure.

Also known as: Validate guardrail, Format enforcement, Length constraint
