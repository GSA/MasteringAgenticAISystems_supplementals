Identity Provider

Software componentSafety & SecuritySafety, Security & Governancearc:IdentityProvider

A service that authenticates agents and issues and refreshes secure tokens so only authorised agents access sensitive tools.

Responsibility. Authenticates principals and issues tokens.

Also known as: OAuth provider, Gateway authentication, Enterprise JWT identity provider, API key / OAuth authentication, OAuth 2.0 authorization server

Design guidance

  • SHOULD refresh expired tokens automatically and map authentication errors to resolution steps.
  • SHOULD require multi-factor authentication for internal administrative systems holding customer data, not only customer-facing apps.
  • SHOULD supply agent identity, role and clearance level as the baseline input determining which policies apply.
