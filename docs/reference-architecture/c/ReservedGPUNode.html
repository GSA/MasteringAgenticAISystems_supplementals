Reserved GPU Node

Infrastructure resourceInfrastructureInfrastructurearc:ReservedGPUNode

A compute instance obtained under a 1-3 year capacity commitment in exchange for a substantial discount over on-demand pricing.

Responsibility. Provides discounted, continuously available baseline capacity.

Also known as: Reserved instance

Variant of GPU Node abstract

When to choose. Choose for the predictable, continuous baseline load present even in low-traffic periods.
