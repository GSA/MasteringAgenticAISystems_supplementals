Goal-Based Decision Engine

Software componentCognitionCognition & Memoryarc:GoalBasedDecisionEngine

A decision engine that selects any action sequence achieving a specified target state, treating all goal-achieving actions as equally valuable.

Responsibility. Selects actions that reach a binary goal state without ranking how efficiently they reach it.

Also known as: Goal-based agent

Variant of Decision Engine abstract

When to choose. Choose when binary goals suffice and no trade-offs exist; offers faster development and easier debugging.

Relationships

alternative to variability

Design guidance

  • SHOULD NOT be used where multiple goals must be prioritized or cost/risk trade-offs arise, since it lacks machinery to rank goal-achieving alternatives.
