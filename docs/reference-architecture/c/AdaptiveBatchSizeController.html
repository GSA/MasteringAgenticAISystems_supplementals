Adaptive Batch Size Controller

Software componentModel ServingModelsarc:AdaptiveBatchSizeController

A control component that adjusts inference batch size at runtime from observed queue depth and latency, enlarging batches during surges and shrinking them to hold latency objectives.

Responsibility. Adapts batching to variable demand while meeting latency SLOs.

Also known as: Adaptive batching algorithm, Memory-aware batch size manager
