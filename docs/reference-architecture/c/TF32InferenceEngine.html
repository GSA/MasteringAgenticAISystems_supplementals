TF32 Inference Engine

Model assetModel ServingModelsarc:TF32InferenceEngine

A model execution configuration using the TensorFloat-32 format (FP32 exponent range with a 10-bit mantissa) that gives near-FP32 accuracy with FP16-like speed and no quantization workflow.

Responsibility. Accelerates inference on Ampere-or-newer GPUs without calibration or explicit quantization.

Also known as: TensorFloat-32

Variant of Optimized Inference Engine abstract

When to choose. Choose when targeting Ampere-or-newer hardware exclusively and near-FP32 accuracy is required without a quantization workflow.
