Purpose-Based Access Controller

Software componentGovernance & ComplianceSafety, Security & Governancearc:PurposeBasedAccessController

An access-control component that permits use of sensitive data only for purposes the data subject consented to, keeping fairness-monitoring data siloed from other applications.

Responsibility. Enforces consented purpose limits on access to sensitive demographic data.

Also known as: Purpose limitation control, Consent enforcement
