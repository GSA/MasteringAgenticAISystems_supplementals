Centralized Log Store

Data storeObservability & EvaluationObservability & Evaluationarc:LogStore

A centralized, indexed store of structured log records from agents and inference services, queryable by field for troubleshooting and pattern analysis.

Responsibility. Retains searchable structured logs that explain why metric anomalies occurred.

Also known as: Searchable log index, Log backend, Log analytics platform

Design guidance

  • SHOULD hold structured (parsed JSON) records enriched with cluster and namespace metadata.
  • SHOULD support filtering slow requests, aggregating error types (OOM, timeout, invalid input), request distribution and authentication failures.
