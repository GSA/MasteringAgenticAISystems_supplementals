Metrics Endpoint

InterfaceObservability & EvaluationObservability & EvaluationVariation point (abstract)arc:MetricsEndpoint

An HTTP endpoint (conventionally /metrics) on an instrumented agent or service that exposes its counters, gauges, histograms and summaries in a scrapeable text format.

Responsibility. Exposes a component's current metrics for collection.

Also known as: /metrics endpoint, Metrics exporter endpoint
