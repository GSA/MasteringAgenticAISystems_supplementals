Learned Heuristic Estimator

Software componentCognitionCognition & Memoryarc:LearnedHeuristicEstimator

A heuristic estimator that runs a trained neural network over state features (e.g., obstacle configuration) to predict true remaining path cost.

Responsibility. Predicts near-exact remaining cost per node via learned-model inference.

Also known as: Neural network heuristic

Variant of Heuristic Estimator abstract

When to choose. Choose only when inference is cheap relative to node expansion cost, so higher accuracy reduces total search time.
