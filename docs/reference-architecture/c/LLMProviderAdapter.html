LLM Provider Adapter

Software componentModel ServingModelsarc:LLMProviderAdapter

A client abstraction presenting a unified chat/completion interface over multiple LLM providers so that the model provider can be swapped by configuration without changing agent code.

Responsibility. Normalizes calls to heterogeneous LLM providers behind one interface.

Also known as: Unified LLM interface, Chat model wrapper, ChatOpenAI client pointed at self-hosted endpoint
