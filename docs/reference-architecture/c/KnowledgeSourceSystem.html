Knowledge Source System

Data storeKnowledge & DataKnowledge & Dataarc:KnowledgeSourceSystem

An authoritative upstream system, such as a document repository or an operational CRM, trading or risk database, from which semantic-memory content is extracted.

Responsibility. Holds the original source records and documents that semantic memory mirrors.

Also known as: System of record, Legacy source system, Documentation base, Enterprise data source, Structured data source, Unstructured document repository, Semi-structured API source, Source system, Upstream source, Product catalog, Inventory database, Policy management system

Design guidance

  • SHOULD catalog every enterprise source relevant to the agent use case before building extraction; a missed source leaves knowledge gaps agents cannot fill.

Quantitative guidance

As stated by the sources; verify before use.

  • Enterprise example: client information spread across 12 legacy systems with different identifiers for the same legal entity (Ch5.8).
  • A typical large organization maintains 70 or more distinct data sources (Gartner 2024, cited in Ch6.3A).
