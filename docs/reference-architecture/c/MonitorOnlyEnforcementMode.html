Monitor-Only Enforcement Mode

Data artifactSafety & SecuritySafety, Security & Governancearc:MonitorOnlyEnforcementMode

A policy enforcement mode in which every action is evaluated and the outcome logged, but no action is blocked, building a baseline behavioural profile.

Responsibility. Runs policies in log-only mode to calibrate thresholds.

Also known as: Monitor mode, Shadow mode, Phase one enforcement

Variant of Policy Enforcement Mode Configuration abstract

When to choose. Choose when first deploying policies, to observe agent behaviour, detect over-triggering or never-triggering policies, and calibrate thresholds before enforcement.
