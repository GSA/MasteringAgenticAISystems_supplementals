Thought Aggregator

Software componentCognitionCognition & Memoryarc:ThoughtAggregator

A cognition component that synthesizes several source thoughts into one new thought with edges from every source, reconciling contradictions and eliminating redundancy.

Responsibility. Merges multiple antecedent thoughts into a single synthesized thought.

Also known as: Aggregation transformation, Thought synthesizer

Design guidance

  • SHOULD synthesize essential insights via an explicit model prompt rather than concatenating source content.
  • SHOULD NOT aggregate near-identical explorations, which yields marginal gain at multiplied token cost.
