Notification Escalation Protocol

Data artifactHuman OversightExperience & Human Oversightarc:NotificationEscalationProtocol

An escalation protocol that informs designated stakeholders that an agent encountered a boundary and how the system responded, without pausing execution.

Responsibility. Alerts stakeholders of boundary events without blocking the agent.

Also known as: Simple escalation

Variant of Escalation Protocol abstract

When to choose. Choose when stakeholders need awareness of a boundary event but the action may proceed (e.g., internal transfers above $10,000 with enhanced logging).
