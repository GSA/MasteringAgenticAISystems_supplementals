AI System Context Record

Data artifactGovernance & ComplianceSafety, Security & Governancearc:AISystemContextRecord

A per-system governance document capturing the operational deployment context, stakeholder analysis, intended and off-label uses, and domain assumptions against which risks and impacts are assessed.

Responsibility. Documents the actual deployment conditions and affected stakeholders of one AI system.

Also known as: Context documentation, Stakeholder analysis, AI management system scope

Design guidance

  • MUST identify all affected parties, including indirectly affected groups and society, not only direct users.
  • SHOULD be re-documented when the same system is deployed into a different context, because context changes the risk profile.
  • SHOULD incorporate technical, legal, ethics and affected-community perspectives.
