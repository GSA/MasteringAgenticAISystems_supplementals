Subdialogue Initiative Controller

Software componentOrchestrationOrchestration & Toolsarc:SubdialogueInitiativeController

A mixed-initiative controller in which the agent temporarily takes limited initiative to ask clarifying questions or correct misunderstandings, then returns control once the uncertainty is resolved.

Responsibility. Opens and closes clarification subdialogues to resolve uncertainty.

Also known as: Subdialogue initiation, Clarifying-question initiative

Variant of Mixed-Initiative Controller abstract

When to choose. Choose when execution hits a specific ambiguity or misunderstanding that a brief clarifying exchange can resolve before control returns to the primary party.
