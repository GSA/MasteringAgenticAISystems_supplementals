Draft Length Controller

Software componentModel ServingModelsarc:DraftLengthController

A runtime control component that tracks speculative acceptance over a sliding window and raises or lowers the draft length K, disabling speculation when acceptance falls below a threshold.

Responsibility. Keeps speculative draft length matched to the observed acceptance rate.

Also known as: Adaptive K adjustment, Dynamic draft length
