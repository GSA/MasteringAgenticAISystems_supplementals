Response Scorer

Software componentObservability & EvaluationObservability & EvaluationVariation point (abstract)arc:ResponseScorer

An abstract evaluation function that scores one agent response against ground truth, policy, or quality criteria and returns a normalized score or pass/fail indicator.

Responsibility. Converts one agent response into a normalized quality score for aggregation.

Also known as: Custom metric, Scoring function, Evaluator

Design guidance

  • SHOULD be implemented as pure functions that accept the response plus test-case context and return a score normalized to 0-1.
  • SHOULD be validated against contrasting examples to confirm it separates good from bad responses.
  • SHOULD correlate with business outcomes; metrics that are easy to measure but do not predict value SHOULD NOT drive decisions.
