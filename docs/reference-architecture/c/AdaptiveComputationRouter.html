Adaptive Computation Router

Software componentCognitionCognition & Memoryarc:AdaptiveComputationRouter

A routing component that skips expensive symbolic reasoning when neural confidence is high on simple cases and invokes full symbolic validation when uncertainty is high.

Responsibility. Routes cases to full symbolic validation according to neural confidence.

Also known as: Confidence-based reasoning depth control
