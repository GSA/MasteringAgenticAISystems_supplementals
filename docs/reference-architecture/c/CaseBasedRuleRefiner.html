Case-Based Rule Refiner

Software componentModel AdaptationModelsarc:CaseBasedRuleRefiner

A rule learner that analyses accumulated misclassified cases to propose added conditions or new rules that correct an existing expert rule set.

Responsibility. Proposes corrective refinements to existing rules from their failure cases.

Also known as: Rule refinement algorithm

Variant of Rule Learner abstract

When to choose. Choose when an expert-provided initial rule set exists and should be refined from accumulated cases where its decisions proved wrong.
