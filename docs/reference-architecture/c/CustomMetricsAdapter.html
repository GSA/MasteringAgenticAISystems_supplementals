Custom Metrics Adapter

Software componentInfrastructureInfrastructurearc:CustomMetricsAdapter

A bridge that exposes collected application metrics through the container orchestrator's metrics API so autoscalers can scale on inference-specific signals.

Responsibility. Makes monitoring-system metrics consumable by the orchestrator's autoscaler.

Also known as: Custom metrics API, Custom metrics exporter
