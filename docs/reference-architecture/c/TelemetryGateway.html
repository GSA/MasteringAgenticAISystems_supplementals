Telemetry Gateway

Software componentObservability & EvaluationObservability & Evaluationarc:TelemetryGateway

An intermediate telemetry aggregation service that receives traces from many sources, buffers them during backend unavailability, applies sampling, enriches them with environment metadata, and forwards them to backends.

Responsibility. Aggregates and forwards trace telemetry from many agents to observability backends.

Also known as: OpenTelemetry Collector, Trace aggregation point

Design guidance

  • MAY be omitted in development, with agents exporting directly to the backend.
  • SHOULD be used in production to buffer traces, implement sampling, and enrich traces with environment metadata.
