Replication and Sharding Configuration

Data artifactInfrastructureInfrastructurearc:ReplicationShardingConfig

A configuration declaring a vector collection's shard count, replication factor and cluster join list.

Responsibility. Specifies how collection data is partitioned and replicated across cluster nodes.
