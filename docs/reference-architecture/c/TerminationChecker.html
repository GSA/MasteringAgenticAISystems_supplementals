Termination Checker

Software componentOrchestrationOrchestration & Toolsarc:TerminationChecker

A control component that evaluates end conditions, such as reviewer approval or a maximum round count, after each message to decide whether a multi-agent conversation stops.

Responsibility. Decides after each message whether a multi-agent conversation has reached an end condition.

Also known as: Termination check function, End-condition validator
