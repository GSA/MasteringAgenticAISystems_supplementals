Active Learning Sampler

Software componentModel AdaptationModelsarc:ActiveLearningSampler

A sampling component that selects production interactions for detailed human review, prioritizing high-uncertainty cases and diverse examples from underrepresented scenarios.

Responsibility. Chooses which conversations warrant human labeling to maximize training value.
