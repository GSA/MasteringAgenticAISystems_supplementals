Design guidance

  • SHOULD centralize and retain production traces so incidents can be investigated after local logs roll over.
  • SHOULD support querying runs by latency range, error status and cost so slow, failing and expensive executions can be isolated (Ref8.01).

Quantitative guidance

As stated by the sources; verify before use.

  • Persistent storage typically retains a 10-20% sample of reasoning traces for ongoing analysis (Ch3.9).
