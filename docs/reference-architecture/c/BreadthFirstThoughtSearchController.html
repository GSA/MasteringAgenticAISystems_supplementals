Breadth-First Thought Search Controller

Software componentCognitionCognition & Memoryarc:BreadthFirstThoughtSearchController

A tree search controller that expands the tree level by level, retaining only the b best-scored states at each depth before generating the next level.

Responsibility. Retains a fixed breadth of top-scored states per depth level.

Also known as: BFS, Beam search (breadth b), Breadth-limited search

Variant of Tree Search Controller abstract

When to choose. Choose when trees are shallow (typically 2-4 steps), evaluation is uncertain so hedging across branches is valuable, or multiple solutions should be compared.

Quantitative guidance

As stated by the sources; verify before use.

  • Memory grows as O(breadth x depth) (Ch5.2).
  • Worked example: Game of 24 with b=3, k=5, max depth 3 (Ch5.2).
