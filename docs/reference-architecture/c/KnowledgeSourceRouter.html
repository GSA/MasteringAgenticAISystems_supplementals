Knowledge Source Router

Software componentKnowledge & DataKnowledge & Dataarc:KnowledgeSourceRouter

A routing component that determines which of several heterogeneous knowledge sources (databases, spreadsheets, document repositories, email archives) should be searched for a given information need.

Responsibility. Selects the knowledge sources to query for each sub-question.
