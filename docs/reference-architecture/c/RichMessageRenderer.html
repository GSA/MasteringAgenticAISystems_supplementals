Rich Message Renderer

Software componentExperienceExperience & Human Oversightarc:RichMessageRenderer

A presentation component that renders structured in-chat elements (code blocks, tables, images, charts, interactive widgets) inline within the conversation stream as mini-interfaces.

Responsibility. Displays structured agent output inside the conversation without redirecting users to external dashboards.

Also known as: In-chat elements, Embedded chart widget, Rich in-chat components
