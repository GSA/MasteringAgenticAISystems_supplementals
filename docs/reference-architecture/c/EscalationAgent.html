Design guidance

  • SHOULD evaluate criteria beyond model confidence (sensitive content, authority limits, repeat escalations).
  • SHOULD publish escalation events rather than call each downstream consumer directly.
  • SHOULD escalate out-of-competence scenarios to specialist agents or human experts rather than produce plausible but incorrect answers.
  • SHOULD prioritise escalation of frustrated customers detected by sentiment analysis.
  • MUST honour explicit user requests for a human agent immediately.
  • SHOULD escalate on low confidence below defined thresholds and on repeated clarification failures.
  • MUST provide an easy escalation path to avoid trapped-user syndrome.
  • SHOULD escalate emotionally charged interactions regardless of confidence, and repeat contacts from the same customer within short timeframes.

Quantitative guidance

As stated by the sources; verify before use.
