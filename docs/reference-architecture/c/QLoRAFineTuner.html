QLoRA Fine-Tuner

Software componentModel AdaptationModelsarc:QLoRAFineTuner

A LoRA fine-tuning pipeline that quantizes the frozen base model to 4-bit precision while keeping trainable adapters at full precision.

Responsibility. Fine-tunes adapters over a quantized frozen base model.

Also known as: Quantized Low-Rank Adaptation
