Thought Exploration Controller

Software componentCognitionCognition & MemoryVariation point (abstract)arc:ThoughtExplorationController

An abstract cognition controller that maintains multiple candidate intermediate thoughts, deciding which to expand, evaluate, prune or combine and when to terminate a deliberate reasoning episode.

Responsibility. Steers exploration over a structure of candidate thoughts toward a solution.

Also known as: Deliberate reasoning controller, Search controller

Design guidance

  • SHOULD be applied only when exploration and backtracking demonstrably help (fatal early mistakes, alternatives worth comparing, informative intermediate evaluation); default to Chain-of-Thought otherwise.
  • SHOULD fall back to a simpler reasoning approach when a per-query token budget is exceeded before a solution is found.
  • SHOULD be benchmarked on tokens-per-correct-solution against CoT and alternative structures before deployment.
