Cache Invalidation Policy

Data artifactTools & IntegrationOrchestration & ToolsVariation point (abstract)arc:CacheInvalidationPolicy

An abstract configuration deciding when cached tool results become stale and must be refreshed, balancing result freshness against latency and cost savings.

Responsibility. Determines when cached tool results are invalidated.

Also known as: Cache freshness policy

Variants

VariantWhen to choose
Event-Based Cache Invalidation PolicyChoose when the upstream source can signal publication of updates, so freshness need not wait for a TTL.
Time-Based Cache Invalidation PolicyChoose when the source updates on a known schedule and no change notifications are available.
