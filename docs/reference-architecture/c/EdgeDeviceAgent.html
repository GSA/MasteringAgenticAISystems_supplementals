Edge Device Agent

Software componentInfrastructureInfrastructurearc:EdgeDeviceAgent

An on-device management agent that applies updates, maintains the local version manifest, buffers results while offline and reports version and status telemetry when connectivity permits.

Responsibility. Represents the device to central fleet management.

Also known as: Device-side agent, Edge node agent, Edge Sync Agent
