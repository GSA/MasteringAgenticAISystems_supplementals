Memory · Data store

Graph Reasoning State Store

Data storeMemoryCognition & Memoryarc:GraphReasoningStateStore

Working-memory store holding all generated thoughts of a reasoning episode as DAG vertices with dependency edges, scores and transformation history, queryable and serializable.

Responsibility. Maintains the explicit reasoning DAG for the current problem.

Also known as: Graph Reasoning State (GRS), Reasoning graph, System non-parametric short-term memory

Variant of Working Memory Buffer abstract

When to choose. Choose when thoughts need multiple parents so independent reasoning chains can merge.

Design guidance

  • MUST remain a directed acyclic graph; reconsideration is modelled as a new vertex or a refinement self-loop, never a backward edge.
  • SHOULD be serializable at any point to support pause, resume and distributed work on subgraphs.
