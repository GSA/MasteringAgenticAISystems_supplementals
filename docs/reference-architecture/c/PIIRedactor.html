PII Redactor

Software componentSafety & SecuritySafety, Security & Governancearc:PIIRedactor

A guardrail that detects personally identifiable information in agent responses and masks or removes it before delivery.

Responsibility. Prevents personal data from leaking in agent output.

Also known as: Privacy guardrail, Privacy validation, Filter guardrail, Sensitive data detection, HIPAA PHI filter, Memorized-PII output filter

Design guidance

  • SHOULD be added or strengthened when production feedback reports PII leakage, with each incident converted into a regression test case.
  • SHOULD detect and redact personally identifiable information during transformation, before data is stored in the knowledge base.
  • MUST redact PII from logs or encrypt logs at rest with access controls.
