Design guidance

  • SHOULD emit traces via standardized protocols so the backend can be selected per team or environment.
  • SHOULD export agent profiling metrics over an OpenTelemetry-compatible path so agent quality metrics appear alongside application metrics in one dashboard.
  • SHOULD batch spans before export rather than exporting each span individually, reducing network overhead.
  • SHOULD batch completed spans before export to reduce network overhead.
