Memory Link Generator

Software componentMemoryCognition & Memoryarc:MemoryLinkGenerator

A memory component that creates connections between related stored memories, giving memory a navigable structure from one memory to related concepts.

Responsibility. Links related memories to enable associative navigation.

Also known as: Link generation, Episode linker

Design guidance

  • SHOULD link consolidated episodes to related semantic knowledge, procedural workflows and prior episodes to enable multi-hop retrieval.
  • SHOULD encode causal structure (which actions led to which outcomes) to support causal retrieval.

Quantitative guidance

As stated by the sources; verify before use.
