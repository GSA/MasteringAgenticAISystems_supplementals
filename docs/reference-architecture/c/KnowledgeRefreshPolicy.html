Knowledge Refresh Policy

Data artifactOrchestrationOrchestration & ToolsVariation point (abstract)arc:KnowledgeRefreshPolicy

An abstract configuration choosing whether a pipeline run processes only the delta since the last successful run or reprocesses the full corpus.

Responsibility. Determines the scope of data a pipeline run reprocesses.

Also known as: Incremental vs full update mode

Variants

VariantWhen to choose
Full Refresh PolicyChoose for initial population, after chunking or schema parameter changes, or to remediate quality issues from earlier permissive filters.
Incremental Refresh PolicyChoose as the default for scheduled (hourly or daily) runs that keep the knowledge base fresh.
