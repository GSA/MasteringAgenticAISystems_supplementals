Reasoning Strategy Router

Software componentCognitionCognition & Memoryarc:ReasoningStrategyRouter

A routing component that sends each query either to single-path chain-of-thought reasoning or to multi-sample self-consistency according to estimated difficulty, stakes and cost policy.

Responsibility. Selects the reasoning strategy tier for each query.

Also known as: Dynamic reasoning router

Design guidance

  • SHOULD reserve self-consistency for complex multi-step reasoning tasks with definable correct answers, base accuracy below ~85-90%, and path-specific rather than systematic errors.
  • SHOULD NOT apply self-consistency to factual retrieval, single-dominant-path, open-ended generation or summarisation tasks.

Quantitative guidance

As stated by the sources; verify before use.

  • General customer-support queries gained only 0.8% accuracy at 5x cost; the feature was removed after a 2-month trial (Ch5.3).
  • EPI cost-sensitivity slope m = -361.09 for Self-Consistency vs -177.22 for CoT (Ch5.3).
