Role-Based Task Orchestrator

Software componentOrchestrationOrchestration & Toolsarc:SequentialTaskCoordinator

A workflow orchestrator that executes predefined tasks assigned to role-defined agents, either sequentially with task-output context inheritance or hierarchically through a manager agent that delegates and reviews.

Responsibility. Executes role-assigned tasks in sequential or hierarchical process order.

Also known as: Crew process, Role-based team orchestration, Sequential process, Sequential crew, Task pipeline, Role-Based Task Orchestrator, Sequential agent handoffs

Variant of Multi-Agent Coordinator abstract

When to choose. Choose when the workflow mirrors an organisational structure with clear roles, predictable task dependencies and sequential or hierarchical delegation; avoid for dynamic workflows needing conditional branching or iterative self-correction loops.

Design guidance

  • SHOULD NOT encode iteration into task descriptions for refinement loops; such workflows belong in a graph-based orchestrator.
  • SHOULD be used only when task order is fixed; it offers no way to request additional upstream work without re-running the workflow.

Quantitative guidance

As stated by the sources; verify before use.

  • Supply chain: three sequential agents consumed 9,200 tokens and 15 API calls per order through context restatement (Ch3.10).
