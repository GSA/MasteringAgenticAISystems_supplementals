Question Decomposer

Software componentCognitionCognition & Memoryarc:QuestionDecomposer

A cognition component that breaks a complex multi-hop question into an ordered set of sub-questions, each representing a distinct information need.

Responsibility. Decomposes a multi-hop question into sub-questions.

Also known as: Question decomposition, Query decomposer, LLM-powered query decomposition, Sub-query generator

Design guidance

  • SHOULD make decomposition explicit so failures can be localised to decomposition, sub-question retrieval, or synthesis.
  • SHOULD bypass decomposition for simple queries using query complexity heuristics (word count, question structure).
  • SHOULD use low temperature to keep decomposition consistent across similar queries.
  • SHOULD measure whether accuracy gains justify the added decomposition and synthesis LLM calls before production deployment.

Quantitative guidance

As stated by the sources; verify before use.
