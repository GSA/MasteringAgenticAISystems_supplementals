Gossip Membership Service

Software componentInfrastructureInfrastructurearc:GossipMembershipService

A cluster component that discovers peer nodes from a join list and exchanges membership and heartbeat messages by gossip to detect node failures within seconds.

Responsibility. Maintains cluster membership and detects failed nodes.

Also known as: Gossip protocol
