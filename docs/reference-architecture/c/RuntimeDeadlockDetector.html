Runtime Deadlock Detector

Software componentOrchestrationOrchestration & Toolsarc:RuntimeDeadlockDetector

A runtime monitor that periodically scans active agents for circular wait conditions and flags deadlocks after they have formed.

Responsibility. Detects circular waits among running agents.

Also known as: Runtime deadlock detection

Variant of Deadlock Controller abstract

When to choose. Choose only when dependencies cannot be declared in advance; it requires periodic scanning of active agents and lets a deadlock persist until the next scan detects it.
