Least-Privilege Permission Set

Data artifactSafety & SecuritySafety, Security & Governancearc:LeastPrivilegePermissionSet

A declarative grant of the minimum object-, operation-, field- and record-level permissions an agent identity needs, starting from a default of zero access.

Responsibility. Specifies exactly which data objects, operations, fields and records an agent may touch.

Also known as: Granular permission set, Organization-Wide Default + sharing rules, Least-privilege IAM role

Design guidance

  • MUST start with zero access and incrementally grant only permissions the task requires.
  • MUST NOT assign administrative, 'Modify All Data' or cloned administrator profiles to agents.
