Output Format Specification

Data artifactCognitionCognition & Memoryarc:OutputResponseSchema

An instruction artifact defining the structure an agent's responses must follow (e.g., structured markdown or fields) so outputs are consistent and machine-processable downstream.

Responsibility. Prescribes the required structure of agent outputs.

Also known as: Output specification, Format specification, Response schema, Format and constraint rules, Structured output format

Design guidance

  • SHOULD be included in agent prompts; its removal degrades both accuracy and output consistency.
  • SHOULD prefer structured output formats (e.g., JSON schemas with required components) over free-form text to prevent verbosity.

Quantitative guidance

As stated by the sources; verify before use.

  • Ablating format specifications typically degrades accuracy and output consistency 10-20% (Ch3.7).
  • Using a structured output format saves 15-20% of tokens (Ref8.05).
