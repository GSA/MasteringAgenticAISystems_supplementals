Action Suggestion Engine

Software componentExperienceExperience & Human Oversightarc:ActionSuggestionEngine

An inference component that analyses user selection, work context, and recent action history to predict and rank the next actions or follow-up questions a user likely wants.

Responsibility. Predicts contextually relevant next actions for the user.

Also known as: AI suggestions, Agent intelligence layer, Related-question suggester, Recommendation engine, Proactive suggestion generator, Anticipatory curation

Design guidance

  • MUST keep proactive suggestions aligned with users' stated goals rather than exploiting momentary weaknesses.
