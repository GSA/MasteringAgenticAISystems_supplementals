Multi-Agent Policy Learner

Software componentModel AdaptationModelsVariation point (abstract)arc:MultiAgentPolicyLearner

An abstract policy learner that trains policies for multiple agents learning simultaneously in a shared cooperative, competitive, or mixed-motive environment.

Responsibility. Trains multiple agents' policies under mutual non-stationarity.

Also known as: Multi-agent reinforcement learning
