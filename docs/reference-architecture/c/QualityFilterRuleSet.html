Quality Filter Rule Set

Data artifactKnowledge & DataKnowledge & Dataarc:QualityFilterRuleSet

A configuration of document quality thresholds and reference lists, such as minimum and maximum length, minimum word count and boilerplate phrases, applied by a quality filter.

Responsibility. Defines the acceptance thresholds for document quality validation.

Also known as: Quality filters config, Boilerplate dictionary, Curation filter thresholds

Relationships

configures structural

  • Document Quality Filter Ch6.3A Ch7.5
  • Perplexity Filter Ch7.5

Design guidance

  • MUST be tuned empirically; no universal threshold (e.g., min_words 50 vs. 100) is correct across domains.
  • SHOULD tolerate higher perplexity and use higher deduplication similarity thresholds for spoken-language transcripts than for formal web text.
