Perplexity Reference Model

Model assetModel AdaptationModelsarc:PerplexityReferenceModel

A generative language model trained on relatively clean text whose average per-token log-likelihood is used to score how typical a document is.

Responsibility. Provides per-document perplexity scores to the perplexity filter.

Also known as: Reference language model
