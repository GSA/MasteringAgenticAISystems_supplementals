Hosted Embedding API Service

Software componentKnowledge & DataKnowledge & Dataarc:HostedEmbeddingAPIService

An embedding service consumed from a third-party provider's hosted API, billed per token, with the provider operating models and infrastructure.

Responsibility. Returns embeddings for submitted texts from a provider-operated model endpoint.

Also known as: Embedding API, Commercial embedding API

Variant of Embedding Service abstract

When to choose. Choose when building initial development or baseline systems, when no data-sovereignty or air-gap constraint applies, and when per-token API cost is acceptable for the query volume.
