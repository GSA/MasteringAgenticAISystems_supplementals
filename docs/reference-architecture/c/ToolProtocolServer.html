Tool Protocol Server

InterfaceTools & IntegrationOrchestration & Toolsarc:ToolProtocolServer

A standard protocol endpoint that exposes tools and external resources to agents with consistent access patterns across diverse tools.

Responsibility. Exposes tools via a standard protocol.

Also known as: MCP server, Model Context Protocol

Design guidance

  • SHOULD be used for infrastructure access only; it MUST NOT be relied on to define delegation, task ownership or orchestration.
  • MAY run in server mode to publish workflow functions as services and in client mode to consume tools from remote servers.
  • SHOULD use established protocols (MCP, HTTP, gRPC) for tool discovery and agent communication rather than custom solutions.
