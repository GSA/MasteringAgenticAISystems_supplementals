Approval Queue API

InterfaceHuman OversightExperience & Human Oversightarc:ApprovalQueueAPI

A service interface exposing endpoints to list an approver's pending requests prioritized by risk and time remaining, retrieve request context, and submit approve/reject decisions with reasons.

Responsibility. Provides programmatic and UI access to pending approvals and decisions.

Also known as: /approvals/decide endpoint, Approval API
