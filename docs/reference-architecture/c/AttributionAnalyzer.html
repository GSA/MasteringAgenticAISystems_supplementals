Attribution Analyzer

Software componentObservability & EvaluationObservability & Evaluationarc:AttributionAnalyzer

An interpretability component that computes how much each input token or evidence component causally influenced a model output, producing attribution maps.

Responsibility. Attributes model outputs to the input tokens that influenced them.

Also known as: Attribution analysis, Post-hoc feature attribution, Interpretability analyzer, Feature importance, Saliency map generator, SHAP explainer, LIME explainer
