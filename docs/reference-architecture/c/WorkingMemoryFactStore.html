Memory · Data store

Working Memory Fact Store

Data storeMemoryCognition & Memoryarc:WorkingMemoryFactStore

A session-scoped store of case facts, derived intermediate conclusions with certainty factors, and goal status that rules pattern-match against during one reasoning session.

Responsibility. Holds the situation-specific facts and reasoning state for the current case until the session ends.

Also known as: Working memory, Fact base

Design guidance

  • MUST reset between reasoning sessions so one customer's or patient's facts cannot contaminate another's reasoning.
  • SHOULD index facts for fast pattern lookup as the fact set grows.
  • MAY persist facts across conversation turns within one session.
