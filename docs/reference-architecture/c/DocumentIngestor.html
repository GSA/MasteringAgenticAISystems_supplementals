Document Ingestor

Software componentKnowledge & DataKnowledge & Dataarc:DocumentIngestor

A component that extracts text, tables and chart values from source documents such as PDFs into structured data.

Responsibility. Extracts content from source documents.

Design guidance

  • SHOULD detect image pages in PDFs and separate them from extracted document text for modality-specific processing.
  • SHOULD handle both native digital PDFs and scanned images requiring OCR.

Quantitative guidance

As stated by the sources; verify before use.

  • 12% of one healthcare knowledge base had corrupted medical tables from PDF extraction errors (Ch6.4 case study).
