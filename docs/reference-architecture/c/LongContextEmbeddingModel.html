Long-Context Embedding Model

Model assetKnowledge & DataKnowledge & Dataarc:LongContextEmbeddingModel

A dense embedding model with a very large input context and bidirectional attention, able to embed long technical, legal or research documents with little or no chunking.

Responsibility. Encodes long documents into single coherent embeddings capturing long-range dependencies.

Variant of Text Embedding Model abstract

When to choose. Choose for enterprise deployments processing long technical documents, contracts or papers that routinely exceed 8,000 tokens, typically self-hosted for data sovereignty.
