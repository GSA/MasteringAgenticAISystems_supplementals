Quantitative guidance

As stated by the sources; verify before use.

  • Compute saturation: GPU util >90%, memory low -> more GPU capacity or smaller models; memory saturation: memory >90%, compute low -> smaller batches or memory-efficient attention; throughput saturation: high queue time, moderate util -> more GPU instances; external: low util and low queue time -> network, CPU preprocessing or database (Ch8.1).
