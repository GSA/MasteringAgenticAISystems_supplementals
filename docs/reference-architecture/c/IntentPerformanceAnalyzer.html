Intent Performance Analyzer

Software componentObservability & EvaluationObservability & Evaluationarc:IntentPerformanceAnalyzer

An analysis component that aggregates conversation metrics per intent category to reveal categories with elevated failure, low confidence or rising escalation rates.

Responsibility. Identifies which intent categories need targeted improvement.
