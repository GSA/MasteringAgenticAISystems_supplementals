Vector Store gRPC API

InterfaceKnowledge & DataKnowledge & Dataarc:VectorStoreGRPCAPI

A binary-protocol vector store interface using HTTP/2 multiplexing for lower latency and higher throughput under load.

Responsibility. Serves vector store requests over gRPC.

Variant of Vector Store Query API abstract

When to choose. Choose when query volume exceeds ~100 requests per second or real-time applications need the lowest latency.
