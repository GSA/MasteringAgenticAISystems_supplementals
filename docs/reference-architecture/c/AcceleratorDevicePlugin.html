GPU Device Plugin

Software componentInfrastructureInfrastructurearc:AcceleratorDevicePlugin

A node-level agent that advertises GPU devices, including hardware partitions, to the container orchestrator as schedulable resources.

Responsibility. Makes GPUs visible and allocatable to container scheduling.

Also known as: NVIDIA device plugin for Kubernetes, GPU device plugin, GPU Device Plugin
