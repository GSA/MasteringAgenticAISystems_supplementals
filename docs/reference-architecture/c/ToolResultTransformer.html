Tool Result Transformer

Software componentTools & IntegrationOrchestration & Toolsarc:ToolResultTransformer

An adapter that converts one tool's output into the data types, structure, and units required by the next tool's input schema in a chain.

Responsibility. Transforms intermediate tool outputs to match downstream tool input requirements.

Also known as: Format transformation step

Design guidance

  • MUST ensure a tool's output format matches the next tool's input requirements, transforming types, structures, or units as needed.
  • SHOULD transform automatically at tool boundaries only when formats differ predictably (e.g., '$142.50' string to 142.50 float).
