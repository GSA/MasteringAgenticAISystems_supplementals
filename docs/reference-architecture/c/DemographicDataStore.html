Demographic Data Store

Data storeGovernance & ComplianceSafety, Security & Governancearc:DemographicDataStore

A store of sensitive protected-attribute data (race, gender, age, disability) collected solely for fairness analysis, segregated from production systems.

Responsibility. Holds consented demographic attributes used only for fairness monitoring and auditing.

Also known as: Segregated fairness data store, Protected attribute store
