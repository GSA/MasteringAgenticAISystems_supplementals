Workflow State Graph

Data artifactOrchestrationOrchestration & Toolsarc:WorkflowStateGraph

A declarative workflow definition specifying nodes (states), edges and conditional edges (transitions), and entry point, kept separate from the state schema it operates on.

Responsibility. Declares the permissible states and transitions of a workflow.

Also known as: State machine definition, Logic tree, Graph structure, Decision tree graph, Graph of nodes, static edges and conditional edges

Design guidance

  • SHOULD define routing on edges separately from node functions so control flow is explicit and analyzable.
  • SHOULD be the source from which workflow visualisations and architecture documentation are generated, keeping them synchronised with code.
  • SHOULD use static edges for deterministic transitions and conditional edges only at decision points.
  • SHOULD tag workflow nodes with authority metadata ('human approval required', 'autonomous if confidence exceeds threshold', 'always escalate to human') so decision provenance is transparent.
