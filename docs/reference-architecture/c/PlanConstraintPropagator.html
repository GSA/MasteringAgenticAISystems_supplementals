Plan Constraint Propagator

Software componentCognitionCognition & Memoryarc:PlanConstraintPropagator

A planning component that incrementally checks ordering, causal-link, resource, temporal and state constraints after each decomposition step and forward-checks preconditions to trigger early backtracking.

Responsibility. Detects constraint inconsistencies in the task network as early as possible.

Also known as: Constraint propagation, Forward checker, Plan validity checker
