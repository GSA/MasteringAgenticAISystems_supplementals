RAG Evaluator

Software componentObservability & EvaluationObservability & Evaluationarc:RAGEvaluator

An automated evaluation component that scores retrieval-augmented answers on faithfulness, answer relevance, context precision, and context recall.

Responsibility. Measures retrieval and grounding quality of RAG outputs.

Also known as: Retrieval Augmented Generation Assessment, RAGAS evaluator

Design guidance

  • SHOULD prioritize recall over precision in multi-hop retrieval, since missing documents are more damaging than irrelevant ones.
  • SHOULD be the starting evaluator for RAG-based workflows.
  • SHOULD monitor accuracy across both retrieval and fine-tuned generation in hybrid systems (Ref6.01).
