Decision Telemetry Event Schema

Data artifactObservability & EvaluationObservability & Evaluationarc:DecisionTelemetryEventSchema

A structured data contract for the per-request telemetry event an agent emits at decision points, carrying request ID, timestamp, decision type, confidence score, latency measurements, tools invoked and outcome.

Responsibility. Defines the fields every agent decision event must carry for aggregation and anomaly detection.

Also known as: Structured telemetry event
