Transparency Report

Data artifactGovernance & ComplianceSafety, Security & Governancearc:TransparencyReport

A periodic, often public, report aggregating AI governance information: deployed system inventory, fairness and demographic impacts, incidents and resolutions, documentation completeness and framework compliance.

Responsibility. Communicates the organization's aggregate AI governance posture to external stakeholders.

Also known as: Public transparency report, Enforcement report
