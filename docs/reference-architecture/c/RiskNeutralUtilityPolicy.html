Risk-Neutral Utility Policy

Data artifactCognitionCognition & Memoryarc:RiskNeutralUtilityPolicy

A risk-attitude configuration using linear utility u(x) = ax + b, so expected utility equals expected value.

Responsibility. Configures constant marginal utility, indifferent between certainty and equal-expected-value gambles.

Also known as: Linear utility

Variant of Risk Attitude Policy abstract

When to choose. Choose only for small-stakes decisions with minimal outcome variance or explicitly risk-neutral domains aggregated across many independent events.
