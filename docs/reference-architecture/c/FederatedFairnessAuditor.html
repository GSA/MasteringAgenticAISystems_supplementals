Federated Fairness Auditor

Software componentGovernance & ComplianceSafety, Security & Governancearc:FederatedFairnessAuditor

A privacy-preserving fairness auditor that combines locally computed fairness statistics from multiple institutions into global fairness metrics without centralizing raw records.

Responsibility. Aggregates institution-local fairness statistics into cross-institutional fairness metrics.

Variant of Privacy-Preserving Fairness Auditor abstract

When to choose. Choose when several institutions (hospital networks, bank consortia) individually lack the data volume or diversity for statistically powerful bias detection but cannot centralize raw data.
