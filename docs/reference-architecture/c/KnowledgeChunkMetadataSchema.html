Knowledge Chunk Metadata Schema

Data artifactKnowledge & DataKnowledge & Dataarc:KnowledgeChunkMetadataSchema

A data contract for semantic-memory chunk metadata recording source document, chunk position, last-updated timestamp, temporal validity period, version and source type.

Responsibility. Specifies the provenance and temporal metadata every indexed knowledge chunk must carry.

Also known as: Temporal metadata tagging, Chunk provenance metadata, Document collection schema, Vector collection schema, Temporal markers

Design guidance

  • MUST tag every knowledge chunk with temporal metadata so retrieval can filter or rank by validity period.
  • SHOULD record source document and chunk position so retrieved chunks can be ordered, reassembled and cited.
  • SHOULD be created idempotently so initialization can run on every startup or deployment.
  • MUST carry publication date, last-modified timestamp and validity period for every ingested document to enable freshness filtering and recency ranking.
