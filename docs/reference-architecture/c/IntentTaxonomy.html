Intent Taxonomy

Data artifactOrchestrationOrchestration & Toolsarc:IntentTaxonomy

A catalogue of discrete user-intent categories, aligned with actual user needs, each mapped to a distinct handling pathway.

Responsibility. Defines the intent categories an intent classifier may assign and the pathway each maps to.

Also known as: Intent framework, Intent categories
