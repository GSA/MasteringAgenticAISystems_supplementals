State-Space Graph

Data storeCognitionCognition & Memoryarc:StateSpaceGraph

A persistent graph of reachable states (e.g., grid cells, intersections, waypoints) and weighted transitions whose edge costs and blocked edges planners search over.

Responsibility. Holds the navigable states and current edge costs used for path search.

Also known as: Navigation mesh, Road network graph, Search graph, Map
