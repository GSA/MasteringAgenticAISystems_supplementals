Unsolicited Reporting Controller

Software componentOrchestrationOrchestration & Toolsarc:UnsolicitedReportingController

A mixed-initiative controller in which the agent only reports critical information asynchronously as it arises, without blocking work or requiring acknowledgment, leaving all initiative with the recipient.

Responsibility. Delivers non-blocking informational reports while the recipient retains initiative.

Also known as: Unsolicited reporting

Variant of Mixed-Initiative Controller abstract

When to choose. Choose when one party holds information the other needs but should not control when or how it is acted upon; the recipient keeps full initiative.
