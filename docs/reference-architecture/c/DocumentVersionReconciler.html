Document Version Reconciler

Software componentKnowledge & DataKnowledge & Dataarc:DocumentVersionReconciler

A component that uses document identifiers and version timestamps to archive superseded or expired versions and ensure each unique document appears only once in the active corpus.

Responsibility. Keeps only the latest valid version of each document active.

Also known as: Temporal consistency validation, Version control check
