Trace Error Classifier

Software componentObservability & EvaluationObservability & Evaluationarc:TraceErrorClassifier

An analysis component that classifies error events in traces as expected (handled by designed recovery such as retries or fallbacks) or unexpected (unhandled or recovery-exhausting).

Responsibility. Separates handled transient errors from genuine failures in trace data.

Also known as: Expected vs. unexpected error classification

Design guidance

  • SHOULD treat errors caught and resolved by designed recovery mechanisms as expected, and only unhandled or recovery-exhausting failures as defects.
  • SHOULD distinguish transient failures (network timeouts) from permanent failures (invalid parameters).
