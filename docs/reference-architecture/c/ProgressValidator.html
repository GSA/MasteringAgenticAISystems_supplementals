Progress Validator

Software componentCognitionCognition & Memoryarc:ProgressValidator

A cognition component that checks each iteration's tool results against success criteria to decide whether the workflow advanced or strategy must change.

Responsibility. Judges whether each iteration made progress toward the goal.
