Cache-Aware Inference Router

Software componentModel ServingModelsarc:CacheAwareInferenceRouter

A load balancer for inference replicas that selects the target instance using model-serving state such as KV-cache contents, per-instance queue length, accelerator load and loaded LoRA adapters, plus request priority and cost.

Responsibility. Routes each inference request to the instance best able to serve it quickly.

Also known as: Model-aware routing, Inference gateway

Variant of Load Balancer abstract

When to choose. Choose when inference replicas hold non-equivalent state (KV caches, loaded adapters) and multi-agent routing must track which pods cache which contexts.
