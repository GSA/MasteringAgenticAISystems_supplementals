Tool Parameter Normalizer

Software componentTools & IntegrationOrchestration & Toolsarc:ToolParameterNormalizer

A pre-invocation component that maps user or domain terminology variants extracted from requests to canonical tool parameter values before the tool call is executed.

Responsibility. Normalises extracted argument values to the canonical vocabulary a tool expects.

Also known as: Entity Normalizer, Parameter normalization, Entity canonicalization
