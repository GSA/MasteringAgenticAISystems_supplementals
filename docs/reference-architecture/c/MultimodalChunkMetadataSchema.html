Multimodal Chunk Metadata Schema

Data artifactKnowledge & DataKnowledge & Dataarc:MultimodalChunkMetadataSchema

A data contract for chunk metadata recording source modality flag, original asset reference, page/section, timestamps, speaker, language, confidence, and extracted tables.

Responsibility. Defines the provenance and filter fields every indexed multimodal chunk carries.

Also known as: Modality metadata, Chunk metadata
