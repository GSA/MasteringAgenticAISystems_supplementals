Load Balancing Policy

Data artifactInfrastructureInfrastructurearc:LoadBalancingPolicy

A declarative configuration selecting the balancing algorithm, per-replica weights, health-check coupling, metric TTLs and fallback behaviour used by a load balancer.

Responsibility. Specifies how a load balancer chooses among replicas.
