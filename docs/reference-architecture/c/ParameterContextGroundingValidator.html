Parameter Context Grounding Validator

Software componentSafety & SecuritySafety, Security & Governancearc:ParameterContextGroundingValidator

A pre-execution gate that checks tool parameters for consistency with conversation state, explicit user constraints, resolved temporal references and stable entity references.

Responsibility. Ensures tool parameters reflect the latest conversational intent and constraints.

Also known as: Context Grounding Validator, Consistency checks, Range checks, State consistency verification

Design guidance

  • SHOULD flag invocations that contradict established context unless the agent explicitly confirmed a change with the user.
  • SHOULD enforce domain-sensible bounds on numeric parameters beyond their syntactic type.
