Chart Data Extractor

Software componentKnowledge & DataKnowledge & Dataarc:ChartDataExtractor

An image-to-text grounder that converts charts, plots, graphs and tables into linearized tables preserving exact values and structure.

Responsibility. Extracts structured numeric data from chart images as linearized tables.

Also known as: Chart-to-table linearizer, Chart linearization

Variant of Image-to-Text Grounder abstract

When to choose. Choose for information-dense images (charts, plots, graphs, tables) where users need exact figures and computation, e.g., financial or benchmark charts.

Design guidance

  • SHOULD combine the linearized table with a natural-language summary as searchable metadata, enabling conceptual and precise numerical queries.
  • SHOULD store the raw table in chunk metadata so answers can reference exact values without re-extracting from the image.
