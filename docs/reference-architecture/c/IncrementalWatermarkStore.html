Incremental Watermark Store

Data storeOrchestrationOrchestration & Toolsarc:IncrementalWatermarkStore

A persistent record of the last successful extraction timestamp of a pipeline, used to bound the next incremental extraction window.

Responsibility. Remembers where the last successful run ended so the next run processes only the delta.

Also known as: ETL state file, High-water mark, Last extraction timestamp state

Design guidance

  • MUST update the watermark only after a run loads successfully, guaranteeing at-least-once processing.
  • SHOULD fall back to a configured lookback window (e.g., 24 hours) on first run when no state exists.
  • SHOULD write state atomically so partial writes never corrupt it.
