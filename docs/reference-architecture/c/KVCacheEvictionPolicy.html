KV Cache Eviction Policy

Data artifactModel ServingModelsVariation point (abstract)arc:KVCacheEvictionPolicy

An abstract policy deciding which requests' KV caches to evict or defer when cache demand exceeds available memory.

Responsibility. Selects KV-cache victims under memory pressure.

Variants

VariantWhen to choose
Cost-Aware Hybrid KV Cache Eviction PolicyChoose in production when recency, priority and recomputation cost must be balanced together.
FIFO KV Cache Eviction PolicyChoose when all requests have similar priority.
LRU KV Cache Eviction PolicyChoose for interactive sessions where recent activity signals continued engagement and idle sessions can be suspended.
Priority KV Cache Eviction PolicyChoose when requests carry differentiated SLAs (e.g., premium versus free tier).
