In-Store Vectorizer

Software componentKnowledge & DataKnowledge & Dataarc:InStoreVectorizer

A vector store module that automatically calls an external embedding provider to vectorize raw text on insert and on query when no vector is supplied.

Responsibility. Generates embeddings inside the vector store for objects submitted without vectors.

Also known as: Built-in vectorization module, Vectorizer module
