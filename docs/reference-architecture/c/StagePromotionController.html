Stage Promotion Controller

Software componentGovernance & ComplianceSafety, Security & Governancearc:StagePromotionController

A release-governance component that transitions registered agent versions between lifecycle stages only after automated quality gates pass and required human approvals are recorded.

Responsibility. Enforces gated promotion of agent versions across lifecycle stages.

Also known as: Registry stage transition, Approval workflow, Deployment ethics gate

Design guidance

  • MUST block progression of versions failing automated gates (e.g., success rate, critical vulnerabilities, latency SLA).
  • SHOULD require designated human approval for promotion to production and record approver, time and comments.
  • MAY require additional approval tiers (executive, security, compliance) for major or high-risk changes.
  • SHOULD require privacy, security and legal review plus compliance sign-off before deployment.

Quantitative guidance

As stated by the sources; verify before use.

  • Example gate: success rate below 90% keeps a version blocked from staging (Ch4.4).
