Vector Index Builder

Software componentKnowledge & DataKnowledge & Dataarc:VectorIndexBuilder

A load-stage component that builds the configured approximate-nearest-neighbour index over a vector collection with the similarity metric matching the embedding model, then loads it into query-node memory.

Responsibility. Builds and loads the similarity-search index for a vector collection.

Also known as: Vector indexing stage

Design guidance

  • MUST use the similarity metric (cosine, L2 or inner product) that matches the embedding model's training objective.
  • SHOULD load the built index into memory and block until resident before admitting queries.

Quantitative guidance

As stated by the sources; verify before use.

  • Wrong similarity metric can degrade retrieval quality by 40% even with good embeddings (Ch6.3B).
  • Without indexing, queries over a million chunks can time out after 30 seconds instead of returning in milliseconds (Ch6.3B).
