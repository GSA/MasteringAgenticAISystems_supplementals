Retry-Queue Timeout Fallback

Data artifactGovernance & ComplianceSafety, Security & Governancearc:RetryQueueTimeoutFallback

A timeout fallback policy that places an escalation request that received no human response within its SLO into a queue for later retry.

Responsibility. Defers unanswered escalations for later retry.

Variant of Approval Timeout Fallback Policy abstract

When to choose. Choose when the request remains valid later and neither declining nor escalating further is appropriate.
