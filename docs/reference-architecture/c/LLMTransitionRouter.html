LLM Transition Router

Software componentOrchestrationOrchestration & Toolsarc:LLMTransitionRouter

A transition router that asks an LLM to reason about which operation to perform next given current state.

Responsibility. Uses LLM reasoning to choose the next workflow operation.

Variant of Transition Router abstract

When to choose. Choose when deciding what to do next requires reasoning, e.g., tasks without predetermined solution paths.
