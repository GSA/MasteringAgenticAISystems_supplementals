Agent Context Budget Coordinator

Software componentOrchestrationOrchestration & Toolsarc:AgentContextBudgetCoordinator

A non-reasoning coordinator agent that estimates each subtask's token needs, assigns working-memory budgets to worker agents, monitors their utilization, and reallocates capacity between them.

Responsibility. Manages working-memory budgets across the worker agents of a multi-agent task.

Also known as: Coordinator-based orchestration, Context allocation coordinator
