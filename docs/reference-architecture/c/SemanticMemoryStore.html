Design guidance

  • SHOULD be kept separate from episodic and procedural memory to avoid retrieval noise.
  • SHOULD receive general patterns abstracted from many episodes so that specific episodes can later be forgotten while the pattern persists.
  • SHOULD choose the representation (vector, knowledge graph or hybrid) by how the agent must reason, not by which technology is better.
  • MUST tag knowledge with temporal validity so historical facts are not mixed with current facts.
  • SHOULD weight retrieval by source reliability rather than treating all ingested sources equally.

Quantitative guidance

As stated by the sources; verify before use.

  • Systems without long-term memory drop 15-30% accuracy on personalization tasks (Ch3.7).
  • A ~20-token semantic entry can replace ~5,000 tokens of source papers (Ch5.9).
