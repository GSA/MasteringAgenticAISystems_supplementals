Least-Connections Load Balancer

Software componentInfrastructureInfrastructurearc:LeastConnectionsLoadBalancer

A load balancer that tracks in-flight requests per replica and sends each new request to the replica with the fewest active requests, adapting to variable request durations.

Responsibility. Routes each request to the replica currently handling the fewest active requests.

Also known as: Least connections

Variant of Load Balancer abstract

When to choose. Choose as the default when request durations vary widely (e.g., 90% under 2 s, 10% over 10 s).

Design guidance

  • SHOULD be the default algorithm for agent workloads with highly variable processing times.
  • MUST couple connection counting with health checks and reset counts for crashed replicas, otherwise a dead replica appears idle and attracts all traffic.

Quantitative guidance

As stated by the sources; verify before use.

  • Same document workload: least connections balanced replicas at 60-70% CPU and cut P95 latency from 45 s to 28 s (within SLO) (Ch4.7).
