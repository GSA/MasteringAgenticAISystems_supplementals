Design guidance

  • MUST use parameterized queries to prevent Cypher injection from user-supplied entity names.
  • SHOULD express relational questions declaratively as graph patterns rather than as LLM reasoning tasks.
  • SHOULD specify relationship types and apply LIMIT clauses, and profile queries (EXPLAIN/PROFILE) to confirm index seeks instead of label scans.
  • SHOULD query archived graph partitions only when explicitly needed.

Quantitative guidance

As stated by the sources; verify before use.

  • Knowledge graph only: medium semantic coverage, high relational accuracy, p95 ~80ms, medium complexity (Ch1.7B).
