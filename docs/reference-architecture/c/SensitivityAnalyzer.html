Decision Sensitivity Analyzer

Software componentCognitionCognition & Memoryarc:SensitivityAnalyzer

An analysis component that re-evaluates decisions while varying probabilities, objective weights and risk parameters to reveal where the optimal choice changes.

Responsibility. Determines how robust the selected action is to plausible variation in utility inputs.

Also known as: Sensitivity analysis, What-if analysis
