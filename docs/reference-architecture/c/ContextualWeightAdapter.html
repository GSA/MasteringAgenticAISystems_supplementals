Contextual Weight Adapter

Software componentCognitionCognition & Memoryarc:ContextualWeightAdapter

A component that adjusts the objective weights of a utility function per decision according to current context such as user tenure, behaviour, time or operating conditions.

Responsibility. Supplies context-conditioned utility weights to the decision maker at decision time.

Also known as: Adaptive weight mechanism, Conditional utility function, Per-patient alignment adapter
