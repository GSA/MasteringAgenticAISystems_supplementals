Browser Navigator

Software componentTools & IntegrationOrchestration & Toolsarc:BrowserNavigator

A browser automation tool that performs page-level navigation actions such as click, type, and scroll on a web interface on behalf of an agent.

Responsibility. Executes navigation actions against web pages.

Also known as: Browser automation tool, Navigation actions toolkit
