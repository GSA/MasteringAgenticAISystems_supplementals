Task Network

Data artifactCognitionCognition & Memoryarc:TaskNetwork

The evolving hierarchical partial plan: a tree or DAG of abstract and primitive tasks with decomposition edges, ordering constraints, causal links and resource assignments.

Responsibility. Represents the current state of hierarchical decomposition, retaining parent-child structure for repair and multi-level views.

Also known as: Hierarchical task network, Decomposition tree, Partial plan
