Lexical Reranker

Software componentKnowledge & DataKnowledge & Dataarc:LexicalReranker

A reranker that applies keyword (BM25) scoring only to the top vector-search candidates instead of fusing over the full collection.

Responsibility. Re-scores a vector-search shortlist by lexical relevance.

Variant of Reranker abstract

When to choose. Choose instead of full hybrid fusion for extremely latency-sensitive applications (sub-50 ms p99) that still need keyword precision.
