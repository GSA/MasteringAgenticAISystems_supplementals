Depth-First Thought Search Controller

Software componentCognitionCognition & Memoryarc:DepthFirstThoughtSearchController

A tree search controller that recursively explores the best-scored child first, backtracking to the next-best sibling when a branch falls below a value threshold or dead-ends.

Responsibility. Pursues the most promising branch to completion with threshold-based backtracking.

Also known as: DFS, Greedy search with backtracking

Variant of Tree Search Controller abstract

When to choose. Choose when trees are deep (5+ steps), evaluation is reliable enough to trust greedy choices, or any solution suffices.
