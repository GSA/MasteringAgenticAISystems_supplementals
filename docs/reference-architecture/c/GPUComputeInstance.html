GPU Compute Instance

Infrastructure resourceInfrastructureInfrastructurearc:GPUComputeInstance

A compute-isolated subdivision of a GPU partition that owns a subset of the partition's streaming multiprocessors while sharing its memory pool with sibling compute instances.

Responsibility. Gives memory-heavy, compute-light workloads compute separation inside one partition's shared memory.

Also known as: Compute Instance (CI), MIG compute instance
