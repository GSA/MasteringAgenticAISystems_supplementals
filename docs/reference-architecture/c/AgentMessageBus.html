Agent Message Bus

Software componentOrchestrationOrchestration & ToolsVariation point (abstract)arc:AgentMessageBus

A communication medium that transports messages or events between agents in a multi-agent system.

Responsibility. Transports inter-agent messages and events.

Also known as: Inter-agent communication channel

Design guidance

  • SHOULD carry correlation IDs on every message so flows can be traced across agents.
  • MUST NOT assume ordered delivery unless the channel guarantees it; use sequence numbers or idempotent handlers.
  • SHOULD be justified by communication ablation: if isolating agents from each other's outputs causes minimal degradation, a simpler pipeline suffices.
  • SHOULD package only the minimal context the receiving agent needs, balancing omission risk against context bloat.

Quantitative guidance

As stated by the sources; verify before use.

  • Selective-sharing messages of ~500-1,000 tokens instead of the sender's ~20,000-token working context (Ch5.9).
