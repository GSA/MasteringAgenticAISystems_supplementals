Graph Consistency Validator

Software componentKnowledge & DataKnowledge & Dataarc:GraphConsistencyValidator

A validation component that checks proposed knowledge graph additions, removals and edge changes against graph constraint rules and rejects or cascades updates that would create contradictions.

Responsibility. Blocks graph updates that violate declared consistency constraints.
