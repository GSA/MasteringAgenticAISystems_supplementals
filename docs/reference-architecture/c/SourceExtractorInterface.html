Source Extractor Interface

InterfaceKnowledge & DataKnowledge & Dataarc:SourceExtractorInterface

A uniform extraction contract under which every data source connector returns records carrying at least an identifier, content and last-updated timestamp.

Responsibility. Decouples transformation and loading from source-specific extraction logic.

Also known as: Unified extractor interface, Extractor contract
