GPU Switch Fabric

Infrastructure resourceInfrastructureInfrastructurearc:GPUSwitchFabric

A hardware switch fabric giving every GPU in a node dedicated all-to-all paths at full link bandwidth without multi-hop contention.

Responsibility. Provides contention-free all-to-all GPU connectivity.

Also known as: NVSwitch

Variant of GPU Interconnect abstract

When to choose. Choose for 8+ GPU nodes and high-batch tensor-parallel inference where all-reduce bandwidth dominates.
