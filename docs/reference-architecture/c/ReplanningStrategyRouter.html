Replanning Strategy Router

Software componentOrchestrationOrchestration & Toolsarc:ReplanningStrategyRouter

An orchestration component that classifies each significant failure by severity, predictability, scope and time budget and routes it to the reactive, contingency, incremental or strategic replanning layer.

Responsibility. Selects the replanning layer that should handle each detected failure.

Also known as: Failure router, Failure characterisation decision tree

Design guidance

  • MUST route safety-critical failures to the reactive layer regardless of other factors.
  • SHOULD route predictable failures with prepared contingencies to the contingency layer; novel localized failures to incremental replanning; novel global failures to strategic replanning.
  • SHOULD escalate to a faster layer when the available time budget is shorter than the selected layer's expected latency, including CPU contention.

Quantitative guidance

As stated by the sources; verify before use.

  • Scope rule: >80% of plan still valid -> incremental replanning; <50% valid -> complete strategic replanning (Ch5.6).
