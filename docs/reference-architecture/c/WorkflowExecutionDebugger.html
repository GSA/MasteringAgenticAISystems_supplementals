Workflow Execution Debugger

Software componentObservability & EvaluationObservability & Evaluationarc:WorkflowExecutionDebugger

A developer observability tool that inspects per-step workflow state, visualizes the execution path, and rewinds to a stored checkpoint to replay execution with modified state or parameters.

Responsibility. Enables state inspection and time-travel replay of agent workflow executions.

Also known as: Time-travel debugger, Execution graph visualizer, State inspection, Trace checkpoints

Design guidance

  • SHOULD replay from the checkpoint preceding a failure rather than re-running the entire workflow when investigating failures in expensive workflows.
  • SHOULD provide checkpoints after each agent allowing manual inspection and state editing.
