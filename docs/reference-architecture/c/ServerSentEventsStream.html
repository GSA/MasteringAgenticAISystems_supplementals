Server-Sent Events Stream

InterfaceExperienceExperience & Human Oversightarc:ServerSentEventsStream

A unidirectional server-to-client streaming interface over a standard long-lived HTTP response carrying event-stream formatted token chunks.

Responsibility. Streams response events one way from agent to client over plain HTTP.

Also known as: SSE endpoint, Event-stream endpoint, /stream endpoint

Variant of Streaming Transport abstract

When to choose. Choose for most agent streaming workflows: the user submits a query, the agent streams a response, and no mid-stream client-to-server interaction is needed.

Design guidance

  • SHOULD be the default streaming transport; reserve bidirectional channels for genuinely interactive scenarios.
  • MAY rely on standard HTTP middleware for authentication, rate limiting, and logging, and on standard load balancers without special configuration.
