Agent Workflow Configuration

Data artifactOrchestrationOrchestration & Toolsarc:AgentWorkflowConfig

A declarative configuration file selecting the LLM, tools, and workflow composing an agent.

Responsibility. Declares the components and settings that compose an agent workflow.

Also known as: YAML workflow config, Kernel configuration, ConfigMap-externalized agent configuration
