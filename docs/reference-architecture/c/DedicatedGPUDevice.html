Dedicated GPU Device

Infrastructure resourceInfrastructureInfrastructurearc:DedicatedGPUDevice

A whole, unpartitioned physical GPU allocated exclusively to one workload, giving it all compute, memory and memory bandwidth.

Responsibility. Provides the full capacity of one GPU to a single workload.

Also known as: Full GPU allocation, MIG strategy none

Variant of GPU Allocation Unit abstract

When to choose. Choose for large models (70B+), high-concurrency single-tenant deployments, or latency-critical workloads needing full memory bandwidth and large continuous batches.
