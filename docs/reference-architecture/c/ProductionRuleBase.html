Production Rule Base

Data artifactKnowledge & DataKnowledge & Dataarc:ProductionRuleBase

A versioned knowledge base of explicit if-then decision rules, each with conditions, actions, priority (salience), optional confidence score and documented rationale, that applies across all cases.

Responsibility. Holds the permanent, domain-general decision rules that the inference engine applies to case facts.

Also known as: Knowledge base, Rule base, Rule set, Clinical decision rules

Design guidance

  • MUST NOT store case-specific facts; these belong in working memory, or later cases will inherit them.
  • SHOULD document each rule with clear naming, business or clinical rationale and hierarchical organisation so traces remain understandable.
  • SHOULD attach validated confidence scores to rules so inference can prefer and weight reliable rules.

Quantitative guidance

As stated by the sources; verify before use.

  • Fraud case: initial base of 85 expert rules achieved 78% detection at 12% false positives (Ch5.11).
