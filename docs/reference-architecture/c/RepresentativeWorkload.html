Representative Workload

Data artifactObservability & EvaluationObservability & Evaluationarc:RepresentativeWorkload

A load specification reproducing real traffic distributions of prompt lengths, conversation histories, tool-usage patterns and concurrency for profiling and benchmarking.

Responsibility. Makes performance measurements reflect production behaviour.

Also known as: Production-like workload, Traffic distribution sample

Design guidance

  • SHOULD use real user traffic distributions for baselines; synthetic benchmarks serve only to compare configurations under control.
  • SHOULD reproduce expected production traffic patterns, including peak concurrency, rather than 5-10 concurrent requests.
