Fixed Subtask Initiative Controller

Software componentOrchestrationOrchestration & Toolsarc:FixedSubtaskInitiativeController

A mixed-initiative controller that assigns pre-designated workflow stages to agent or human ownership and halts at human-owned stages to request human judgment.

Responsibility. Enforces a fixed partition of workflow stages between agent and human.

Also known as: Fixed subtask initiative

Variant of Mixed-Initiative Controller abstract

When to choose. Choose when workflow stages can be pre-partitioned by clear decision criteria, e.g., routine verification to the agent and judgment-heavy decisions to humans.
