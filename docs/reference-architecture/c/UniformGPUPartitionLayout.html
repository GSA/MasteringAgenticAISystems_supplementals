Uniform GPU Partition Layout

Data artifactInfrastructureInfrastructurearc:UniformGPUPartitionLayout

A GPU partition layout that applies one identical partition profile to every GPU in the cluster, exposing interchangeable partition resources.

Responsibility. Declares a homogeneous partition geometry so any partition satisfies any matching request.

Also known as: Strategy single, all-1g.10gb

Variant of GPU Partition Layout abstract

When to choose. Choose for homogeneous workloads and SaaS platforms with many similar-sized tenants where operational simplicity is the priority.
