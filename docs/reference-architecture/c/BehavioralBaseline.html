Behavioral Baseline

Data artifactObservability & EvaluationObservability & Evaluationarc:BehavioralBaseline

A statistical, multivariate profile of an agent's (or customer's) normal operational characteristics, such as decision distributions, confidence, latency and transaction patterns, against which deviations are judged.

Responsibility. Captures what normal behaviour looks like for anomaly detection.

Also known as: Behavioral fingerprint, Adaptive baseline
