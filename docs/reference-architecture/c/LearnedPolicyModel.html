Learned Decision Policy

Model assetCognitionCognition & MemoryVariation point (abstract)arc:LearnedPolicyModel

Learned parameters mapping states to actions, produced by reinforcement learning to maximize expected long-term reward.

Responsibility. Encodes a learned state-to-action policy.

Also known as: Policy, Q-function, Action-value function
