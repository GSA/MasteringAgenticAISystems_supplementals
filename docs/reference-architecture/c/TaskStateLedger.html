Task State Ledger

Data storeOrchestrationOrchestration & Toolsarc:TaskStateLedger

A shared record of task ownership, status and explicit completion flags across agents in a multi-agent workflow.

Responsibility. Tracks which agent owns and has completed which task.

Also known as: Workflow state, Task status tracker, Running bibliography / processed-items tracker

Design guidance

  • MUST record explicit task completion flags so multiple agents do not start the same expensive computation.
  • SHOULD record task ownership to prevent both overlap and coordination gaps.

Quantitative guidance

As stated by the sources; verify before use.
