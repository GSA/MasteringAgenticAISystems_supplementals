Plan Executor

Software componentCognitionCognition & Memoryarc:PlanExecutor

A component that iterates through planned steps, invoking tools or delegating to sub-agents for each, tracking progress and reporting failures.

Responsibility. Executes plan steps and tracks progress.

Also known as: Executor, HTN executor, Action executor

Design guidance

  • SHOULD execute independent steps in parallel using explicit DAG dependencies.
  • SHOULD check each action's preconditions before executing it so infeasible actions trigger replanning pre-emptively rather than failing.

Quantitative guidance

As stated by the sources; verify before use.

  • Five independent extraction steps run sequentially take roughly five times as long as in parallel (Ch1.2).
