Annotation Task Router

Software componentHuman OversightExperience & Human Oversightarc:AnnotationTaskRouter

A workflow component that assigns prompt-response comparison tasks to available annotators according to required domain expertise and redundancy needs.

Responsibility. Distributes comparison tasks to suitable annotators, including multiple annotators per item for validation.

Also known as: Annotation workflow router
