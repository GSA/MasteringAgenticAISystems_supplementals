Design guidance

  • SHOULD designate minimum viable functionality (e.g., returning document links) as core and enhancements (summaries, citation formatting, relevance scoring) as auxiliary.
  • SHOULD classify each tool capability as optional or essential to determine whether its failure may be degraded around.
