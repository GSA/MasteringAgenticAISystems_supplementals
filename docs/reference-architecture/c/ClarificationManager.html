Clarification Manager

Software componentOrchestrationOrchestration & Toolsarc:ClarificationManager

A dialogue-control component that, when intent inference is ambiguous or low-confidence, asks progressively more structured follow-up questions to resolve the user's intent.

Responsibility. Resolves ambiguous user intent through staged clarification turns.

Also known as: Progressive clarification, Disambiguation dialog

Design guidance

  • SHOULD acknowledge uncertainty transparently and offer specific options when multiple intents have similar confidence.
  • SHOULD escalate from open-ended rephrasing to targeted multiple-choice options to guided examples only as ambiguity persists.
  • SHOULD log failed intent inferences with eventual clarifications as training data.
