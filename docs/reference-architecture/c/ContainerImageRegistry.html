Container and Model Artifact Registry

Data storeInfrastructureInfrastructurearc:ContainerImageRegistry

An authenticated, access-controlled repository that stores tagged container images and optimized model weights and serves them to deployment targets.

Responsibility. Holds versioned deployable images for retrieval by deployments and rollbacks.

Also known as: Container registry, NGC private registry, Private container registry, Fleet Command private application registry, Private Artifact Registry
