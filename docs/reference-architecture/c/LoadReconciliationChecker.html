Load Reconciliation Checker

Software componentObservability & EvaluationObservability & Evaluationarc:LoadReconciliationChecker

A post-load verification component that queries the target store and confirms that the persisted record count matches the number of chunks the pipeline loaded.

Responsibility. Detects silent data loss between loader and target store.

Also known as: Completeness check, End-to-end load verification
