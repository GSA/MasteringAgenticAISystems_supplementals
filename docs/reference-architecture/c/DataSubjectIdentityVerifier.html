Data Subject Identity Verifier

Software componentSafety & SecuritySafety, Security & Governancearc:DataSubjectIdentityVerifier

A verification component that confirms a data-subject request originates from the person who owns the data, by matching account credentials or confirming through email, before fulfilment.

Responsibility. Prevents rights requests from being exercised against someone else's data.

Also known as: Requester identity verification
