# Expert Engagement
{: .no_toc }

As of November 9, 2026, 19 outside experts invited to contribute to the curriculum are working on improving it: 12 have posted review findings or a contribution, and the rest have taken an issue on GitHub and are working on it. The figures count only those experts. The organization and research-area breakdowns appear only where at least 2 of them share one. The list of most recent contributing institutions names institutions and dates only, never people.
