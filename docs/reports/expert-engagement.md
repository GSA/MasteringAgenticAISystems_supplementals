# Expert Engagement
{: .no_toc }

As of October 28, 2026, 18 outside experts invited to contribute to the curriculum are working on improving it: 6 have posted review findings or a contribution, and the rest have taken an issue on GitHub and are working on it. The figures count only those experts. Organizations and research areas appear only where at least 2 of them share one, so no figure points to a single person.
