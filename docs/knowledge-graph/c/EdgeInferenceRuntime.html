Edge Inference Runtime

Software componentModel ServingModelsarc:EdgeInferenceRuntime

An on-device inference runtime that executes compact, hardware-targeted model formats locally, operating autonomously when connectivity is absent.

Responsibility. Executes optimized models on edge hardware.
