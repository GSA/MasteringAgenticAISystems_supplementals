Dead Letter Queue

Data storeOrchestrationOrchestration & Toolsarc:DeadLetterQueue

A holding store for poison messages that repeatedly fail processing, isolating them from healthy traffic.

Responsibility. Isolates messages that exceed retry limits.

Also known as: DLQ, Poison message queue, ETL dead letter queue
