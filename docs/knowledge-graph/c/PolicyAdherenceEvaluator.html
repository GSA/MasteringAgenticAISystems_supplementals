Policy Adherence Evaluator

Software componentGovernance & ComplianceSafety, Security & Governancearc:PolicyAdherenceEvaluator

An evaluation component that checks an agent's actions against domain policy documents and regulatory constraints, scoring task completion jointly with policy compliance.

Responsibility. Detects policy violations in agent runs and computes policy-aware success.

Also known as: Policy-aware evaluation, Automated compliance checking, Online Action Validator, Post-hoc Action Audit, Action Sequence Auditor

Design guidance

  • MUST treat policy violations as failures regardless of task completion in regulated domains.
  • SHOULD give policy compliance equal weight to task completion in evaluation.
  • SHOULD run in production as automated compliance checking, not only pre-deployment.
  • SHOULD validate production actions against policies rather than reference trajectories.
  • SHOULD report near-misses prevented by validation layers to inform prompt refinement and retraining.

Quantitative guidance

As stated by the sources; verify before use.

  • Under joint scoring, 95% task success with a 10% violation rate scores below 90% success with zero violations (Ch3.3).
