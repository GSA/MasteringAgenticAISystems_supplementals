WebSocket Channel

InterfaceExperienceExperience & Human Oversightarc:WebSocketChannel

A persistent full-duplex interface, established by an HTTP upgrade handshake, over which client and server exchange messages at any time during generation.

Responsibility. Carries streamed agent output and concurrent client messages over one persistent connection.

Also known as: Bidirectional streaming channel

Variant of Streaming Transport abstract

When to choose. Choose for genuinely interactive scenarios: agents expecting mid-stream user feedback or interruption, collaborative multi-user agent sessions, or real-time dashboards whose pushed updates need client acknowledgment.
