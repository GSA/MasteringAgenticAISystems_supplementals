Rule-Based Bias Detector

Software componentSafety & SecuritySafety, Security & Governancearc:RuleBasedBiasDetector

A bias detector that matches explicit bias indicators, such as gendered descriptors, racial stereotypes, or age assumptions, against a configured rule set.

Responsibility. Flags explicit bias markers in text by pattern matching.

Also known as: Rule-based bias filter, Pattern-based bias detection

Variant of Output Bias Detector abstract

When to choose. Choose for fast, interpretable, immediate filtering of explicit bias indicators; insufficient alone because paraphrasing evades it and it misses contextual bias.
