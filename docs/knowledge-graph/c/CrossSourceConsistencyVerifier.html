Cross-Source Consistency Verifier

Software componentCognitionCognition & Memoryarc:CrossSourceConsistencyVerifier

A verification step that retrieves the same information from multiple reputable sources, compares them, and flags conflicts for manual review instead of answering confidently.

Responsibility. Detects contradictions across retrieved sources before an answer is given.

Also known as: Contradiction detection
