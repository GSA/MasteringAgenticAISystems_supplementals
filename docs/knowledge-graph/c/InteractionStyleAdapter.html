Interaction Style Adapter

Software componentExperienceExperience & Human Oversightarc:InteractionStyleAdapter

A component that adapts interaction depth, initiative and directness per interaction according to user expertise, task complexity, environmental stress, time pressure and system confidence.

Responsibility. Selects the interaction style appropriate to the current context.

Also known as: Adaptive interaction pattern, Contextual interaction adapter

Design guidance

  • SHOULD adapt dynamically per context rather than via user-level profiles applied uniformly.
