Agent Packaging Interface

InterfaceModel ServingModelsarc:AgentPackagingInterface

A standard load-context and predict contract wrapping an agent so any compatible serving platform can load its artifacts and invoke it without deployment-specific code.

Responsibility. Decouples a packaged agent from the platform that serves it.
