Heuristic Image Type Classifier

Software componentKnowledge & DataKnowledge & Dataarc:HeuristicImageTypeClassifier

An image type classifier that labels images as charts using visual heuristics such as the presence of axis labels, legends, or grid patterns.

Responsibility. Flags likely charts from simple visual cues without invoking a model.

Variant of Image Type Classifier abstract

When to choose. Choose when a simple rule suffices to spot charts, e.g., images containing axis labels, legends or grid patterns, as in the financial-report worked example.
