Model Routing Policy

Data artifactModel ServingModelsarc:ModelRoutingPolicy

A declarative policy mapping request characteristics such as token length or reasoning complexity to model tiers and providers, together with spending caps, applied centrally by the AI gateway.

Responsibility. Specifies which model and provider serve each class of request.

Also known as: AI gateway routing policy, Cost cap policy

configures structural

Design guidance

  • SHOULD be configured once at the gateway layer rather than reimplemented across agent services.

Quantitative guidance

As stated by the sources; verify before use.

  • <500 tokens -> Claude 3.5 Haiku; >2,000 tokens multi-step reasoning -> Claude 3.5 Sonnet (Ch4.2 example).
  • Simple queries -> GPT-4o-mini, moderate and complex -> GPT-4o (Ch8.3).
  • Complexity score < 0.3 -> 4B model (~30x cheaper), < 0.6 -> 8B (~10x cheaper), else 70B (Ref8.05).
  • Tier cost/quality: 4B $0.0001/1K (75%), 8B $0.0005/1K (85%), 70B $0.003/1K (95%), 405B $0.01/1K (98%) (Ref8.05).
