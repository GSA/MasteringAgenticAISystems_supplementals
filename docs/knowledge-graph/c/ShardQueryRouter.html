Shard Query Router

Software componentInfrastructureInfrastructurearc:ShardQueryRouter

A cluster component on every node that forwards each request to a node owning the relevant shard and redirects to replica shards when an owner is degraded.

Responsibility. Routes queries to shard owners, failing over to replicas.

Also known as: Query forwarding
