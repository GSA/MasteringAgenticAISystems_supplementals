Scoped Access Token

Data artifactSafety & SecuritySafety, Security & Governancearc:ScopedAccessToken

A short-lived credential carrying only the specific OAuth 2.0 scopes (e.g., read:calendar) an agent capability requires.

Responsibility. Restricts API operations an agent can perform to its granted scopes.

Also known as: OAuth 2.0 scoped token, Short-lived scoped credential
