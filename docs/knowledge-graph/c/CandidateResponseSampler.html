Candidate Response Sampler

Software componentModel AdaptationModelsarc:CandidateResponseSampler

A component that generates several genuinely different candidate responses per prompt by varying sampling parameters, prompting strategies or model checkpoints, for pairwise preference comparison.

Responsibility. Produces alternative responses for preference annotation.

Also known as: Response variant generation, RLAIF response-pair generation
