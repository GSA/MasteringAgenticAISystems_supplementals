On-Demand Explanation Expander

Software componentExperienceExperience & Human Oversightarc:OnDemandExplanationExpander

An expansion controller that reveals deeper explanation layers only when the user activates controls such as 'Show More Details', 'Technical View' toggles or collapsible step indicators.

Responsibility. Expands explanation layers upon explicit user request.

Also known as: Passive explanation, Show More button, Technical View toggle, Collapsible step cascade

Variant of Explanation Expansion Controller abstract

When to choose. Choose when users can be expected to seek detail themselves (low time pressure, routine or low-stakes decisions); insufficient alone because users rarely seek additional information spontaneously.
