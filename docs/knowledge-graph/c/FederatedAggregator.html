Federated Aggregator

Software componentModel AdaptationModelsarc:FederatedAggregator

A central training component that distributes the global model to devices and aggregates their locally computed updates, optionally with differential-privacy noise, into an improved global model.

Responsibility. Improves a global model from distributed device updates without collecting raw data.

Also known as: Federated learning server
