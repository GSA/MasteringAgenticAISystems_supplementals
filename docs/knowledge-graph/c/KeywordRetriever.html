Keyword Retriever

Software componentKnowledge & DataKnowledge & Dataarc:KeywordRetriever

A retriever that ranks documents by sparse keyword (lexical) matching against the query rather than by embedding similarity.

Responsibility. Retrieves documents by lexical keyword match.

Also known as: Sparse keyword search, Sparse retriever, BM25 retriever, Keyword search fallback

Variant of Retriever abstract

When to choose. Choose alongside dense vector search when sparse keyword matching can return results faster, run in parallel to cut retrieval latency.
