Alert Consolidator

Software componentObservability & EvaluationObservability & Evaluationarc:AlertCorrelator

An alert-processing component that merges overlapping alerts from redundant detectors about the same underlying issue into a single synthesized alert.

Responsibility. Deduplicates and synthesizes correlated alerts into one actionable alert.

Also known as: Alert correlator, Alert deduplicator, Alert correlation, Incident narrative builder, Alert Consolidator

Design guidance

  • SHOULD consolidate alerts such as 'CPU > 80%', 'high CPU usage' and 'performance degradation' into one alert that synthesizes the signals.
  • SHOULD present symptom relationships explicitly as one incident rather than requiring monitors to assemble incident stories from fragments.
  • SHOULD use system topology to attribute simultaneous alerts on dependent components to the upstream root cause.

Quantitative guidance

As stated by the sources; verify before use.

  • Example: resource pressure produced 47 individual alerts that correlation consolidates into one incident (Ch10.4).
  • Alerts firing within 5-minute windows are likely related (Ch10.4).
