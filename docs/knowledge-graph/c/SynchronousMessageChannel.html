Synchronous Message Channel

Software componentOrchestrationOrchestration & Toolsarc:SynchronousMessageChannel

A point-to-point channel carrying explicitly addressed, performative-typed request-response messages with sender, receiver, content, ontology and conversation-id metadata.

Responsibility. Delivers addressed request-response messages between agents.

Also known as: Message passing, Request-response messaging

Variant of Agent Message Bus abstract

When to choose. Choose when immediate feedback or strong consistency is essential, interactions are brief and synchronous, the agent network is small, and explicit communication trails aid compliance.

Relationships

alternative to variability

Design guidance

  • MUST use acknowledgements, timeouts with retries, and idempotent handling to survive message loss.
  • SHOULD tune timeouts to avoid both false failovers and cascading blocking chains.
  • SHOULD NOT be used for broadcast to many agents; point-to-point fan-out grows linearly with recipients.
  • SHOULD use adaptive rather than static protocols where roles, topology or load change at runtime.

Quantitative guidance

As stated by the sources; verify before use.

  • Suited to agent networks of fewer than 50 agents (Ch1.3 selection criteria).
