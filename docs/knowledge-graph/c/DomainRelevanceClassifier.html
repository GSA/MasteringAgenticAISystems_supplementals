Domain Relevance Classifier

Software componentModel AdaptationModelsarc:DomainRelevanceClassifier

A curation stage that scores each document's topical relevance to the target domain with a trained classifier and filters or prioritizes documents by that score.

Responsibility. Selects high-value, domain-relevant documents and excludes off-domain content.

Also known as: Domain classification stage, Topical relevance scorer
