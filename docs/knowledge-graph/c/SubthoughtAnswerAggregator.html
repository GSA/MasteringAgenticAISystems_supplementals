Subthought Answer Aggregator

Software componentCognitionCognition & Memoryarc:SubthoughtAnswerAggregator

A cognition component that extracts intermediate candidate answers from all reasoning branches within a single trace and selects an answer by majority or confidence-weighted vote.

Responsibility. Selects an answer by voting across intermediate answers in one reasoning trace.
