Stalled Workflow Resumer

Software componentOrchestrationOrchestration & Toolsarc:StalledWorkflowResumer

A monitoring function that detects agent workflows left incomplete by function timeouts or interruptions and resubmits continuation events that resume them from the last checkpoint.

Responsibility. Restarts interrupted workflows from their last checkpoint.

Also known as: Continuation monitor
