Persistent Search Tree Store

Data storeCognitionCognition & Memoryarc:PersistentSearchTreeStore

A store retaining a search's per-node cost values, parent pointers and consistency information across planning cycles so later replans can reuse them.

Responsibility. Persists search-tree bookkeeping between planning cycles.

Also known as: LPA* search tree, g-value and parent-pointer cache
