Conversational Agent Coordinator

Software componentOrchestrationOrchestration & Toolsarc:GroupChatManager

A workflow orchestrator in which autonomous agents, each keeping its own message history and auto-reply behaviour, advance work through natural-language message exchange rather than predefined control flow.

Responsibility. Advances a multi-agent task through turn-based conversational message exchange.

Also known as: Conversation-driven multi-agent coordination, Agent group chat, GroupChat, GroupChatManager, Conversational coordinator, Speaker selector, Conversational Agent Coordinator

Variant of Multi-Agent Coordinator abstract

When to choose. Choose when collaboration benefits from flexible dialogue (agents challenging outputs, requesting clarification, negotiating), for exploratory workflows, prototyping and human-overseen scenarios where readable transcripts aid transparency; avoid where determinism and structured audit trails are required.

Design guidance

  • SHOULD NOT be used where regulation requires identical decisions for identical inputs, because conversation order and content vary across runs even at temperature 0.
  • SHOULD add custom structured state management when workflow state goes beyond conversational context.
  • SHOULD NOT be used where compliance, auditability or reproducibility require identical inputs to yield identical execution paths, because conversation flow is non-deterministic.
  • SHOULD bound conversations with a maximum round limit and explicit termination conditions.
  • SHOULD pair with human validation of final outputs when conversational flexibility is used.
