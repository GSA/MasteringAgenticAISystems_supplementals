Voice Persona Profile

Data artifactExperienceExperience & Human Oversightarc:VoicePersonaProfile

A configuration of voice identity, pitch, speaking rate and prosody settings that expresses an agent persona or a user's accessibility preference in synthesized speech.

Responsibility. Defines how an agent sounds when it speaks.

Also known as: Voice customization settings, Prosody configuration
