Final Answer Extractor

Software componentCognitionCognition & Memoryarc:FinalAnswerExtractor

A cognition component that extracts the final answer from each completed reasoning path so that answers from independently sampled paths can be compared and counted.

Responsibility. Extracts a comparable final answer from each reasoning path.

Also known as: Answer extractor
