Trace Context Propagator

Software componentObservability & EvaluationObservability & Evaluationarc:TraceContextPropagator

A telemetry component that propagates shared trace, session and parent-span identifiers across agent handoffs and service boundaries so distributed spans correlate into one causally ordered trace.

Responsibility. Carries trace and session identifiers across agent and service boundaries.

Also known as: Trace ID propagation, Session ID propagation

Design guidance

  • MUST propagate shared trace IDs across all agents of a multi-agent workflow to reconstruct the end-to-end timeline.
  • SHOULD scope trace IDs to individual conversations and consistently propagate session IDs.
  • SHOULD treat parent-child span relations and trace-ID propagation as ground-truth causal ordering, using timestamps only as approximate guides.
  • MUST propagate trace context (trace ID, span ID, sampling decision) across every inter-agent call or message so agent spans become children of the caller's span.

Quantitative guidance

As stated by the sources; verify before use.

  • Healthcare case: ~15% of multi-turn conversations included context from previous sessions; billing agent retrieved wrong patient's payment history 3% of the time (Ch3.6).
