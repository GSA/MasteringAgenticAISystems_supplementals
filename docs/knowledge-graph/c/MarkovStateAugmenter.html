Markov State Augmenter

Software componentCognitionCognition & Memoryarc:MarkovStateAugmenter

A state-representation component that enriches the current decision state with sufficient interaction history for the augmented state to satisfy the Markov property.

Responsibility. Augments decision state with relevant history so future outcomes depend only on the augmented state.

Also known as: History-augmented state builder
