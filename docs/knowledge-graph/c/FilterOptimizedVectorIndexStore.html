Filter-Optimized Vector Index Store

Data storeKnowledge & DataKnowledge & Dataarc:FilterOptimizedVectorIndexStore

A vector store whose index and query engine are explicitly optimized for combining vector similarity with complex metadata filter expressions without latency degradation.

Responsibility. Executes vector similarity search constrained by complex attribute filters at low latency.

Also known as: Filtered vector search database

Variant of Vector Index Store abstract

When to choose. Choose when filtered vector search is the core workload (recommendations under business-rule constraints, document search with access control, analysis within temporal windows); available self-hosted or managed.
