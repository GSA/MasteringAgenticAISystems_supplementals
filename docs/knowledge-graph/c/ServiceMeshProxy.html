Service Mesh Proxy

Software componentInfrastructureInfrastructurearc:ServiceMeshProxy

A sidecar proxy deployed beside each agent container that intercepts all inbound and outbound traffic to apply routing, resilience, mutual TLS and tracing without application changes.

Responsibility. Applies traffic, security and telemetry policies transparently to inter-service calls.

Also known as: Sidecar proxy, Service mesh
