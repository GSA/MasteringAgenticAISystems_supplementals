Source Schema Validator

Software componentKnowledge & DataKnowledge & Dataarc:SourceSchemaValidator

A validation component that checks extracted records or API responses against the expected source schema, surfacing source schema or API contract changes before processing.

Responsibility. Detects mismatches between source data and the expected extraction schema.

Also known as: Schema drift detector, API response validator, Startup schema validation
