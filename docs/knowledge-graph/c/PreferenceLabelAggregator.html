Preference Label Aggregator

Software componentModel AdaptationModelsarc:PreferenceLabelAggregator

A data component that combines redundant annotators' judgments on the same comparison into a preference label annotated with the observed agreement distribution.

Responsibility. Produces preference labels that preserve disagreement metadata rather than forcing consensus.

Also known as: Disagreement-aware label aggregator
