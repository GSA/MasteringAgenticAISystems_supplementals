Environment Simulator

Software componentCognitionCognition & Memoryarc:EnvironmentSimulator

A forward model that, given a state and action, returns legal actions, a sampled successor state (drawn from its outcome distribution when stochastic) and terminal status for planning simulations.

Responsibility. Generates simulated state transitions for search and rollouts.

Also known as: Forward model, Simulator, Generative model, Training environment, Simulation environment, Grid world

Design guidance

  • MUST produce different rollouts on repeated calls from the same state; identically seeded RNGs break statistical independence.
  • SHOULD be used for exploration and DAgger rollouts when failures in the real environment are unacceptable.
