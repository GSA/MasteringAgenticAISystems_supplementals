Web Transaction Executor

Software componentTools & IntegrationOrchestration & Toolsarc:WebTransactionExecutor

A transaction-operation tool that mutates web-application state on an agent's behalf: submitting forms, authenticating, modifying carts, downloading files, and confirming purchases or payments.

Responsibility. Executes WRITE operations that change state on external websites.

Also known as: Transaction operations tool, Form submission tool, Checkout executor
