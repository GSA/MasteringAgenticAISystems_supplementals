Draft Token Proposer

Model assetModel ServingModelsVariation point (abstract)arc:DraftTokenProposer

Model weights that propose K speculative future tokens for a target model to verify in one parallel forward pass, selected for distributional alignment with the target rather than task accuracy.

Responsibility. Supplies speculative tokens whose acceptance multiplies decode throughput.

Also known as: Draft model, Draft strategy
