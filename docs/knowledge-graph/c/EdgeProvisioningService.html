Edge Provisioning Service

Software componentInfrastructureInfrastructurearc:EdgeProvisioningService

A cloud endpoint that authenticates newly powered edge devices by pre-issued provisioning tokens and registers them as managed locations for initial configuration download.

Responsibility. Enrolls edge hardware into the managed fleet without on-site technical work.

Also known as: One-touch provisioning, Zero-touch provisioning

  • Provisioning tokens valid 30 days in the example (Ch4.6).
