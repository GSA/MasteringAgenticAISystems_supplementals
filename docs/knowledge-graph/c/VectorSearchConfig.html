Vector Search Configuration

Data artifactKnowledge & DataKnowledge & Dataarc:VectorSearchConfig

A query-time configuration setting ANN search depth (ef) and result count (k), adjustable per query without rebuilding the index.

Responsibility. Specifies the runtime accuracy/latency trade-off of each vector search.

Also known as: search_params, Runtime accuracy dial

Relationships

configures structural

  • Approximate Vector Search Retriever Ch6.2A

Design guidance

  • MUST set ef >= k; typically ef = 2-5x k.
  • SHOULD tune ef dynamically from latency and recall monitoring, reserving higher ef for high-stakes queries.

Quantitative guidance

As stated by the sources; verify before use.

  • ef=50 ~90% Recall@10, ef=100 ~95%, ef=200 ~98%; diminishing returns beyond 200 (Ch6.2A).
