Precompiled Context Template

Data artifactCognitionCognition & Memoryarc:PrecompiledContextTemplate

A pre-compiled, domain- or specialty-specific context block injected into prompts in place of dynamically generated context for a known task type.

Responsibility. Supplies compact, stable task-type context without per-request context construction.

Also known as: Specialist template, Template-based context

Quantitative guidance
