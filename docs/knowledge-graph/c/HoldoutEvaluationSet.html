Holdout Evaluation Set

Data artifactObservability & EvaluationObservability & Evaluationarc:HoldoutEvaluationSet

A sequestered evaluation dataset never consulted during configuration exploration, used only once configuration decisions are final to measure generalisation.

Responsibility. Provides an unbiased generalisation estimate for finalised configurations.

Also known as: Holdout Set, Final Evaluation Set, Rule validation dataset, Validation set

Quantitative guidance

As stated by the sources; verify before use.
