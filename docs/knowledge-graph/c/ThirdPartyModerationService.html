Third-Party Moderation Service

Software componentSafety & SecuritySafety, Security & Governancearc:ThirdPartyModerationService

A moderation inference service consumed as an external API that scores submitted content for toxicity or other harm categories.

Responsibility. Scores content via an externally operated moderation API.

Also known as: API-based classifier, Content moderation API, Toxicity detector, Harmful content detection, Content Moderation Service
