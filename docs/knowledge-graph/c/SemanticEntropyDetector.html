Semantic Entropy Detector

Software componentCognitionCognition & Memoryarc:SemanticEntropyDetector

A hallucination detector that samples several responses to the same prompt and quantifies their semantic divergence, treating high variability as evidence the model is guessing.

Responsibility. Detects knowledge gaps via semantic inconsistency across sampled responses.

Also known as: Semantic consistency checking, Self-consistency sampling detector
