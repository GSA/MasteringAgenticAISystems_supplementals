Approval Escalation Protocol

Data artifactHuman OversightExperience & Human Oversightarc:ApprovalEscalationProtocol

An escalation protocol that pauses agent execution and requests explicit human authorization before the action proceeds.

Responsibility. Blocks a boundary-crossing action until a human authorizes it.

Also known as: Approval workflow escalation
