Counterfactual Explainer

Software componentCognitionCognition & Memoryarc:CounterfactualExplainer

An explanation component that identifies which fact values would need to change, relative to rule condition thresholds, for a rule-based decision to come out differently.

Responsibility. Explains decision boundaries by stating the minimal changes that would alter the outcome.

Also known as: Decision boundary explainer, Counterfactual explanation, What-would-need-to-change explanation, Contrastive explanation generator, Diverse counterfactual explanations

Variant of Decision Explainer abstract

When to choose. Choose when users need to know the minimal changes that would flip the decision (why-not / recourse).
