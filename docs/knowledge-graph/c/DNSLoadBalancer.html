DNS Load Balancer

Software componentInfrastructureInfrastructurearc:DNSLoadBalancer

A name-resolution-level load balancer that spreads client traffic across multiple load balancer instances or regional endpoints, removing the single front-end load balancer as a failure point.

Responsibility. Distributes clients across redundant load balancers or regional stacks via DNS resolution.

Also known as: DNS-based load balancing, Nearest-region routing
