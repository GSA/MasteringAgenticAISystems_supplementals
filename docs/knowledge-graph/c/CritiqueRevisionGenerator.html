Critique-Revision Generator

Software componentModel AdaptationModelsarc:CritiqueRevisionGenerator

A training-data generator that has a model critique its own response against a randomly sampled constitutional principle, then revise the response to remove identified violations.

Responsibility. Produces principle-aligned revised responses for supervised fine-tuning.

Also known as: Supervised self-critique (SL-CAI), Self-critique-and-revision cycle
