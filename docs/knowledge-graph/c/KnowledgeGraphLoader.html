Design guidance

  • MUST use create-or-update (merge) semantics so repeated runs over overlapping documents do not create duplicates.
  • MUST merge on immutable identifiers only and set mutable attributes separately.
  • SHOULD write in bulk transactions over document batches rather than per document.

Quantitative guidance

As stated by the sources; verify before use.

  • Process documents in batches of 100-1000 before bulk writes to the graph (Ch1.7A).
