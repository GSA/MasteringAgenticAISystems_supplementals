Managed Vector Index Store

Data storeKnowledge & DataKnowledge & Dataarc:ManagedVectorIndexStore

A fully managed, cloud-hosted vector store whose provider handles scaling, multi-region replication and real-time indexing, exposing no cluster or index tuning to the user.

Responsibility. Provides vector similarity search without customer-operated infrastructure.

Also known as: Managed vector database, Serverless vector database, Fully managed vector database service

Variant of Vector Index Store abstract

When to choose. Choose when rapid deployment and operational simplicity outweigh infrastructure control and cloud-hosted storage is acceptable.

Design guidance

  • SHOULD be chosen only where cloud deployment satisfies security requirements, since it cannot run on-premises and creates vendor lock-in.
  • SHOULD NOT be chosen where strict data residency, self-hosting, specialized index types or custom distance metrics are required (cloud-only, vendor lock-in).
  • MAY be chosen to abstract partitioning and horizontal scaling behind autoscaling APIs.
