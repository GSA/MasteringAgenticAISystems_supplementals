Web Navigation Agent

Software componentOrchestrationOrchestration & Toolsarc:WebNavigationAgent

An agent runtime that carries out multi-step web tasks by planning action sequences, selecting browser actions from the current page state, and tracking state across navigation steps until the user's goal state is reached.

Responsibility. Drives the per-task loop that chooses the next web interaction toward the user's goal.

Also known as: Web agent, Browser agent, Agentic commerce agent

Design guidance

  • SHOULD generalize across site architectural patterns rather than executing memorized interaction sequences.
  • SHOULD start production deployment with read-only information gathering before expanding to transactional operations.
  • SHOULD maintain state and context across multi-turn conversations in which users supply requirements incrementally.
  • SHOULD adapt when preferred items or paths are unavailable, e.g., by proposing alternatives matching user preferences.

Quantitative guidance

As stated by the sources; verify before use.

  • Frontier agents reaching ~60% success on controlled WebArena drop to ~30% on live Online-Mind2Web sites (Ch3.3).
  • MMInA: 1,050 real-world multimodal web tasks averaging 2.85 hops between sites and 12.9 actions per task (Ch3.3).
  • Illustrative: an agent at 85% on e-commerce sites seen in development may reach only 40% on unfamiliar forum sites (Ch3.3).
