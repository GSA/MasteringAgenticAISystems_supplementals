MCTS Search Tree Store

Data storeMemoryCognition & Memoryarc:MCTSSearchTreeStore

Working-memory store of an MCTS search tree whose nodes are states and edges actions, holding per state-action pair the visit count N(s,a), cumulative reward Q(s,a) and child pointers.

Responsibility. Retains accumulated simulation statistics that guide subsequent search iterations.
