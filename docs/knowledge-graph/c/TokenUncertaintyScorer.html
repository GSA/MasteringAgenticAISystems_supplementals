Token Uncertainty Scorer

Software componentCognitionCognition & Memoryarc:TokenUncertaintyScorer

A statistical hallucination detector that flags generated outputs as uncertain using token log-probabilities, response perplexity and response-length anomalies relative to expected patterns.

Responsibility. Flags likely hallucinated generations from model-internal uncertainty signals.

Also known as: Statistical evaluator, Confidence filtering, Perplexity scoring, Response length anomaly detection
