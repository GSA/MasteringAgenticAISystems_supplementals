Structured Reasoning Prompt Template

Data artifactCognitionCognition & MemoryVariation point (abstract)arc:StructuredReasoningPromptTemplate

A prompt template that prescribes the format in which an agent exposes its reasoning, creating consistent step boundaries and evaluation checkpoints in reasoning traces.

Responsibility. Structures agent reasoning output into a consistent, parseable format.

Also known as: Structured CoT prompt, Structured reasoning template

Variants

VariantWhen to choose
Numbered Step Reasoning TemplateChoose when the simplest structure suffices and clear step boundaries are needed for automated parsing and step-by-step evaluation.
Tagged Reasoning TemplateChoose when evaluation must extract and assess specific reasoning components, e.g., whether verification actually checks results or conclusions quantify confidence.

Design guidance

  • MUST apply whichever reasoning structure is adopted consistently across all reasoning tasks so evaluation pipelines can reliably parse traces.
  • SHOULD specify domain-specific steps with concrete deliverables rather than generic 'think step by step' instructions.
  • MAY embed per-step verification criteria so agents mark assumptions and revise failing steps before continuing.
