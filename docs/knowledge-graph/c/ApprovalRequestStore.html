Approval Request Store

Data storeHuman OversightExperience & Human Oversightarc:ApprovalRequestStore

A durable store of serialized approval requests capturing pending action, analysed context, agent reasoning, eligible approvers, creation time, status and timeout, persisted independently of agent execution.

Responsibility. Persists approval workflow state so paused agents can resume across process lifecycles.

Also known as: Approval state store, Persistent approval queue
