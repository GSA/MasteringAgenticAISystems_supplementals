Stream Connection Manager

Software componentExperienceExperience & Human Oversightarc:StreamConnectionManager

A session component that tracks open streaming connections and their users, detects client disconnects and idle timeouts, and releases the associated generation resources.

Responsibility. Manages the lifecycle of streaming connections so abandoned streams do not consume server resources.

Also known as: Connection manager, Disconnection detector
