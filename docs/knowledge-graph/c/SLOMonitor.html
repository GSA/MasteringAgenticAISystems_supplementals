Design guidance

  • SHOULD watch a new deployment over a soak period and trigger automatic rollback on any threshold violation.
  • SHOULD trigger a detailed profiling capture for the affected request pattern when p99 latency suddenly increases.
  • SHOULD flag breaches whenever P95 exceeds the SLA threshold rather than when the mean does (Ch8.1, Ref8.03).

Quantitative guidance

As stated by the sources; verify before use.

  • Example alerts: p95 latency > 200ms or failure rate > 1% (Ch1.7B).
  • Layered resilience targets 99.9% uptime (Ch2.8).
  • Staging soak thresholds: success rate > 95%, p95 latency < 8 s, error rate < 2%, memory stable (Ch4.2).
  • Example SLA targets: P95 <200ms, error rate <0.5% (Ch7.2).
