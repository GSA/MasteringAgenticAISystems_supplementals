Evaluation Configuration

Data artifactObservability & EvaluationObservability & Evaluationarc:EvaluationConfig

A declarative configuration specifying an evaluation's dataset source, evaluators with their metric names and judge LLMs, and output location, overridable at runtime.

Responsibility. Defines what an evaluation run measures, with which judges and data.
