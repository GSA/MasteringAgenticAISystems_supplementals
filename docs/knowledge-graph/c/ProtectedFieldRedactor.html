Protected Field Redactor

Software componentSafety & SecuritySafety, Security & Governancearc:ProtectedFieldRedactor

A runtime filter that removes fields designated as protected from structured retrieved records or tool results while keeping permitted fields for LLM processing.

Responsibility. Removes protected fields from data entering the LLM context.

Also known as: Field-level redaction, Analyst-view pseudonymizer
