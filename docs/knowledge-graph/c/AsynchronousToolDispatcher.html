Asynchronous Tool Dispatcher

Software componentTools & IntegrationOrchestration & Toolsarc:AsynchronousToolDispatcher

A tool call dispatcher that submits tool calls to a background executor without blocking the serving loop, so GPU inference for other requests overlaps external tool latency.

Responsibility. Hides I/O-bound tool latency behind concurrent inference work.

Also known as: Async tool execution, Non-blocking tool executor

Variant of Tool Call Dispatcher abstract

When to choose. Choose when profiling shows GPU idle gaps during I/O-bound tool calls in multi-step agent loops (e.g., ReAct) under concurrent load.

Quantitative guidance

As stated by the sources; verify before use.

  • Case study: GPU utilisation 45% -> 78%, p99 3,200 -> 1,850 ms (-42%), throughput 12.5 -> 23.8 req/s (+90%); 85% of tool time overlapped with inference (Ch4.2).
