Agent Dependency Graph

Data artifactOrchestrationOrchestration & Toolsarc:AgentDependencyGraph

A declared directed acyclic graph of which agents consume which other agents' outputs in a workflow, from which topologically sorted execution phases are derived.

Responsibility. Records inter-agent dependencies for validation and ordered execution.

Also known as: Explicit dependency graph, Dependency DAG, Workflow dependency declarations
