Connection Pool

Software componentInfrastructureInfrastructurearc:ConnectionPool

A component that maintains and reuses established, authenticated database connections across queries to avoid per-query connection setup.

Responsibility. Supplies reusable database connections to data access components.

Also known as: Database connection pooling, HTTP connection pool

Quantitative guidance

As stated by the sources; verify before use.

  • Connection pooling reduced per-query overhead from 500 ms to 5 ms (Ch6.3B).
  • Removes 20-50ms TCP/TLS setup per request, saving 20-50 seconds per thousand requests (Ch7.2).
