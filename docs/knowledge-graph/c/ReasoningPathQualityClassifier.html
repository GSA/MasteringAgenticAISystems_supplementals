Reasoning Path Quality Classifier

Software componentCognitionCognition & Memoryarc:ReasoningPathQualityClassifier

A lightweight classifier that scores each sampled reasoning path from 0 to 1 on coherence, faithfulness and task relevance, supplying vote weights and rationale rankings.

Responsibility. Scores the reasoning quality of each sampled path.

Also known as: RASC quality scorer, Rationale quality scorer
