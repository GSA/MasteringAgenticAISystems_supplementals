Configuration Repository

Data storeGovernance & ComplianceSafety, Security & Governancearc:ConfigurationRepository

A version-controlled store of every agent configuration element (prompts, tool definitions, model versions, retrieval configurations, hyperparameters) enabling reconstruction of any past system state.

Responsibility. Versions all agent configuration artifacts for reproducibility.

Also known as: Version control, Agent release registry, Model registry, Git source repository, GitOps infrastructure repository
