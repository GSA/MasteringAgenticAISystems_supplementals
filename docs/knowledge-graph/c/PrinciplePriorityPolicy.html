Principle Priority Policy

Data artifactGovernance & ComplianceSafety, Security & Governancearc:PrinciplePriorityPolicy

A declarative value hierarchy ranking constitutional principles and user intent for conflict scenarios, e.g., privacy versus security, safety versus autonomy, fundamental principles over user instructions.

Responsibility. Resolves which principle prevails when principles conflict.

Also known as: Principle ranking, Value hierarchy, Value prioritization

Design guidance

  • MUST let fundamental ethical principles override user intent while fulfilling user intent within those boundaries.
  • SHOULD be set by human judgment from multi-stakeholder deliberation, since no technical analysis resolves value trade-offs.
  • SHOULD place non-negotiable safety first, then optimize efficiency and fairness within safety constraints (autonomous-vehicle example).
  • MUST make trade-offs explicit rather than claim they are eliminated.
