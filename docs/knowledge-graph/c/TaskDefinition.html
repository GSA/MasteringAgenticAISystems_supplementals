Task Definition

Data artifactOrchestrationOrchestration & Toolsarc:TaskDefinition

A declarative specification of a discrete unit of multi-agent work: description, expected output, assigned role, required tools, and dependencies on upstream task outputs.

Responsibility. Specifies one unit of team work and its dependencies on other tasks.

Also known as: Task, CrewAI Task

Design guidance

  • SHOULD define a clear expected output and explicit context dependencies for every task.
  • SHOULD NOT be used to encode frequent ad-hoc back-and-forth interaction between agents, which fits task abstractions poorly.
