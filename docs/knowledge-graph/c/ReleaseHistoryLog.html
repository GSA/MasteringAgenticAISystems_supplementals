Release History Log

Data storeGovernance & ComplianceSafety, Security & Governancearc:ReleaseHistoryLog

A persistent record of each deployment event, capturing version, update type, outcome (success or rollback), timestamp, duration, affected users, previous version and changelog.

Responsibility. Keeps an auditable history of updates and rollbacks.

Also known as: Update history tracking, UpdateTracker, Change log
