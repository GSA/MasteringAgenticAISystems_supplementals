Value Priority Profile Store

Data storeMemoryCognition & Memoryarc:ValuePriorityProfileStore

A per-principal store of discovered value priorities, such as a patient's weighting of autonomy, safety, convenience and outcomes, used to adapt an agent's alignment specification to that individual.

Responsibility. Persists individual stakeholders' value priorities for personalised value alignment.

Also known as: Patient value profile, Stakeholder value profile
