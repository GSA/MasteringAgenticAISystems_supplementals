Edge Cost Updater

Software componentCognitionCognition & Memoryarc:EdgeCostUpdater

A cognition component that applies incoming environment-change observations (e.g., traffic travel-time estimates, detected blockages) as edge-cost changes to the state-space graph.

Responsibility. Updates state-space edge costs from new environment observations.

Also known as: Traffic cost updater, Map change detector
