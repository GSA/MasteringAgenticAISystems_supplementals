REST Agent API

InterfaceTools & IntegrationOrchestration & Toolsarc:RESTAgentAPI

A resource-oriented, stateless HTTP/JSON API exposing agent capabilities as endpoints manipulated with standard HTTP methods.

Responsibility. Exposes agent capabilities as stateless HTTP resources.

Also known as: Chain serving endpoints (/invoke, /batch, /stream, /stream_log), Workflow serving endpoint (/generate, /chat, /chat/stream), REST RAG API

Variant of Agent Service API abstract

When to choose. Choose when human readability matters, clients are diverse (any HTTP client), performance requirements are moderate, and REST infrastructure can be reused.
