Content-Based Event Router

Software componentOrchestrationOrchestration & Toolsarc:ContentBasedEventRouter

An event broker that matches event content and metadata against filtering rules and delivers each event, optionally transformed, to the targets whose rules it satisfies.

Responsibility. Routes events to specialised agents based on event content.

Also known as: Event bus with content-based filtering

Variant of Event Broker abstract

When to choose. Choose when events in one stream must reach different specialised agents depending on classification metadata in the payload (e.g., financial vs legal documents).
