Output Edit Recorder

Software componentObservability & EvaluationObservability & Evaluationarc:OutputEditRecorder

A telemetry component that records user edits, rewrites, parameter adjustments and copy-paste refinements of agent outputs as before-and-after pairs and detects substantial edits.

Responsibility. Captures user modifications of agent outputs as correction pairs.
