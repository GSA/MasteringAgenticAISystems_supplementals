Plan Deviation Monitor

Software componentCognitionCognition & Memoryarc:PlanExecutionMonitor

An execution-monitoring component that compares primitive outcomes with operator-predicted effects and identifies the abstraction level whose assumptions failed.

Responsibility. Detects divergence between predicted and actual execution outcomes of a plan.

Also known as: Execution monitoring, Plan execution monitor, Discrepancy detector, Plan monitor, Plan Deviation Monitor

Design guidance

  • MUST monitor primitive success and failure; primitives can fail despite satisfied preconditions (timeouts, rate limits, outages).
  • MUST run in parallel with execution and check preconditions before, progress during, and effects after each action.
  • SHOULD flag but not directly trigger replanning; severity evaluation decides whether a discrepancy warrants adaptation.
  • SHOULD also watch for goal changes, which invalidate plans through obsolescence rather than failure.
