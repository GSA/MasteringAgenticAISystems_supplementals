Container Image

Data artifactInfrastructureInfrastructurearc:ContainerImage

An immutable, tagged package of an agent's code, dependencies, model artifacts and runtime configuration that a container runtime instantiates.

Responsibility. Serves as the portable, reproducible unit of agent deployment.

Also known as: Docker image, Agent image, Multi-arch image, Inference microservice container, Pristine base image
