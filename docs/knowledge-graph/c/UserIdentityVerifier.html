User Identity Verifier

Software componentSafety & SecuritySafety, Security & Governancearc:UserIdentityVerifier

A security component that verifies an end user's identity, for example through multi-factor authentication, before the agent accesses accounts or executes financial or claims transactions.

Responsibility. Authenticates the conversing user before sensitive operations.

Also known as: Security verification, Customer identification
