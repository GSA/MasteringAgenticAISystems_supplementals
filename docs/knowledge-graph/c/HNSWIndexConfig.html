HNSW Index Configuration

Data artifactKnowledge & DataKnowledge & Dataarc:HNSWIndexConfig

A vector index configuration building a hierarchical navigable small-world graph for millisecond approximate search at very large scale.

Responsibility. Configures graph-based approximate vector search.

Also known as: HNSW index

Variant of Vector Index Build Configuration abstract

When to choose. Choose for large collections (beyond ~10 million vectors) where search latency outweighs higher memory usage.
