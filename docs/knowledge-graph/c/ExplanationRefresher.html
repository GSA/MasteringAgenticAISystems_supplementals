Explanation Refresher

Software componentExperienceExperience & Human Oversightarc:ExplanationRefresher

A component that regenerates a decision explanation when new evidence, feedback, policy changes or corrected data arrive, time-stamping each version and flagging stale explanations.

Responsibility. Keeps displayed explanations current as underlying information changes.

Also known as: Dynamic explanation, Staleness warning
