Responsibility. Encodes the learned mapping from diverse user phrasings to intent categories.

Design guidance

  • SHOULD be trained on data reflecting real-world linguistic variation (dialects, slang, colloquialisms, frustrated phrasing), not idealized formal language.
  • SHOULD be retrained continuously on production data as user language evolves.
