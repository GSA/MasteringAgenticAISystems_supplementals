Inductive Rule Learner

Software componentModel AdaptationModelsarc:InductiveRuleLearner

A rule learner that induces general if-then rules from attribute patterns distinguishing outcomes across labelled training examples.

Responsibility. Induces candidate rules from labelled historical examples.

Also known as: Rule induction

Variant of Rule Learner abstract

When to choose. Choose when rules must be induced from historical labelled examples (e.g., past approved/denied applications) rather than from an existing expert rule set.
