Thought Search Policy

Data artifactCognitionCognition & Memoryarc:ThoughtSearchPolicy

A configuration artifact fixing tree-search parameters: breadth b, branching factor k, maximum depth and the pruning value threshold below which branches are abandoned.

Responsibility. Bounds search breadth, depth and pruning aggressiveness.

Also known as: Pruning policy, Pruning threshold, Search budget parameters

Design guidance

  • SHOULD limit branching factor k to 3-5 rather than ten or more alternatives per state.
  • SHOULD configure backtracking conservatively, using pruning thresholds to eliminate obviously unproductive branches early.
  • SHOULD adjust thresholds from measured value-estimate calibration.

Quantitative guidance

As stated by the sources; verify before use.
