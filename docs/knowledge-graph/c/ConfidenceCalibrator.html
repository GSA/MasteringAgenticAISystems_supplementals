Confidence Calibrator

Software componentCognitionCognition & Memoryarc:ConfidenceCalibrator

A component that adjusts raw model confidence to match empirical accuracy for the scenario type, lowering presented confidence where the model is known to be overconfident.

Responsibility. Converts raw model confidence into calibrated confidence for presentation.

Also known as: Calibrated confidence display
