Reward Shaper

Software componentModel AdaptationModelsarc:RewardShaper

A training-time component that adds intermediate shaping rewards to a sparse reward signal to accelerate learning while preserving the optimal policy.

Responsibility. Densifies sparse rewards with potential-based shaping terms during learning.
