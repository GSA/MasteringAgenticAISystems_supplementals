Agent Message Contract

Data artifactOrchestrationOrchestration & Toolsarc:AgentMessageContract

A versioned specification of the data format, units, field names and semantic meaning of messages exchanged between agents.

Responsibility. Defines the syntax and semantics of inter-agent messages.

Also known as: Interface contract, Event schema, .proto definition, Shared ontology, Structured inter-agent message schema, Standard event envelope

Design guidance

  • MUST state units and semantic meaning, not just syntax, of exchanged values.
  • SHOULD evolve additively: never delete fields or renumber field IDs.
  • SHOULD balance event granularity; overly generic events couple subscribers and overly granular events create versioning burden.
  • SHOULD standardise events on required routing fields (event type, timestamp, source service) plus type-specific optional payload.
  • SHOULD force agents to declare intent and outputs in structured formats that other agents and monitoring systems can parse.
