Ephemeral Sandbox Manager

Software componentInfrastructureInfrastructurearc:EphemeralSandboxManager

A lifecycle component that creates a fresh minimal sandbox from a pristine base image for each tool execution and destroys it, with all created state, when execution completes or times out.

Responsibility. Guarantees no state persists between agent executions.

Also known as: Container lifecycle manager
