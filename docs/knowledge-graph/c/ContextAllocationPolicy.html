Context Allocation Policy

Data artifactMemoryCognition & Memoryarc:ContextAllocationPolicy

A configuration artifact specifying per-task-type context-window allocation shares, the reserve fraction, utilization thresholds that escalate compression, and the advertised versus enforced capacity.

Responsibility. Declares how context-window capacity is apportioned and when compression escalates.
