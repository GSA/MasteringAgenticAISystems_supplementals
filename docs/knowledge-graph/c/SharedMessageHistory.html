Shared Message History

Data storeOrchestrationOrchestration & Toolsarc:SharedMessageHistory

An append-only conversation transcript shared by all participants in a multi-agent dialogue, holding every agent's messages as the common coordination context.

Responsibility. Holds the ordered messages of a multi-agent conversation for all participants to read.

Also known as: Group chat history, Shared conversation history, Message history

Design guidance

  • SHOULD serve as the transparent record of what each agent contributed and why, for human oversight.
  • MUST NOT be assumed to carry custom state that agents track locally; such state requires explicit synchronization.
