Rolling Update Controller

Software componentInfrastructureInfrastructurearc:RollingUpdateController

A rollout controller that replaces the instances of a workload with a new version gradually, a few at a time, instead of all simultaneously.

Responsibility. Updates a running workload to a new version without service interruption.

Also known as: Rolling update strategy

Variant of Rollout Manager abstract

When to choose. Choose gradual one-at-a-time replacement when safety matters more than update speed; replacing all instances at once is faster but risky.
