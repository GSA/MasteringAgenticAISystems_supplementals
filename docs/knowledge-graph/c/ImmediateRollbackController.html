Immediate Rollback Controller

Software componentInfrastructureInfrastructurearc:ImmediateRollbackController

A rollback controller that switches all traffic to the previous version at once, scaling the new version to zero and scaling the previous version up.

Responsibility. Performs an instant, complete traffic reversion to the previous version.

Also known as: Emergency rollback

Variant of Version Rollback Controller abstract

When to choose. Choose for critical issues: error rate > 5%, latency > 200% of baseline, system crash/unavailability or detected data corruption.
