Command Palette with Agent Suggestions

Software componentExperienceExperience & Human Oversightarc:CommandPalette

A keyboard-invoked, non-modal overlay that fuzzy-matches typed text to executable commands and surfaces agent-predicted, context-relevant command suggestions.

Responsibility. Provides fast keyboard-driven access to agent actions.

Also known as: Command palette, Cmd+K palette

Variant of Agent User Interface abstract

When to choose. Choose for IDEs, productivity and design tools where power users value keyboard speed and the agent can predict intent from context; avoid when discoverability for new users, multi-turn dialogue, or extensive explanation is required.
