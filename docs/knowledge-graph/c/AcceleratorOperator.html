Accelerator Operator

Software componentInfrastructureInfrastructurearc:AcceleratorOperator

A cluster controller that automates deployment, upgrade and lifecycle of the per-node accelerator software stack (driver, container runtime hooks, device plugin, telemetry exporter, node labeling) as managed operands.

Responsibility. Manages the lifecycle of accelerator software on cluster nodes.

Also known as: GPU Operator, NVIDIA GPU Operator
