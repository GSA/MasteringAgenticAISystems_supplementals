Failure Analyzer

Software componentCognitionCognition & Memoryarc:FailureAnalyzer

A cognition component that interprets verification failures, such as failed test output, into human-readable error analysis and categorized recurring error patterns that guide the next generation attempt.

Responsibility. Converts failed verification results into error context for the next refinement iteration.

Also known as: analyze_failures node, Error analysis node, Analysis plugin, Error pattern extraction, Root cause analysis
