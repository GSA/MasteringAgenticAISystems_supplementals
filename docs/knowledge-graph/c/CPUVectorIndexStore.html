CPU Vector Index Store

Data storeKnowledge & DataKnowledge & Dataarc:CPUVectorIndexStore

A vector store that builds ANN indices (HNSW, IVF) and computes similarity search on CPUs.

Responsibility. Stores embeddings and answers similarity queries using CPU compute.

Also known as: CPU-only vector database

Variant of Vector Index Store abstract

When to choose. Choose when collections and query rates are modest enough that CPU-based index building and search latency are acceptable.
