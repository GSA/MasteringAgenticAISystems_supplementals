Database State Store

Data storeOrchestrationOrchestration & Toolsarc:DatabaseStateStore

A state checkpoint store that persists workflow state durably in a database.

Responsibility. Durably persists workflow state for long-running workflows.

Also known as: Durable state store, SQLite checkpointer, PostgreSQL checkpointer

Variant of State Checkpoint Store abstract

When to choose. Choose for long-running processes (hours or days) whose state must survive instance failure and be resumable by any instance.
