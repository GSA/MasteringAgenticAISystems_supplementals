Model Metadata Descriptor

Data artifactModel ServingModelsarc:ModelMetadataDescriptor

A machine-readable description of a model's architecture, context length, tokenizer settings and build environment that serving runtimes use to configure backend engines.

Responsibility. Informs the serving runtime how to initialise engines for a specific model.

Also known as: Hugging Face config.json, Model metadata

Design guidance

  • MUST provide complete and accurate architecture, context length and tokenizer metadata for every served model.
  • SHOULD record the CUDA and engine library versions used to build compiled engines as part of model metadata.
