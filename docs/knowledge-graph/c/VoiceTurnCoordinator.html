Voice Turn Coordinator

Software componentOrchestrationOrchestration & Toolsarc:VoiceTurnCoordinator

A runtime component that sequences one spoken conversation turn: streams user audio to speech recognition, hands transcripts to the agent, and passes the agent's reply to speech synthesis.

Responsibility. Coordinates the ASR-agent-TTS turn pipeline within the conversational latency budget.

Also known as: Voice agent pipeline, Voice interaction orchestrator

Design guidance

  • SHOULD target end-to-end voice turn latency near human turn-taking (~200-400ms) and avoid >1 second.
  • SHOULD start agent context retrieval on partial transcripts while the user is still speaking.

Quantitative guidance

As stated by the sources; verify before use.

  • Users expect <300ms end-to-end; a simple query totals ~300-900ms across ASR, LLM (100-500ms) and TTS (100-200ms) (Ch7.5).
