Agent Circuit Breaker

Software componentSafety & SecuritySafety, Security & Governancearc:AgentCircuitBreaker

A protective control that automatically pauses an agent when accumulated errors exceed a threshold and keeps it paused until a human reviews and resumes it.

Responsibility. Halts a failing agent automatically pending human review.
