Source Change Detector

Software componentKnowledge & DataKnowledge & Dataarc:SourceChangeDetector

An ingestion component that monitors source systems for modified documents using versions and modification timestamps and queues changed items for reindexing.

Responsibility. Detects changed source content that requires reindexing.

Also known as: Change detection pipeline, Change data capture for knowledge, Timestamp-based change detection, Delta detection, Incremental update tracking, Change Data Capture, File system watch, API webhook receiver, Change detection

  • Incremental change detection reduces update lag from days (batch) to minutes or seconds (streaming) (Ch6.4).
