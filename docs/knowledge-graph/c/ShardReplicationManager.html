Shard Replication Manager

Software componentInfrastructureInfrastructurearc:ShardReplicationManager

A cluster component that keeps each data shard on the configured number of nodes, continues writes to surviving replicas during failures and resynchronizes nodes when they rejoin.

Responsibility. Maintains shard replicas and catch-up resynchronization.
