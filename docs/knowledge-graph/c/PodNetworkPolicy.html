Pod Network Policy

Data artifactSafety & SecuritySafety, Security & Governancearc:PodNetworkPolicy

A declarative firewall rule set specifying allowed ingress and egress traffic between workloads by label and namespace.

Responsibility. Restricts which components may communicate with each other.

Also known as: Network policy, Network egress allow-list, Default-deny network policy

Design guidance

  • SHOULD allow vector databases to accept connections only from authorised agent pods.
  • SHOULD restrict cluster-gossip traffic to internal networks, separating it from data-replication and client ports.
  • MUST start sandboxes with zero network connectivity and allow-list specific destinations (host, port) incrementally.
  • MUST NOT isolate the filesystem while leaving network connectivity unrestricted.
