Canonical Form Matcher

Software componentSafety & SecuritySafety, Security & Governancearc:CanonicalFormMatcher

A matching component that maps a user utterance to a declared canonical intent by semantic similarity to its example phrases, generalizing beyond the enumerated wordings.

Responsibility. Recognizes which declared user intent an utterance expresses.

Also known as: Canonical intent recognizer, User intent matcher
