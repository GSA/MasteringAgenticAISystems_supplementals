Streaming Transport

InterfaceExperienceExperience & Human OversightVariation point (abstract)arc:StreamingTransport

An abstract client-facing transport through which incremental agent output is delivered from server to client while it is still being generated.

Responsibility. Carries progressively generated agent output to the client over a long-lived connection.

Also known as: Streaming endpoint, Streaming protocol

Variants

VariantWhen to choose
Server-Sent Events StreamChoose for most agent streaming workflows: the user submits a query, the agent streams a response, and no mid-stream client-to-server interaction is needed.
WebSocket ChannelChoose for genuinely interactive scenarios: agents expecting mid-stream user feedback or interruption, collaborative multi-user agent sessions, or real-time dashboards whose pushed updates need client acknowledgment.
