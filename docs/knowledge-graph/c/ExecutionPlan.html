Execution Plan

Data artifactCognitionCognition & MemoryVariation point (abstract)arc:ExecutionPlan

An explicit, ordered or dependency-graph representation of the steps an agent will execute to achieve a goal.

Responsibility. Specifies the steps and dependencies of a task.

Also known as: Plan, Task DAG, Primitive task network, Executable plan, Active plan, Action sequence, Route plan, Planned route with waypoints and target times

Design guidance

  • SHOULD encode step dependencies as a DAG so independent steps can run in parallel.
  • SHOULD annotate each step with preconditions, expected effects and verification conditions (e.g., position within 1 m of prediction).
