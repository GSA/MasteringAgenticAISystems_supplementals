State Retention Policy

Data artifactGovernance & ComplianceSafety, Security & Governancearc:StateRetentionPolicy

A governance policy specifying how long persisted workflow state is kept after completion and when it must be deleted.

Responsibility. Specifies retention and deletion rules for persisted workflow state.
