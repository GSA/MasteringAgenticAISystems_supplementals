Accessibility Auditor

Software componentGovernance & ComplianceSafety, Security & Governancearc:AccessibilityAuditor

An automated conformance checker that scans agent interfaces on every build for accessibility defects such as missing alt text, insufficient contrast, invalid markup, and missing ARIA labels.

Responsibility. Checks agent UIs against accessibility standards.

Also known as: Automated accessibility testing
