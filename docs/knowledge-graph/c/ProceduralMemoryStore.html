Procedural Memory Store

Data storeMemoryCognition & Memoryarc:ProceduralMemoryStore

Long-term memory of learned rules, task-execution patterns and strategies, activated by context pattern matching.

Responsibility. Stores learned procedures and strategies.

Design guidance

  • SHOULD be isolated from factual retrieval so heuristics do not contaminate factual queries.
  • SHOULD be refined from episodic outcomes: successful episodes reinforce procedures, failed episodes trigger refinement.

Quantitative guidance
