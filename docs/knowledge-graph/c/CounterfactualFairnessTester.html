Counterfactual Fairness Tester

Software componentGovernance & ComplianceSafety, Security & Governancearc:CounterfactualFairnessTester

An audit component that submits paired test cases differing only in a sensitive attribute (audit-study style) to a decision model and compares the resulting decisions.

Responsibility. Tests whether decisions change when only a protected attribute changes.

Also known as: Audit study tester, Counterfactual fairness assessment
