Error Presenter

Software componentExperienceExperience & Human Oversightarc:ErrorPresenter

A presentation component that translates agent failures into plain-language layered messages stating cause, permanence, expected resolution, and separate user and system recovery actions.

Responsibility. Communicates failures with actionable recovery guidance.

Also known as: Error communication UI, Recovery guidance, Degradation warning display

Design guidance

  • MUST NOT expose raw exceptions or stack traces to end users by default.
  • SHOULD indicate whether an error is temporary (auto-retry) or needs user action, with estimated resolution time when known.
  • SHOULD offer fallback options such as cached results when primary methods fail.
  • SHOULD log full technical error details separately for debugging.
