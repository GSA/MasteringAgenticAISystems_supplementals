Static Batch Scheduler

Software componentModel ServingModelsarc:StaticBatchScheduler

A batch scheduler that waits until a fixed number of requests accumulate before executing, maximizing GPU saturation at the cost of unbounded wait for early arrivals.

Responsibility. Executes only full, fixed-size batches.

Also known as: Static batching

Variant of Inference Batch Scheduler abstract

When to choose. Choose for offline batch workloads (overnight reports, bulk document processing, scheduled evaluation) where no user waits.

Relationships

Design guidance

  • SHOULD NOT be used for interactive agents because low traffic makes first-arriving requests wait seconds or minutes.

Quantitative guidance

As stated by the sources; verify before use.

  • Batch 32 at 50 req/s: 640 ms average formation wait + 150 ms compute = 790 ms, with unbounded waits during traffic transitions (Ch4.7).
