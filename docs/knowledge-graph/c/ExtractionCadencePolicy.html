Extraction Cadence Policy

Data artifactOrchestrationOrchestration & ToolsVariation point (abstract)arc:ExtractionCadencePolicy

An abstract configuration choosing whether a pipeline extracts source data in periodic batches or continuously as it arrives.

Responsibility. Fixes the extraction cadence and hence knowledge freshness of a pipeline.

Also known as: Batch vs streaming extraction decision

Variants

VariantWhen to choose
Batch Extraction PolicyChoose for relatively static knowledge bases where daily updates suffice, and for structured sources with efficient timestamp-based change detection.
Streaming Extraction PolicyChoose for rapidly changing domains (e.g., news, stock trading) and semi-structured event sources where near-real-time freshness justifies added complexity.
