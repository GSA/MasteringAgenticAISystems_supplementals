Metadata-Filtered Retriever

Software componentKnowledge & DataKnowledge & Dataarc:MetadataFilteredRetriever

A vector retriever that applies metadata predicates (modality, speaker, time period, source) to narrow the search space before vector similarity search.

Responsibility. Restricts similarity search to chunks matching metadata filters.

Also known as: Hybrid search (vector + metadata filter), Context-aware episodic retrieval
