Vector Collection Schema

Data artifactKnowledge & DataKnowledge & Dataarc:VectorCollectionSchema

An explicit schema for a vector store collection declaring the fixed embedding dimensionality plus stored chunk text, source identifier, JSON metadata and an auto-generated primary key.

Responsibility. Fixes the structure and embedding dimension of stored vector records.

Also known as: Collection schema

Design guidance

  • MUST declare the embedding dimension to match the embedding model output; it cannot change after collection creation.
  • SHOULD store chunk text alongside vectors to avoid joins with a separate document store at query time.
  • SHOULD store a source-document identifier per chunk so neighbouring chunks can be fetched for additional context.
