Parallel Sub-Query Retrieval Controller

Software componentKnowledge & DataKnowledge & Dataarc:ParallelSubQueryRetrievalController

A retrieval control component that issues retrieval for all independent sub-queries concurrently and gathers per-sub-query context, so total latency approximates the slowest single retrieval.

Responsibility. Retrieves context for independent sub-queries concurrently.

Also known as: Parallel retrieval, Concurrent sub-query retrieval

Design guidance

  • SHOULD execute sub-query retrievals concurrently rather than sequentially.
  • SHOULD report sub-query count, successful retrievals and per-sub-query chunk counts to detect sub-queries that consistently retrieve nothing.

Quantitative guidance

As stated by the sources; verify before use.

  • Four sub-queries: ~800 ms sequential (4 x 200 ms) vs ~200 ms concurrent (Ch6.6).
