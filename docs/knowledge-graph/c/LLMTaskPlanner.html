LLM Task Planner

Software componentCognitionCognition & Memoryarc:LLMTaskPlanner

A task planner that prompts a language model to break a goal into subgoals and select available functions for each, leveraging broad model knowledge rather than an encoded method library.

Responsibility. Produces shallow goal decompositions and function selections using LLM reasoning.

Also known as: Semantic Kernel planner, LLM-based goal decomposer

Variant of Task Planner abstract

When to choose. Choose for high-level decomposition of open-ended goals where broad knowledge matters and encoding deep domain methods in prompts would be too expensive.
