Thought Decomposition Specification

Data artifactCognitionCognition & Memoryarc:ThoughtDecompositionSpec

A design artifact defining what constitutes one thought for a problem class (e.g., one arithmetic operation, one narrative plan, one crossword word), fixing tree granularity.

Responsibility. Defines the intermediate-thought unit that shapes generation and evaluation.

Also known as: Thought granularity definition, Thought decomposition strategy

Design guidance

  • MUST place thought boundaries at natural breakpoints where genuinely distinct candidates exist and meaningful evaluation is possible.
  • SHOULD keep search tree depth manageable (typically under six levels).
  • SHOULD be validated on small problem samples before full implementation, since decomposition errors are expensive to correct later.
