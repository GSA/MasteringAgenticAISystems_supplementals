Episode Encoder

Software componentMemoryCognition & MemoryVariation point (abstract)arc:EpisodeEncoder

An abstract memory component that decides which experiences from an interaction become episodic memories and converts them into structured episode records.

Responsibility. Converts selected interaction experiences into structured episode records for long-term storage.

Also known as: Encoding strategy, Episode capture

Variants

VariantWhen to choose
Event-Based Episode EncoderChoose when every action might be significant later (e.g., debugging complex technical problems where the solution hinges on minor details); avoid for routine standard-pattern interactions where storage overhead outweighs retrieval value.
Significance-Based Episode EncoderChoose when most interactions follow standard patterns and storage must be reduced while preserving the most informative experiences (failures, unusual outcomes, high-impact states).

Design guidance

  • SHOULD encode context metadata (timestamp, segment, channel, handling agent) so later retrieval can match circumstances, not just content.
  • SHOULD store debugging or multi-turn sessions as trajectories with problem category, resolution success, total time, attempts and outcome.

Quantitative guidance

As stated by the sources; verify before use.

  • Richer encoding enables retrieval by similar context (segment, time of day, initial diagnostic hunches) (Ch5.7).
