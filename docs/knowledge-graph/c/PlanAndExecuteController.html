Plan-and-Execute Controller

Software componentOrchestrationOrchestration & Toolsarc:PlanAndExecuteController

An agent controller that separates strategic planning from tactical execution, coordinating a planner, an executor, and a replanner around an explicit multi-step plan.

Responsibility. Coordinates plan creation, step execution, and replanning.

Also known as: Plan-and-Execute agent, Replanning agent loop, Continuous adaptation controller

Variant of Agent Controller abstract

When to choose. Choose for complex workflows with mostly predictable steps in stable environments, resource-constrained settings, or supervisor-worker coordination; avoid for highly dynamic, real-time, simple, or open-ended exploratory tasks.

Design guidance

  • SHOULD use powerful models for planning and lighter-weight models or rule-based executors for execution.
  • SHOULD design replanning triggers that are neither too sensitive nor too conservative.
  • SHOULD run execution monitoring in parallel with execution rather than treating planning and execution as separate sequential phases.

Quantitative guidance

As stated by the sources; verify before use.

  • Frontier model for planning with smaller execution models can cut total inference cost by 60-70% (Ch1.2).
