Goal Specification

Data artifactCognitionCognition & Memoryarc:GoalSpecification

A shared, asynchronously updatable specification of the target state or outcome an agent's current plan must achieve (e.g., delivery address).

Responsibility. States the planning objective and its success criteria.

Also known as: High-level goal, Root task, Shared task specification, Goal state

  • SHOULD be monitored during execution so goal changes cause the in-progress plan to be abandoned immediately.
