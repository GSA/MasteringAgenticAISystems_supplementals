Explanation Method Selector

Software componentExperienceExperience & Human Oversightarc:ExplanationMethodSelector

A component that selects which explainability method(s) and visualizations to apply for a decision, based on user mode (novice or expert), investigation goal and decision context.

Responsibility. Selects the explainability methods applied to a decision for a given user and context.

Also known as: Multi-method explanation interface, Novice/expert mode switch

Design guidance

  • SHOULD offer multiple explanation methods rather than one universal method, since regulators, end users, developers and operators need different explanation types.
  • Novice mode SHOULD present a single default method selected by decision context; expert mode MAY expose all methods and visualization parameters.
  • Divergence between methods SHOULD be treated as a signal of complexity warranting further investigation or human oversight.
