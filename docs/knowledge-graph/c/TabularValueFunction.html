Tabular Value Function

Model assetCognitionCognition & Memoryarc:TabularValueFunction

A learned policy model stored as a table holding one value estimate per state-action pair (Q-table).

Responsibility. Stores a Q-value for every state-action pair.

Also known as: Q-table

Variant of Learned Decision Policy abstract

When to choose. Choose when the state-action space is small and discrete enough to enumerate and visit.
