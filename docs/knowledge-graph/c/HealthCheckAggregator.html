Health Check Aggregator

Software componentObservability & EvaluationObservability & Evaluationarc:HealthCheckAggregator

A health-check service that runs layered service, model, integration and end-to-end checks and combines their results into an overall healthy, degraded or unhealthy status for an agent system.

Responsibility. Combines layered health-check results into one system health status.

Also known as: Unified health check, Layered health check framework

Design guidance

  • SHOULD start with simple availability checks and layer in performance, quality and diagnostic checks.
  • SHOULD keep basic checks fast (under 1 second) so health checking does not slow the system.
  • SHOULD run basic checks frequently and comprehensive diagnostics less often.
  • SHOULD itself be tested.

Quantitative guidance

As stated by the sources; verify before use.

  • Schedule: basic health every 1 min, detailed every 5 min, comprehensive diagnostics hourly (Ref8.07).
