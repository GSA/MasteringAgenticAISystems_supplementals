Encrypted Model Volume

Data storeInfrastructureInfrastructurearc:EncryptedModelVolume

An encrypted persistent storage volume local to a serving node that caches model weights, and at edge sites application data and logs, unreadable without externally held keys.

Responsibility. Persists model artifacts near the accelerator while protecting them at rest.

Also known as: Persistent volume for model caching, Encrypted edge volume
