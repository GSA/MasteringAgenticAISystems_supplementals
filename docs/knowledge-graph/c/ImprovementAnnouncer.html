Improvement Announcer

Software componentExperienceExperience & Human Oversightarc:ImprovementAnnouncer

A user-communication component that proactively tells users when an AI system update changes agent behaviour, closing the feedback loop and setting expectations.

Responsibility. Informs users of released behaviour changes and improvements derived from their feedback.

Also known as: System update notice, Close-the-loop notification

Design guidance

  • SHOULD proactively communicate AI system updates back to users when bot behaviour changes (e.g., "We've improved how we understand refund requests").
  • SHOULD tell users about improvements made in response to their feedback (Ref10.03).
