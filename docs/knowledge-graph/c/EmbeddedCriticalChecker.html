Embedded Critical Checker

Software componentCognitionCognition & Memoryarc:EmbeddedCriticalChecker

A self-contained last-resort checker that runs a small static set of critical checks requiring no external services when both LLM and rule-engine analysis are unavailable.

Responsibility. Provides minimal critical-check analysis without any external dependency.
