Agent Delegation Interface

InterfaceOrchestrationOrchestration & ToolsVariation point (abstract)arc:AgentDelegationInterface

An inter-agent interface through which one agent hands a task, with structured context, to another agent.

Responsibility. Accepts delegated tasks with structured context from other agents.

Also known as: Agent-to-agent protocol endpoint, Inter-agent coordination interface, Delegate work to coworker tool, Ask question to coworker tool

Variants

VariantWhen to choose
Discoverable Delegation InterfaceChoose in heterogeneous systems where agent availability fluctuates or several agents offer similar capabilities with different trade-offs, requiring runtime discovery.
Static Delegation InterfaceChoose when task delegation boundaries are well-defined and agent capabilities are static, so no runtime capability discovery is needed.

Design guidance

  • MUST be complemented by semantic alignment (shared ontologies, data models, behavioural contracts); protocol compliance alone does not ensure interoperability.
  • SHOULD be kept distinct from infrastructure/tool access protocols (e.g., MCP), which cannot define delegation or orchestration logic.
