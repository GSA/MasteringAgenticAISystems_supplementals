Model Repository

Data storeModel ServingModelsarc:ModelRepository

A versioned directory store of model artifacts and their serving configurations, mounted by an inference server from persistent or object storage.

Responsibility. Holds deployable model versions separately from inference server code.

Also known as: Triton model repository, Shared model-weight storage, NGC model catalog
