Reference Trajectory

Data artifactObservability & EvaluationObservability & Evaluationarc:ReferenceTrajectory

A ground-truth expected action sequence for a test case, listing each tool, its expected parameters and outputs, required ordering, context conditions and success criteria.

Responsibility. Specifies the correct action path against which agent trajectories are scored.

Also known as: Golden Trajectory, Expected Action Sequence
