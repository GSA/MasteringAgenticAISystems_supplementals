Access Anomaly Detector

Software componentSafety & SecuritySafety, Security & Governancearc:AccessAnomalyDetector

A monitoring component that analyses personal-data access logs for anomalous patterns such as unusual access times, bulk exports, repeated failed authentication or unexpected locations, and raises security alerts.

Responsibility. Detects suspicious access to personal data from audit trails.

Also known as: Access log analysis
