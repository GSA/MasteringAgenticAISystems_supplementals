Proactive Agent

Software componentOrchestrationOrchestration & Toolsarc:ProactiveAgent

An agent that continuously senses user, historical and environmental context and initiates interventions or actions without an explicit user request, based on predicted needs (push-based rather than pull-based interaction).

Responsibility. Initiates anticipatory interventions from monitored context and predicted user needs.

Also known as: Anticipatory agent, Push-based agent, Proactive assistant

Design guidance

  • SHOULD treat user interruptions as a scarce resource and intervene only when a high-confidence intervention substantially improves outcomes.
  • MUST NOT operate autonomously without graduated oversight matched to decision stakes; autonomous errors compound and cascade before humans notice.
  • SHOULD ask a clarifying question rather than act when behavioural signals are ambiguous and uncertainty is high.
  • SHOULD explain each proactive intervention: triggering signals, data analysed, underlying assumptions, and how the user can correct it.
  • MUST log for every proactive suggestion which data was accessed, what inference was drawn and what action was taken.
