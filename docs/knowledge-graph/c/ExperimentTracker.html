Experiment Tracker

Software componentObservability & EvaluationObservability & Evaluationarc:ExperimentTracker

A tracking service that records each evaluation run's agent configuration, metrics and artifacts so runs are reproducible and comparable over time.

Responsibility. Logs evaluation runs and makes their history queryable for comparison.

Also known as: Experiment tracking, Experiment tracking platform, MLflow experiments and runs

Design guidance

  • SHOULD log model name, temperature, prompt template, all metrics and detailed result artifacts for every run.
  • SHOULD group related metrics with consistent naming prefixes and tags to support filtering and comparison.
  • SHOULD record the exact configuration that produced each ablation result so it can be verified and re-run.
