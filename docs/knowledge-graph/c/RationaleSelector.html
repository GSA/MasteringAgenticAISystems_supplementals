Rationale Selector

Software componentCognitionCognition & Memoryarc:RationaleSelector

A cognition component that chooses, among sampled reasoning paths reaching the consensus answer, the highest-quality path to present as the explanation.

Responsibility. Selects the best supporting reasoning path for explanation.

Also known as: Best-rationale selector
