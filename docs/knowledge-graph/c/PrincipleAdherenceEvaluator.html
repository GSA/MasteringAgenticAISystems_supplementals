Principle Adherence Evaluator

Software componentObservability & EvaluationObservability & Evaluationarc:PrincipleAdherenceEvaluator

An evaluation component that tests a model with per-principle violation-seeking prompts, edge cases and out-of-distribution framings, measuring false refusals and accepted violations.

Responsibility. Measures how consistently a model follows each constitutional principle.

Also known as: Principle compliance evaluator, Principle adherence testing, Cross-domain generalization testing, Pre-deployment alignment testing

Design guidance

  • MUST measure both false positives (inappropriate refusals) and false negatives (accepted violations).
  • SHOULD probe generalization with test cases deliberately distinct from the training distribution.
  • SHOULD confirm alignment with specified values before deployment and after each update.

Quantitative guidance

As stated by the sources; verify before use.

  • Illustrative: a model may adhere on 99.9% of test cases yet violate principles under specific framings, so adversarial testing is required (Ch9.5).
