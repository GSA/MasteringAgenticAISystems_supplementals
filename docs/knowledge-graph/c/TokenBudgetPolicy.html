Token Budget Policy

Data artifactOrchestrationOrchestration & Toolsarc:TokenBudgetPolicy

A configuration artifact stating per-task-category token, step and cost-per-interaction budgets beyond which an agent run must degrade, stop or be escalated.

Responsibility. Declares the resource budgets agent runs must respect.

Also known as: Cost budget, Complexity threshold, Coding-agent resource budget

Relationships

configures structural

  • Alert Manager Ch3.10
  • Token Budget Enforcer Ch3.10 Ch10.5

Design guidance

  • SHOULD set budgets per task category, since simple and complex tasks have fundamentally different efficiency profiles.

Quantitative guidance

As stated by the sources; verify before use.

  • A 500-token context limit suited to FAQ queries could cripple document analysis needing ~2,000 tokens of retrieved content (Ch3.10).
