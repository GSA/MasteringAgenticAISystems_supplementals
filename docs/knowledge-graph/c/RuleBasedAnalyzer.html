Rule-Based Analyzer

Software componentCognitionCognition & Memoryarc:RuleBasedAnalyzer

A deterministic analyzer that applies domain rule checks or rule-based extraction as a lower-fidelity substitute for LLM-based analysis.

Responsibility. Produces a basic deterministic analysis when LLM-based analysis is unavailable.
