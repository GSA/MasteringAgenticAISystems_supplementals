Tool Efficiency Scorer

Software componentObservability & EvaluationObservability & Evaluationarc:ToolEfficiencyScorer

A response scorer that analyses an agent's tool-call sequence for a task and penalizes redundant or suboptimal invocations.

Responsibility. Scores how efficiently an agent used tools to complete a task.

Also known as: Tool utilization effectiveness

Variant of Response Scorer abstract

When to choose. Choose when the agent exposes a tool-call log and operational efficiency matters.
