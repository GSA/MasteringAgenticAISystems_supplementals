Memory Write Validator

Software componentSafety & SecuritySafety, Security & Governancearc:MemoryWriteValidator

A validation gate between perception and long-term storage that checks candidate memories for consistency, hallucination patterns and multi-source confirmation before persistence.

Responsibility. Blocks unverified or inconsistent information from entering long-term memory.

Also known as: Memory validation gate

Design guidance

  • MUST validate information before persisting it; agents SHOULD NOT autonomously memorise unvalidated content.
  • SHOULD require multi-source confirmation for critical assertions.
