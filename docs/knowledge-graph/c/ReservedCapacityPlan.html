Reserved Capacity Plan

Data artifactInfrastructureInfrastructurearc:ReservedCapacityPlan

A serverless hosting plan that provisions continuously running reserved compute billed for capacity rather than per execution.

Responsibility. Provides always-on reserved capacity for steady function workloads.

Also known as: App Service Plan, Dedicated plan

Variant of Serverless Hosting Plan abstract

When to choose. Choose for predictable, constant high-volume agent workloads where reserved capacity costs less than pay-per-execution billing.
