Image Type Classifier

Software componentKnowledge & DataKnowledge & DataVariation point (abstract)arc:ImageTypeClassifier

An abstract preprocessing classifier that assigns each image a content class, such as chart/plot versus general image, to drive processing-path selection.

Responsibility. Classifies images by content type so they can be routed to the appropriate vision model.

Also known as: Content complexity assessor, Chart detector

Variants

VariantWhen to choose
Heuristic Image Type ClassifierChoose when a simple rule suffices to spot charts, e.g., images containing axis labels, legends or grid patterns, as in the financial-report worked example.
VLM-based Image Type ClassifierChoose when routing at scale and a vision-language model is already deployed, reusing it for meta-classification instead of adding a separate classification model.
