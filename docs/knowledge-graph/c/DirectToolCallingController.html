Direct Tool-Calling Controller

Software componentOrchestrationOrchestration & Toolsarc:DirectToolCallingController

An agent controller that maps a request directly to one or a few structured tool calls without iterative reasoning loops or upfront planning.

Responsibility. Answers simple requests via direct function calls.

Also known as: Direct tool calling, Simple function calling, Structured function-calling agent, OpenAI Functions agent, OPENAI_FUNCTIONS agent, Single tool integration

Variant of Agent Controller abstract

When to choose. Choose for simple, deterministic tasks where a straightforward tool call suffices and latency or budget constraints cannot absorb multi-step reasoning or planning overhead.
