Data Value Anomaly Detector

Software componentKnowledge & DataKnowledge & Dataarc:DataValueAnomalyDetector

A statistical consistency checker that flags field values deviating significantly from historical ranges or violating known numeric constraints as potential factual errors.

Responsibility. Flags statistically anomalous data values that suggest inaccuracy.
