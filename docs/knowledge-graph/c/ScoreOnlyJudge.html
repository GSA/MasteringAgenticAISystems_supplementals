Software componentObservability & EvaluationObservability & Evaluationarc:ScoreOnlyJudge

An LLM judge that returns evaluation scores without exposing any reasoning trace for its verdict.

Responsibility. Grades outputs with bare scores.

Also known as: Black-box judge, Opaque evaluator

Variant of LLM Judge abstract
