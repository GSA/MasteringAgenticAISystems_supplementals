Rule Firing Trace

Data artifactGovernance & ComplianceSafety, Security & Governancearc:RuleFiringTrace

A per-decision record of which rules fired, in what order, on which matched facts, and what each derived, forming the decision's complete reasoning chain.

Responsibility. Records the exact inference path that produced a rule-based decision.

Also known as: Inference trace, Reasoning trace
