Secrets Vault

Data storeSafety & SecuritySafety, Security & Governancearc:SecretsVault

A secure store of API keys and credentials used by tools, from which agents obtain current credentials.

Responsibility. Stores credentials for tools and services.

Also known as: Credential store, Centralized credential configuration, Credential management for web authentication, API key management, Centralised provider credentials, CI encrypted secrets, Kubernetes Secret holding NGC API key, Kubernetes Secret (secretKeyRef)

Design guidance

  • SHOULD propagate key rotation to agents so credentials stay consistent across development and production.
  • MUST inject API keys and registry/cluster credentials into pipelines as encrypted secrets, never hardcoded or logged.
  • MUST store registry credentials as orchestrator secrets and monitor their validity, since expired keys cause hard-to-diagnose pull failures.
