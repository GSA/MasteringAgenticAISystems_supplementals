Tool Integration Adapter

Software componentTools & IntegrationOrchestration & ToolsVariation point (abstract)arc:ToolIntegrationAdapter

An abstract connector that binds a tool to an external system through a specific integration mechanism and returns structured results.

Responsibility. Connects tool calls to an external system.

Also known as: Tool, Integration mechanism, Web search tool, Calculator tool, Native function, Tool function calling a model-serving inference endpoint

Variants

VariantWhen to choose
Database ConnectorChoose when the agent needs direct querying or updating of structured data stores.
Message Queue AdapterChoose for distributed systems needing reliable, buffered delivery that survives temporary component failure.
REST API AdapterChoose for synchronous CRUD operations and cloud-service integration; the most common mechanism.
Webhook ReceiverChoose for event-driven, asynchronous workflows where external systems should notify the agent instead of being polled.

Design guidance

  • SHOULD be single-purpose, composable, and functionally pure where possible.
  • SHOULD return descriptive error messages (timeouts, rate limits, invalid input, no results) as observations rather than raising exceptions, so the agent can reason about retrying or refining.
  • SHOULD be used for deterministic operations (database queries, API calls, calculations, business logic) where LLM reasoning is unnecessary and reliability is critical.
