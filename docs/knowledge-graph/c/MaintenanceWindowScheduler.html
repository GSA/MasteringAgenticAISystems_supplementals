Maintenance Window Scheduler

Software componentInfrastructureInfrastructurearc:MaintenanceWindowScheduler

An operations component that schedules planned maintenance in a low-traffic window and sequences user notification, state backup, rollback-point preparation, execution and health verification.

Responsibility. Coordinates planned maintenance within a scheduled window.

Also known as: Scheduled maintenance
