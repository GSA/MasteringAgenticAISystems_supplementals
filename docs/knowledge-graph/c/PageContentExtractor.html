Page Content Extractor

Software componentTools & IntegrationOrchestration & Toolsarc:PageContentExtractor

An information-extraction tool that reads visible text and extracts structured data such as tables from the current web page without modifying site state.

Responsibility. Returns page content (text, table data) to the agent for READ tasks.

Also known as: Information extraction tool, Read text / extract table data tool
