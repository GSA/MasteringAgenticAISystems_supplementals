Grounded Answer Prompt Template

Data artifactKnowledge & DataKnowledge & Dataarc:GroundedAnswerPromptTemplate

A prompt template instructing the LLM to answer using only the supplied retrieved context and to cite sources by numbered reference, together with low-temperature generation settings.

Responsibility. Constrains generation to retrieved context with citations.

Also known as: RAG prompt template, Grounding prompt
