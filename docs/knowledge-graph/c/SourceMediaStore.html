Source Media Store

Data storeKnowledge & DataKnowledge & Dataarc:SourceMediaStore

A store of original non-text source assets (images, charts, audio recordings) referenced from chunk metadata for visual reasoning, citation, and playback.

Responsibility. Preserves original media so retrieved chunks can be traced back to their source assets.

Also known as: Original image store, Audio source repository
