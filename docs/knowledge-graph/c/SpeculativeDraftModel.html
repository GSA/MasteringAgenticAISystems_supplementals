Speculative Draft Model

Model assetModel ServingModelsVariation point (abstract)arc:SpeculativeDraftModel

A small, fast language model that proposes multi-token candidate continuations for a larger target model to verify in one forward pass.

Responsibility. Drafts candidate tokens for target-model verification.

Also known as: Draft model, Two-model draft

Quantitative guidance

As stated by the sources; verify before use.

  • Typically 5-10x smaller than the target with 60-80% token-level agreement (Ch4.4).
  • 3B draft reached only 48% acceptance; 13B draft overhead negated benefits; 8B (8.7x smaller) was near-optimal for a 70B target (Ch4.4).
  • Draft 7B + target 70B needs ~77GB FP16 (154GB with KV cache/activations); on A100 80GB draft reduces target batch from 16 to 8-10 (Ch7.1A).
