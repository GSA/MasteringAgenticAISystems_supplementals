Operational Norm Set

Data artifactGovernance & ComplianceSafety, Security & Governancearc:OperationalNormSet

A context-specific set of behavioural norms and constraints translated from abstract values (e.g., fairness as demographic parity, equalized odds or individual fairness) that agents and their guardrails can computationally enforce.

Responsibility. Translates endorsed values into enforceable per-context or per-agent behavioural boundaries.

Also known as: Operational norms, Network of norms, Agent-level value constraints, Behavioral norms

Design guidance

  • MUST document which values were prioritized when conflicting values were translated into norms, and why.
  • SHOULD encode critical, never-to-be-violated requirements as explicit rules and leave contextual judgment to learned alignment or human oversight.
  • SHOULD specify fewer, carefully prioritized values rather than many unprioritized constraints, which cause moral overload and brittleness.
  • SHOULD be customized per domain and context; alignment norms do not transfer directly across domains.
  • SHOULD be treated as provisional and updated as monitoring and feedback reveal gaps.
