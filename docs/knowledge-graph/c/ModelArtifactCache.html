Model Artifact Cache

Data storeModel ServingModelsarc:ModelArtifactCache

A shared store of model weights and adapters mounted by inference replicas so models load locally instead of being re-downloaded by each replica.

Responsibility. Serves model artifacts to replicas without redundant downloads.

Also known as: Model cache volume, Model cache directory
