Vector Store Query API

InterfaceKnowledge & DataKnowledge & DataVariation point (abstract)arc:VectorStoreQueryAPI

The network interface through which clients authenticate to a vector store and submit schema, ingestion and search requests.

Responsibility. Accepts authenticated query and write requests for a vector store.

Variants

VariantWhen to choose
Vector Store REST APIChoose for broad client compatibility, debugging and moderate query volumes (below ~100 requests per second).
Vector Store gRPC APIChoose when query volume exceeds ~100 requests per second or real-time applications need the lowest latency.
