Execution Monitor Console

Software componentHuman OversightExperience & Human Oversightarc:ExecutionMonitorConsole

A real-time oversight interface showing agent workflow progress, aggregate metrics, and upcoming steps, with prominent pause, stop, emergency-stop, and override-next-action controls.

Responsibility. Lets humans observe running agent workflows and intervene.

Also known as: Monitoring dashboard, Monitoring pattern, Progress panel, Big red button, HOTL monitoring dashboard, Visibility layer, Robot supervisory dashboard

Design guidance

  • MUST provide clear pause and stop controls for long-running processes.
  • SHOULD show aggregate status (success rate, processing speed, error count) by default with drill-down to individual transactions.
  • SHOULD emphasise an emergency stop over per-action control for high-frequency automation.
  • SHOULD expose persistent decision context (input, triggering rule, confidence, metadata) for drill-down after execution.

Quantitative guidance

As stated by the sources; verify before use.

  • Users should be able to scan the monitor in about 5 seconds to judge 'everything normal' vs. 'needs attention' (Ch1.1B).
