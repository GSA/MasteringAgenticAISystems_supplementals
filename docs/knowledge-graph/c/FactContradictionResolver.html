Fact Contradiction Resolver

Software componentCognitionCognition & Memoryarc:FactContradictionResolver

A cognition component that reconciles duplicate or contradictory derived facts in working memory according to a configured strategy before they are committed.

Responsibility. Keeps working memory coherent when rules derive duplicate or conflicting facts.
