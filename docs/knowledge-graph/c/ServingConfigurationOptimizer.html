Serving Configuration Optimizer

Software componentModel ServingModelsarc:ServingConfigurationOptimizer

An automated search component that sweeps inference-server settings (instance count, dynamic-batching size and timeout, concurrency, cache sizing), measures each, and reports the latency-throughput Pareto frontier.

Responsibility. Selects serving configurations on the latency-throughput Pareto frontier.

Also known as: Configuration search, Model analyzer
