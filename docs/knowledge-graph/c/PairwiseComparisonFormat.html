Pairwise Comparison Format

Data artifactHuman OversightExperience & Human Oversightarc:PairwiseComparisonFormat

An annotation task format presenting two candidate responses to one prompt and asking which better satisfies the stated criteria.

Responsibility. Elicits reliable comparative judgments that map directly to Bradley-Terry reward modeling.

Variant of Annotation Task Format abstract

When to choose. Choose as the default (gold standard) elicitation format: comparative judgments are more reliable than absolute ratings and scale well.
