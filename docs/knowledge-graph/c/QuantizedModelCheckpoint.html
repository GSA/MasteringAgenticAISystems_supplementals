Quantized Model Checkpoint

Model assetModel ServingModelsarc:QuantizedModelCheckpoint

A framework-neutral model graph whose weights are stored at reduced integer or floating-point precision together with embedded quantization metadata (scaling factors, zero points), not yet compiled for a target GPU.

Responsibility. Holds the calibrated low-precision model and its quantization parameters as input for engine compilation.

Also known as: Quantized ONNX, INT8 ONNX model
