Property Graph Store

Data storeKnowledge & DataKnowledge & Dataarc:PropertyGraphStore

A knowledge graph store using the property graph model, with labelled nodes and typed directed edges that both carry key-value properties.

Responsibility. Stores labelled nodes and typed edges carrying key-value properties.

Also known as: Labeled Property Graph

Variant of Knowledge Graph Store abstract

When to choose. Choose when rapid development and schema flexibility (properties on nodes and edges, multiple labels, schema evolution) matter more than formal semantics; the industry-standard choice for agent systems.
