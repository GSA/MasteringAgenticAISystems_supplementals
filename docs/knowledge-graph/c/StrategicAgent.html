Strategic Agent

Software componentCognitionCognition & Memoryarc:StrategicAgent

A self-interested agent that selects strategies by reasoning about or learning from competitors' actions in a non-cooperative environment.

Responsibility. Chooses actions that maximise its own payoff against competing agents.

Also known as: Competitive agent, Game-theoretic agent

Design guidance

  • SHOULD NOT treat Nash equilibrium as collectively optimal; equilibria may be inefficient or multiple.
  • SHOULD expect non-stationarity when competitors learn simultaneously; convergence guarantees vanish.
  • SHOULD be hardened against adversarial observation, action and environment attacks, which transfer across agent architectures.
