Capability-Matching Allocator

Software componentOrchestrationOrchestration & Toolsarc:CapabilityMatchingAllocator

A task allocator that queries advertised agent capabilities and selects a collaborator based on current load, historical accuracy or cost.

Responsibility. Selects a collaborator by matching task needs to advertised capabilities.

Also known as: Capability discovery selector

Variant of Task Allocator abstract

When to choose. Choose when collaborators must be discovered at runtime by advertised capability rather than hardcoded.
