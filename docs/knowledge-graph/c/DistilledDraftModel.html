Distilled Draft Model

Model assetModel ServingModelsarc:DistilledDraftModel

A separate small draft model trained by knowledge distillation to minimize KL divergence from the target model's logits, learning the target's preferences rather than accuracy.

Responsibility. Provides high-acceptance speculative drafts aligned to the target distribution.

Variant of Speculative Draft Model abstract

When to choose. Choose for production where improved acceptance justifies 50-100 GPU-hours of training; use online distillation at scale to track target shifts.
