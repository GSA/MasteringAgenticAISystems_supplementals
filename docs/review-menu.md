# Review menu
{: .no_toc }

Every chapter, slide deck and quiz set has its own issue. Pick the ones that match what you know. Each issue is deliberately open-ended: read, then tell us what you find.

## How it works

1. Find an issue below (or browse the [open review issues](https://github.com/GSA/MasteringAgenticAISystems_supplementals/issues?q=is%3Aissue%20is%3Aopen%20label%3Atrack%3Acontent-review)).
2. Comment on it to say you'd like to take it, and which angle you plan to take if you have one. A maintainer assigns it to you.
3. For a chapter, we email you the chapter text. Chapter text is not published in this repository. Slide decks and quizzes are already public, so you can start right away.
4. Post what you find as comments on the issue: where it is, what you found, a quote or source, and a suggested fix. The [review checklist]({{ site.repo_blob }}/.github/REVIEW_CHECKLISTS.md#instructional-content-review-chapter-text-slides-quizzes) says what a useful finding looks like.
5. Say where you land: accept, minor revisions, or major revisions. A partial review (one section, or one angle) is a real contribution.

There is no minimum and no fixed list to work through. Contributors are credited through [All Contributors]({{ site.repo_blob }}/CALL_FOR_COLLABORATORS.md#what-you-get).

## What kinds of review help

- **Fact-checking.** Are the claims right, and are tools, models, APIs and standards still current?
- **Expert reading.** Does it match how practitioners actually build and operate these systems?
- **Learner's eye.** Is it clear, in a sensible order, and pitched at the right level? Where would a newcomer get lost?
- **Exam fit.** Does it prepare a candidate for the certifications it is mapped to in [`cert_mapping/`]({{ site.repo_blob }}/cert_mapping/README.md)?
- **Consistency.** Does it agree with neighboring chapters, the slides and the quizzes?
